## Модель готовности (readiness)

- `readiness` (int промилле) начисляется каждому участнику каждый тик
  (`CombatService.AccrueReadiness`, UpdateTimer): `+= attackSpeedPermil × deltaTime`.
- Удар принимается при `readiness ≥ AttackThresholdPermil (1000‰)`, вычитает
  порог. **Расход — только при ПРИНЯТИИ** (charged/pending/мгновенный пути);
  отвергнутый гейтами удар готовность не теряет. **Кап = порогу** (не
  «банковать» залп замахов).
- `attackSpeedPermil` = `WeaponMain.AttackSpeedPermil` (новое поле предмета;
  генератор копирует AttackSpeedFactor×1000: кинжал 1300, меч 1000, двуруч 750)
  × AGI-фактор `(1000 + AGI×10)/1000` (§8.2, инверсия формулы длительности);
  кулаки 1000; **звери 500‰** (не в провайдере экипировки = видовой темп,
  1 атака/2 тика — прежний каденс волка). Кламп 100-3000.
- **Инициатива**: StartCombat — инициатор readiness=порог (первый удар сразу),
  защитник 0. CombatStage фиксируется на бой (игрок участвует → PlayerTurn).
- Эффект (Normal, 1 тик=1с): волк 500‰ → укус/2 тика; игрок-меч 1100‰ →
  **2.2 удара за укус волка**; кинжал 2.86; двуруч 0.93 (урон-компенсация
  SpeedDamageScale уже работала — пара урон/скорость замкнута).
- `ICombatService` + `GetReadinessPermil(entityId)` / `IsAttackReady(entityId)`
  / `IsEntityCasting(entityId)` (гейт LOS/стрел проверяет каст ИМЕННО
  атакующего — прежде общий IsCasting при параллельных атаках почти всегда
  true → гейт отключался, LOS-тест ловил это).

## CLASH — одновременная атака → парирование (решение пользователя)

- Удар прилетает, пока **защитник в замахе** (его собственный per-attacker
  pending-каст) → «клинки скрестились»: удар парируется **гарантированно**
  (DamageRequest.ForceClashParry → Parry → урон ×0.5, слой 5); замах
  защитника НЕ отменяется, готовность не тратится (уже потрачена на замах).
  Уклонение/крит сильнее (обрабатываются до форса).
- Обычные удары стойкой выбора НЕ блокируются («пока что не блокируемые»);
  стойки (R16) остались реакцией на следующую входящую атаку.
- Первая итерация (IsAttackReady-защитник + ConsumeReadiness) выкачивала
  готовность защитника входящими атаками (игрок не мог ударить) — переведена
  на семантику «защитник в замахе».

## Инциденты по ходу (починены)

1. **Цикл DI**: AnimalService ctor + ICombatService ↔ CombatService →
   StatProviderAdapter → IAnimalService → цикл (IBodyDataProvider).
   Фикс: AnimalService БЕЗ ICombatService (видовой темп рулит readiness-гейт
   CombatService; тиковый CombatCooldownTicks=2 оставлен как троттлинг
   интентов, синхронный с готовностью).
2. **Combat-wide pending-каст**: атака игрока отвергалась «Каст уже идёт:
   npc_strike» пока кастовал NPC — несовместимо с параллельными ударами →
   per-attacker словарь (прерывание по урону/конец боя — по-прежнему честны).
3. **LOS-гейт отключался**: `!IsCasting` (любой) при почти постоянном чужом
   касте → стрела летела сквозь камень (QA LOS-тест поймал) → IsEntityCasting.
4. **Расход готовности до гейта каста** + **кап 3000** (залп 3 ударов) →
   расход только при приёме + кап = порогу.
