### 2. Performance fixes (Easy Wins из аудита 4-a)

#### Fix 1: SmoothBiomes — Dictionary → int[16] array
- **Раньше:** `new Dictionary<BiomeType,int>()` PER TILE → 250k allocs (64 MB GC churn at 500×500)
- **Теперь:** `var counts = new int[16]` heap-allocated ONCE, reset per tile
- **+** `BiomeTypeCount` cached statically (avoid `Enum.GetValues` per tile — caused stack overflow)
- **Фикс stack overflow:** `stackalloc int[16]` в 250k итераций вызывал SO → replaced with heap array

#### Fix 2: Viewport culling для 3 рендереров
Каждый рендерер теперь вычисляет видимую область через `GetGlobalTransformWithCanvas().AffineInverse()` и итерирует только видимые тайлы:
- **BiomeTileRenderer:** 250k → ~57-144 tiles (1736× reduction)
- **ObjectLayerRenderer:** 250k → ~7-11 objects (2270× reduction)
- **SurfaceTransitionRenderer:** 2M GetTile → ~100-200 (margin +1 для neighbor lookups)
- **QueueRedrawAll()** в SceneBuilder, throttle 10 Hz в GameWorldController (`RedrawIntervalSec = 0.1f`)

#### Fix 3: Parameterize map size
- `LocationCatalog.LargeWorld` (500×500, seed=67890) добавлен
- `IGameSession.NewGame(int startVariant, string locationId)` overload
- `TileMapGenPhase` / `PlayerSpawnPhase` / `WorldInitPhase` используют `_session.Data.WorldId` (не hardcoded)
- `MainMenuController`: кнопка "◈ Большой мир (500×500)"

#### Fix 4: GODOT_MAP_SIZE env var для CLI benchmarking
- `GODOT_MAP_SIZE=500 godot --headless scenes/GameWorld.tscn`
- Stopwatch в TileModule.Start для измерения

## Решения

- **Viewport culling вместо TileMapLayer migration** — Easy Win (2 часа vs 3-5 дней). Culling даёт 1736× reduction, достаточно для 500×500. TileMapLayer migration отложен до 1km+ maps.
- **int[16] array вместо Dictionary** в SmoothBiomes — устраняет 250k allocs, фиксит stack overflow
- **QueueRedraw throttle 10 Hz** — баланс между отзывчивостью и производительностью. При zoom=3 visible tiles меняются медленно.
- **GODOT_MAP_SIZE env var** — для automated benchmarking без UI
- **LocationCatalog как single source of truth** — убраны hardcoded 50×50 из TileMapGenPhase, PlayerSpawnPhase, WorldInitPhase

## Найденные проблемы

- **Stack overflow в SmoothBiomes** при 500×500 — `stackalloc int[16]` в 250k итераций. Fixed: heap-allocated array.
- **Enum.GetValues per tile** — вызывался 250k раз, медленно + alloc. Fixed: static cache.
- **Biome sprites missing** (biome_ocean.png etc.) — существующая проблема, не связана с текущей задачей. Godot не может загрузить .ctex (нужен Editor для импорта).
- **Duplicate Generate** — TileModule.Start генерирует fallback (для CLI), TileMapGenPhase генерирует снова (для NewGame). При normal flow (MainMenu → NewGame) генерация дважды. Для 500×500 это 2.8 sec вместо 1.4 sec. Acceptable для V1, fix в V2 (make TileMapGenPhase skip if already generated).
