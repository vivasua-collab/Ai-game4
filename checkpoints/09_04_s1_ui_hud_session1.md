## Диагностика (VLM-аудит скриншота боя)

Критичные проблемы (по приоритету):
1. Контраст: статусная строка (дата/время, Ци-подпись) — светлый текст без
   тени на светлом фоне воды — нечитаемо.
2. Информативность: нет числового HP игрока, нет имени/уровня врага,
   нет статуса боевой готовности (кулдаун атаки M2 §8.1).
3. «Мёртвые проводки»: клавиша J (журнал) и Q (квесты) рекламировались
   в легенде HUD и F1-справке, но не существовали — вход в квест-систему
   вообще отсутствовал (никто не вызывал StartQuest).

## Что сделано

1. **HUD-контраст (GameWorldController.SetupHUD):**
   - timeLabel/qiLabel/attackStateLabel: + font_shadow_color (0,0,0,0.85)
   - hudLabel (легенда клавиш): 13→14px + светлая тень

2. **HP/Qi бары игрока:**
   - StyleBoxFlat-подложки с рамкой (бары больше не теряются на фоне)
   - Числовые подписи на барах: «HP 472/500», «Ци 1000/1000»
     (Label-дети ProgressBar, FullRect, тень)
   - qiLabel упрощён: только «L1.0 | пров. 2.8/с» (цифры теперь на баре)

3. **Индикатор боевой готовности (⚔ под барами):**
   - PlayerCombatAdapter.AttackCooldownRemaining (новое свойство)
   - «⚔ Ближний/Дальний бой — атака готова / удар через 0.4с»
     (режим из CurrentWeaponMode, кулдаун из M2 §8.1; приглушение в откате)

4. **Нейм-плейты врагов (NPCSpriteRenderer):**
   - Над HP-баром повреждённого NPC: «Имя · L{уровень} · {hp}HP»
   - Center-паттерн FormationVisualRenderer + двойная отрисовка (тень)
   - Данные: NPCState.DisplayName + CultivationLevel (IWorldTimeService-метки
     не нужны — HP-бар уже есть)

5. **EventLogWindow (J) — НОВОЕ окно, 2026-09-04:**
   - Журнал событий: бой (старт/удары/победа), смерть врага, добыча,
     подбор, прорыв культивации
   - Анти-спам: только события с участием игрока (npc-vs-npc отфильтрован)
   - Ring-buffer 60 записей, метки игрового времени, цвет-кодирование
   - IPlayerInputService.IsJournalPressed (экспорт «мёртвого» поля _journal)

6. **QuestWindow (Q) — НОВОЕ окно, 2026-09-04:**
   - Все квесты: имя, статус, описание, цели с прогрессом, награды
   - Кнопка «Принять» для NotStarted → StartQuest (квест-система впервые
     достижима из UI! 4 дефолтных квеста регистрируются в QuestService)
   - IQuestService.GetQuestSummaries() + Core-DTO QuestSummary
     (Core не ссылается на типы модуля — слойность соблюдена)
   - IPlayerInputService.IsQuestLogPressed (экспорт «мёртвого» поля _questLog)

7. **Модальные окна:** J/Q пауза-как-F1 + Esc-цепочка закрытия
   (GameWorldController.HandleStickyInput).

## Найденные проблемы / решения

- GetStringLength/GetTextSize недоступны в Font API 4.7 → Center-паттерн
  (width-параметр DrawString), как в FormationVisualRenderer
- Тень Label: font_shadow_color достаточно (проверено кропом), offset-константы
  не обязательны
