# Чекпоинт: Этап-7 аудита — квесты/диалоги/NPC (BUG-022..024, GAP-025)

**Дата:** 2026-10-22 16:35 UTC
**Сессия:** Этапы 6-7 аудита; Этап-7 завершён после обрыва контекста (точка падения — батарея источников сима)
**Тип:** audit + fix

## Контекст

Этап-7 внешнего аудита: квесты/диалоги/NPC. Дефекты: BUG-022 (P2) покупка
засчитывалась как сбор + дабл-адд добычи, BUG-023 (P2) завершение одного квеста
пропускало другой той же цели, BUG-024 (P2) неподдержанная награда терялась при
метке «выдано», GAP-025 TalkToNPC без проверки типа взаимодействия.

Обрыв сессии произошёл на Stage7-симе: первая редакция гонила батарею источников
по реальному квесту quest_gather_iron с таргетом 5 — после реальной добычи
(+3) источники world/pickup закрывали квест, loot/craft оставались без запаса и
«не зачитывались». Владелец диагностировал: ошибка КОНСТРУКЦИИ СИМА, не игры —
и директивой вынес батарею в отдельный квест с таргетом 50.

## Что сделано

- BUG-022: ItemAddedEvent.Source + канон ItemSources (11 источников);
  TryAddItem(item, count, source) — все продюсеры размечены; QuestProgressTracker
  засчитывает GatherItem ТОЛЬКО для world/harvest/pickup/loot/craft (пустой
  источник = world, легаси); дабл-адд добычи (command + факт) вылечен — одна
  добыча = ровно один ItemAddedEvent.
- BUG-023: QuestService.ForEachActiveQuest — обход по СНИМКУ активных ID
  (ToArray) + фильтр по фактическому статусу Active: CompleteQuest внутри
  callback не сдвигает обход; одно событие закрывает ВСЕ квесты одной цели.
- BUG-024: QuestRewardService.GrantRewards — превалидация ВСЕГО набора:
  реализованы Item/Qi; неподдержанный тип = отказ ЦЕЛИКОМ (консоль + тост),
  квест НЕ помечается награждённым; never-grant-страховка в GrantSingleReward.
- GAP-025: OnNPCInteracted — TalkToNPC только при InteractionType == "talk"
  (Ordinal); trade/attack/gift игнорируются.
- Сим Stage7QuestTruthSimDebug (GODOT_STAGE7_DEBUG, №25): ИСПРАВЛЕНА КОНСТРУКЦИЯ
  по директиве владельца — батарея источников живёт в отдельном квесте
  qa_battery_sources (GatherItem material_iron_ore, таргет 50), стартует ПОСЛЕ
  реальной добычи (чистая база 0): 6 не-сборов не двигают, world/pickup/loot/craft
  дают +4 (квест жив 4/50); побочный инвариант-документация: реальный квест
  quest_gather_iron закрылся РОВНО на таргете 5/5 без перелива (AddProgress
  капает в Min, завершённые не итерируются). VERDICT PASS 11/11 (полный лог —
  qa_artifacts/stage7_sim_20261022.log).
- Фикстура AUDIT0922 P1-19 (Этап-6 зона, но обнаружена на регрессии Этапа-7):
  qa_p_probe регистрируется в каталог — валидация BUG-021 честна, P4/P5 снова
  PASS (контракт «снятое ≠ стёртое» не менялся).

## Решения

- Семантика сбора = ИСТОЧНИК предмета, а не факт наличия в инвентаре: покупка/
  награда/переносы — не сбор (директива аудитора, соответствует жанру).
- Тестовым батареям семантики — собственные квесты с запасом по таргету:
  батарея на живом квесте упирается в его потолок и меряет потолок, а не
  семантику (урок Stage7-батареи; тот же класс ошибки — у фикстуры P1-19).
- Снимок вместо живого списка в ForEachActiveQuest: мутация внутри callback
  легальна, обход стабилен; события редкие — аллокация допустима.
- Неподдержанная награда = ЧЕСТНЫЙ отказ с сохранением права на повторную
  выдачу (never-grant вместо was-granted).

## Найденные проблемы

- (сим, не игра) батарея источников на таргете-5 — упёрлась в потолок квеста;

- (фикстура, не игра) AUDIT0922 qa_p_probe без каталога — отклонялся валидацией
  BUG-021; вылечена регистрацией зонды.
