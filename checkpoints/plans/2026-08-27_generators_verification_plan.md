## Цели сессии (из запроса пользователя)

1. **Проверить работу** генераторов техник (TechniqueGeneratorService),
   генераторов формаций (FormationGeneratorService), генераторов экипировки
   (EquipmentGenerator + ItemGeneratorService), прорисовку формаций
   (FormationService lifecycle Drawing→Filling→Active→Depleted).
2. **Создать систему верификации** техник и экипировки: объекты должны
   входить в границы своего уровня.
3. **Проработать границы уровней**: min/max для damage / capacity / qiCost /
   durability по (Level, Type/Subtype, Grade).
4. **Разброс характеристик** в рамках уровня: какие параметры варьируются
   (mastery, coverage, dodge, weight variance).
5. **Легендарные вещи**: разрешён заход на +1 уровень по некоторым
   характеристикам (макс. 1-2 статам). Mythic =+1 ко ВСЕМ.
6. **Пред-генерация техник при генерации мира**: новая фаза `PreGenTechniquePhase`
   печёт набор техник на уровень сессии, регистрирует в `TechniqueRegistry`,
   затем `VerificationService` постпроверяет и отбрасывает невалидные.
7. **Дедупликация**: одинаковые по характеристикам (но разные по имени) техники
   должны быть детектированы и удалены.
8. **Чит-меню**: обновить документацию `docs_v2/07_ui/CHEAT_PANEL.md`, добавить
   кнопки: генерация экипировки (оружие/броня по типу + рандом), генерация
   расходников, генерация техник с привязкой формаций.
9. **Проверка визуализации формаций**: убедиться, что в sim-режиме работает
   StartDrawing → ContributeQi → Active → Depleted → autodеactivate.

- **G.** Документация: CHEAT_PANEL.md, LEVEL_BOUNDARIES.md, VERIFICATION_SYSTEM.md.
