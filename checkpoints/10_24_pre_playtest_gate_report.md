**Изолированная инъекция** (`GODOT_STAGE18_FAULT_INJECT=1`, сценарий H):

```
FAIL       CRASH/H — необработанное исключение: InvalidOperationException:
           Stage18 fault-injection: … вердикт обязан стать FAIL

```

PASS при crash невозможен; 30 зелёных сценариев не маскируют падение.
`qa_regression.sh` (шаг STAGE18-FAULT-INJECT, ожидание FAIL) распознал
инъекцию **1/1 в каждом прогоне регрессии** (2/2 прогонов гейта): инъекция
краснеет → шаг зелёный; зелёная инъекция или отсутствие вердикта считались
бы провалом агрегации. Норма без инъекции: `PASS=31 FAIL=0 CRASH=0 GAP=1`,
VERDICT PASS — проверки не ослаблены (FA-1, f129408).

Уроки окружения (в логе инъекции): без `DOTNET_ROOT` движок падает
signal 11 (hostfxr) — окружение, не код; без `GODOT_QA_SEED` легитимно
падает F1 (детерминизм реестра техник требует сид раннера), при этом
инъекция краснела и без сида — контракт crash→FAIL от сида не зависит.

## 5. GATE-001 — дефект, найденный GUI smoke (исправлен в гейте)

GUI smoke large_world обнаружил: **33× IndexOutOfRangeException за 55с**
в `NPCPathfinder.NewNode` (строка 240). GameEntryPoint гасит исключения
модуля пер-тиково (мир жив), но аборт `ProcessMovement` за тик ломал
обработку ходьбы всех NPC основного мира плейтеста.

- **Причина:** пулы `_pos/_g/_f/_parent/_heap` размером `MaxNodes=4000`;
  guard `++expanded > MaxNodes` считает POP-узлы, но узлы СОЗДАЮТСЯ до
  ~8 на раскрытие → `_nodeCount` пересекал ёмкость. large_world 500×500
  (достижимых тайлов ≫4000) исчерпывал бюджет; test_polygon 50×50 (2500
  тайлов) достичь не мог — headless-QA был структурно слеп.
- **Фикс:** `NewNode` возвращает −1 при `_nodeCount >= MaxNodes`;
  вызовы FindPath обрабатывают −1 (skip соседа / null на старте).
  Потолок = штатный «нет пути» → `NoPath + retry 0.5с` (жадный шаг как
  страховка) — контракт NPC_AI_SYSTEM §6 сохранён, детерминизм
  tie-break не тронут, анти-всплеск-семантика потолка сохранена.
- **Постфикс:** 0 исключений за 55с + 600/2400-кадровые прогоны;
  STAGE13/COMBATAI/L500 зелёные; полная регрессия №2 зелёная (§4).
- Зарегистрирован в реестре: **GATE-001** (P1, verified, волна 9).

Префикс/постфикк: `…_gui_smoke_prefix.log` / `…_gui_smoke_postfix.log`.
