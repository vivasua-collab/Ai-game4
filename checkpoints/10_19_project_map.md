## Контекст

аудита кода — с расчётом на будущий **веб-портал «звуковые дорожки»**:
последовательные шкалы выполнения задач, где у каждого модуля свой «трек»
(начало → выполненные этапы → невыполненные → финал модуля). Явно указано:
несколько итераций, не всё за раз.

## Ключевые аудит-вердикты итерации 2 (grep-пруфы)

1. **Mastery НЕ растёт** от использования — фиксируется rng при генерации
   (формулы чувствительны). Механика роста → контент-план M6.
2. **Каст-эффекты техник** подтверждены у Combat/Defense/Healing/Movement
   (рывок с P2-45 клампом); Sensory/Curse/Poison/Support — генерируются
   без эффектов.
3. **Формации:** зарядник→формация работает (FormationContributeQiRequestEvent
   от ChargerService); NPC-помощники (до 50) — нет; enum Disk/Altar есть,
   предметов-носителей нет; типы Barrier/Trap/Amplification генерируются,
   боевые бонусы работают (R24/B5).
4. **NPC AI:** Spinal/BehaviorTree/NeuralRouter/BrainController — 0 вхождений
   в коде; фактически работают месть/селектор защит/бегство/leash (событийные
   реакции, без слоистой архитектуры спеки §3.7).
5. **Крафт:** CraftingService + RegisterRecipe(s) API готовы; UI крафта и
   контент рецептов — 0 вхождений.
6. **Смерть игрока:** технический респавн (GWC 3с) есть; экрана смерти нет.
7. **События мира:** IEventService интерфейс без реализации; караваны —
   TrySpawnEventNpc (NPC-модуль), событийной системы нет.
8. **Зарядники:** домен 5 форм-факторов готов (ChargerData), генерация+UI
   только Belt. **NPCCategory** Temp/Plot/Unique: enum+сейв есть, семантика
   различий частичная. **VFX стихии:** ElementPalette красит 5 рендеров —
   этап закрыт.

## Решения

- **Формат = JSON + генерируемый MD** — портал читает JSON; человек — MD;
  рассинхрон исключён одним источником правды.
- **Прогресс по формуле** (доля done-этапов), а не экспертная оценка —
  метрика самосогласована и воспроизводима.
- **29 треков, а не 17** — кроме игровых модулей добавлены треки
  инфраструктуры (core/qa/docs/save), представления (ui/vfx/sprites/perf),
  горизонта (party/content/dungeons) и сквозных систем (loot-death,
  npc-ai отдельно от npc, stats отдельно от player).
- **Вехи M0–M7** — верхняя «дорожка» портала: M4 плейтесты и M5 спрайты
  в работе; M6 контент и M7 MVP — впереди.
