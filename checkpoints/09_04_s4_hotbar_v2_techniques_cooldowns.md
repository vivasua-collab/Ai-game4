## Проблема (информативность — критично)

HotbarPanel (нижняя панель 1-9) показывал на слотах 3-9 **пояс** (расходники),
хотя клавиши 3-9 (без Shift) на самом деле **кастуют техники** из слотов
(TechniqueSlotService). Пояс используется через Shift+3-9. Игрок видел одно,
жал другое — прямое противоречие «интерфейс ≠ реальный биндинг».
Дополнительно: кулдауны техник нигде не отображались (только текст в окне
Культивации), Ци-стоимость техник — тоже (узнавали только по отказу каста).

## Решение: HotbarPanel v2 (полная переработка)

- **Основной ряд (9 слотов 52×52):**
  - 1-2 — оружие (имя + тултип «1/2 — выбор режима атаки»);
  - 3-9 — **техники**: emoji стихии + короткое имя, рамка цвета стихии
    (ElementStyle), тултип с полными статами (Ци/кулдаун/урон/дальность/
    мастерство/Ultimate);
  - **кулдаун-оверлей**: тёмный «занавес» сверху слота (высота =
    remaining/cooldown) + крупные янтарные цифры секунд (F1 < 10с, F0 ≥ 10с)
    с чёрной обводкой; обновление каждый кадр из TechniqueService.GetCooldown
    (кэш текста — Text-сеттер только при изменении);
  - **Ци-гейт**: строка «Ци 64» внизу слота — зелёная если хватает, красная
    если нет (текущий Qi игрока из IQiService.CurrentQi);
  - **клик по слоту = каст** (как клавиша): TechniqueCastRequestedEvent с
    позицией курсора (полный паритет мышь/клавиатура).
- **Пояс-ряд (верхний, 7 слотов 40×40):** виден только при надетом поясе;
  клик = Belt.Use; тултипы предметов; компактная подпись «Пояс ⇧+3..9».
- События: TechniqueSlotAssigned/Cleared → мгновенное обновление слота;
  BeltSlotsChanged/EquipmentChanged(Belt) → обновление пояса.
- Панель динамически меняет размер при появлении/скрытии пояса.

2. Пустой слот 4 → «—».

вместо «—» (кэш _nameCache не учитывал начальное состояние «цифра»).

## Технические находки

- InputAdapter маршрутизация цифр: 1/2 → weapon_melee/ranged sticky,
  3-9 (без Shift) → technique_slot_N → мгновенный каст (не «выбор слота»);
  Shift+N → hotbarSlot → BeltService.Use (GameWorldController:1391-1409).
- TechniqueService._cooldowns тикает из CombatModule.Tick (UpdateCooldowns).
- QiCost техник может быть 0 («Нейтральная Культивация») — Qi-гейт корректно
  считает её всегда доступной (тест пропускает).
- TechniqueSlotSelectedEvent (HotbarContracts) — мёртвый контракт (никто не
  слушает) — не задействован, оставлен без изменений.
- Чит-меню F2: полностью закрыто ранее (M2): гейт GameSettings.CheatsEnabled
  в GameWorldController:1107 + чекбокс в MainMenu + persist user://settings.json.
  Release-сборка не содержит панель физически (#if DEBUG) — двойная защита.
