## Корни и фиксы

### R39-2. Кинжал суммируется с кулаком (3+10=13)
- **Корень**: `CombatService.cs` `baseDamage = Math.Max(baseDamage, weaponBonus)` — урон оружия ЗАМЕНЯЛ кулак (10): любое оружие слабее кулака вносило **НОЛЬ** (кинжал 3: weaponBonus=4 < 10 → били ровно как кулаком; «Урон: 3» на кукле врал).
- **Фикс**: для атак игрока (`isPlayerAttacker`) — `baseDamage += weaponBonus` (кумулятивно); **NPC сохраняют прежний Max** — баланс NPC-боёв (multi R24-C) не сдвинут (глобальное += дало multi-FAIL на первом прогоне).
- `WeaponDamageCalculator.CalculateMeleeWeaponDamage`: handDamage (замаскированный кулак `3+(STR-10)×0.3`) **удалён** из формулы — иначе кулак учтён дважды. Чистый вклад оружия = `weaponDamage + weaponDamage×AGI×5%`.
- Кулак 10 → `GameConstants.UNARMED_BASE_DAMAGE` (выведен из хардкода).
- Кукла: «Урон: 13 (кулак 10 + оружие 3)» — v2 двухстрочно (v1 однострочно **обрезалось краем панели** — поймано VLM, перепруф чистый).
- Итог кинжала L1 @ базовые статы: 10 + 3 + 1 (AGI-скейл) = **14** к базе (голое «3+10=13» + AGI-скейл оружия — сохранённая механика §7.3, объяснено в доке).

### R39-3. Лавка Lx
- `TradeWindow.FormatItemName(item)`: `item is EquipmentData eq ? $"L{eq.ItemLevel} {item.NameRu}" : item.NameRu` — через **единую воронку** ResolveItemName (список торговца, продажа игрока, тултипы, тосты).
- Префикс только на экипировку: расходники уже несут «уровня N» в имени («Лекарство уровня 3»), «Железная руда» уровня не имеет. Формат `L{x}` — конвенция проекта (книга техник, чит-панель).

### R39-4. Погоня 15 + точность от дистанции
- `AnimalService.ChaseRangeTiles` 20 → **15** (ChaseGraceTicks=3 сохранён).
- **НОВАЯ механика Miss** (`DamageCalculator.DetermineAttackResult`, ролл ПЕРВЫМ — до Dodge/Block/Parry):
  - `miss = (dist−3) × 500‰ / (range−3)`, кап 500‰ (50%); dist ≤ 3 → точное прицеливание.
  - Лук (range 18): d4→3%, d9→20%, d15→40%, d18→50%.
  - Инфраструктура: `DamageRequest +AttackDistanceTiles/+RangedRangeTiles`; дистанция — Чебышёв через новый `CombatRangeGateService.GetChebyshevDistanceTiles` на момент резолва удара (после pending-каста 0.5с — цель могла сместиться).
  - **Гейт `tech == null`**: Miss только для basic_attack с дальнобойным оружием. Ци-снаряды/лучи/AoE не «прицеливаются руками» — первая итерация без гейта легитимно промахивала homing-снаряд (QA 3j поймал сразу).
  - Miss-ветка публикует честное событие Damage=0 (по образцу Dodge/CMB-3): лог «промах» (ожила мёртвая ветка EventLogWindow), цифры «промах» над целью, месть цели включается (стрела просвистела).
