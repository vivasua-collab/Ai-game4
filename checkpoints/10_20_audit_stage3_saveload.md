## 2. Исправления

### FIX-1 (P1) — SaveDataAggregator
- `CurrentFormatVersion = 1` (константа формата).
- `CriticalBlocksV1 = {world, world_time, player, body}`; таблица
  `CriticalBlocksForVersion(version)` — неизвестная версия → null → отказ.
- `ValidateFormat` в `Load()` ДО RestoreState: нет save_meta → отказ;
  version > Current → отказ («обновите игру»); критический блок отсутствует
  → отказ. Отказ = RestoreState НЕ вызывается, домены нетронуты.
- Свойства JsonElement читаются без учёта регистра (CamelCase/PascalCase
  сейвы обоих хендлеров).
- `TryGetSlotMeta` — мета слота для UI (дата записи) без полного рестора.

### FIX-2+3 (P2) — Adapter/Persistence/SaveFileHandler
- `HasSave` → `File.Exists(main.json)` (готовность = файл состояния).
- `GetAllSaves` → только каталоги с main.json (пустые/недописанные не
  выдаются за сейвы).
- `DeleteSave` — операция с try/catch и фактическим результатом
  (true = существовал и удалён; false = не было / I/O-отказ), паритет
  с Modules-хендлером. Void-`Delete(string)` сохранён для остальных вызовов.

### FIX-4 (P2) — WorldDomainResetCoordinator (новый, Entry/Phases)
- Единая точка сброса world-scoped доменов: try/catch на каждый домен,
  ВСЕ получают ResetWorld() (провал не прерывает цикл), ошибки →
  AggregateException (fail-closed), WeaponVisualCatalog.ResetCache() всегда.
- Пользователи: WorldDomainResetPhase (NewGame, фаза 0) и
  GameSession.LoadGame (до RestoreState). Одна семантика для всех
  world-transition.

## 5. Дизайн-решения

1. **Формат без save_meta не поддерживается**: в проекте не существовало
   формата без меты — сейвы v0 не выпускались, поэтому «отсутствие версии =
   отказ» не ломает совместимость (жёстче, чем «считать всё необязательным»).
2. **Отказ формата НЕ вызывает частичный RestoreState**: проверка ДО цикла
   восстановления — при отказе домены нетронуты (провал загрузки не
   должен оставлять «полумир»; fail-closed, зеркально P1-9).
3. **Внутриигровая загрузка** = тот же пайплайн + пересоздание сцены
   (НЕ горячий подмен поверх живых рендеров: смена сетки/локации рендерами
   не покрыта; сцена дешевле и надёжнее).
4. **Меню сейвов в INP-1 стеке** — «окно планирования» с паузой (как
   инвентарь), индикатор паузы показывает «F5·сейвы» (паттерн INP-1-репортов).
5. **Экран смерти не открывает меню сейвов** — гейт DeathScreenShown в
   HandleStickyInput ранним Return (мёртвый не сейвится и не грузится).

## 6. Находки вне зоны (в реестр, НЕ исправлять без директивы)
