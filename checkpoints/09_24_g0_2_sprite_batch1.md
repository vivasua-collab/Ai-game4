## §2. Ключевые решения

1. **Маппинг по file-stem — первичный, id — вторичный.** 150/221 позиций
   манифеста имеют id≠имя файла; генерации называются по README-контракту.
   Без двойного пространства иконки оружия бы не резолвились.
2. **Решение о дефектах — по машинным метрикам, VLM-ревью — advisory.**
   VLM на ×4-листах галлюцинировал «полупрозрачные ореолы» и «провисание
   стоп f1/f3» — пиксельная экспертиза опровергла оба (0 полупрозрачных,
   разброс базовой линии 0). В игровом кадре VLM артефактов тоже не нашёл.
3. **CONFORM вместо REJECT для кадров ≠ манифест.** Рантайм берёт кадры
   из ширины PNG (авторитет файла), манифест — контракт: доводка
   (обрезка/дубль последнего) даёт автоматическую конвергенцию без
   ручной правки.
4. **equipped/ — только DIRECT.** У weapon_hand якорь рукояти G=(16,36),
   у стикеров брони свои якоря — авто-FIT сломал бы крепления; чужая
   геометрия → REJECT с ручной подгонкой.
5. **Dual-режим ANIMQA вместо инверсии.** Сим остаётся регрессионным
   №21 в обоих состояниях каталога (пруфы обеих сторон) — иначе каждый
   раунд с доставкой давал бы ложный FAIL.
