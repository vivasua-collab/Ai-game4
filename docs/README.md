# Документация проекта

> ⚠️ **АРХИВНОЕ ПРЕДУПРЕЖДЕНИЕ** (добавлено 2026-08-26, B6)
>
> **Источник истины — [`docs_v2/`](./docs_v2/)** (engine-agnostic спецификация, синхронизирована с кодом на HEAD).
>
> Папки `docs/docs/` (Unity 6.3 итерация) и `docs_old/` (Phaser итерация) — **исторические архивы**.
> Они содержат концепции и лор, которые могут быть полезны для контекста, но
> **НЕ отражают текущую реализацию** (Godot 4.7.1 + C# + модульная архитектура).
>
> Известные расхождения с кодом в `docs/docs/`:
> - Пути Unity (`Assets/Scripts/...`, `ScriptableObject` вместо runtime-генерации)
> - Устаревшие формулы (напр. `ALGORITHMS.md §15` — 15.15с каст техники, заменён на модель заполнения в `docs_v2/TECHNIQUE_SYSTEM.md §5.3`)
> - `TECHNIQUE_USAGE_REPORT.md` — до Qi-этапов (Stage 0+1 GLM-5.3 не отражены)
> - Местоположение файлов (`Scripts/Modules/*` вместо `src/Modules/*`)
>
> **Перед использованием любого документа из `docs/docs/` или `docs_old/` —
> сверьтесь с эквивалентным документом в `docs_v2/`.** Если актуального аналога нет —
> документ в архиве рассматривается как концептуальный набросок, требующий
> переноса в `docs_v2/` перед внедрением в код.
