## 🎯 Концепция

Система достижений отслеживает прогресс игрока и награждает за выполнение определённых условий. Достижения могут быть:
- **Скрытые** — невидимы до получения
- **Публичные** — видны всегда
- **Секретные** — особые условия, не отображаются даже после получения (до разблокировки)

### Архитектурный принцип

Система достижений — **модуль-наблюдатель** (Hub-and-Spoke):
- Не инжектит сервисы других модулей
- Подписывается на MessagePipe-события:
  - `QiChangedEvent` → отслеживание прорывов
  - `CombatContracts` → отслеживание боевых достижений
  - `NPCContracts` → отслеживание социальных достижений
  - `InventoryContracts` → отслеживание коллекций
- Публикует: `AchievementUnlockedEvent` (для UI и логов)

## 🏗️ Архитектура модуля

```
Modules/Achievement/
├── AchievementModule.cs           # Инициализация модуля
├── AchievementModuleServices.cs   # DI-регистрация
├── AchievementLifetimeScope.cs    # VContainer scope
├── AchievementService.cs          # Главный сервис
├── AchievementTracker.cs          # Отслеживание условий
├── AchievementConfig.cs           # Настройки (ScriptableObject)
└── Data/
    ├── AchievementData.cs         # Структура достижения
    └── AchievementSaveData.cs     # Данные сохранения
```

### MessagePipe-интеграция

**Подписки (входящие события):**
- `ISubscriber<QiChangedEvent>` — отслеживание прорывов
- `ISubscriber<CombatEvent>` — отслеживание боёв
- `ISubscriber<NPCInteractedEvent>` — социальные достижения
- `ISubscriber<InventoryChangedEvent>` — коллекции

**Публикации (исходящие события):**
- `IPublisher<AchievementUnlockedEvent>` — уведомление UI
- `IPublisher<AchievementProgressEvent>` — обновление прогресса

### DI-регистрация

```
AchievementLifetimeScope : ModuleLifetimeScope
├── IAchievementService → AchievementService.AsSelf()
├── AchievementTracker
├── AchievementConfig (из Resources)
└── Подписки MessagePipe (авто через ISubscriber<T>)
```

## 💾 Сохранение прогресса

Через `ISaveable` интерфейс (как все модули):

```
AchievementSaveData:
├── unlockedAchievements: List<string>    # ID разблокированных
└── progressData: Dictionary<string, int> # текущий прогресс по ID
```

Интеграция с `SaveModule` через MessagePipe (`SaveRequestedEvent` / `SaveCompletedEvent`).
