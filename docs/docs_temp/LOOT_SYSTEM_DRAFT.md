## ⚠️ Назначение документа

> Этот документ описывает **систему полного лута** при убийстве NPC:
> как инвентарь NPC становится доступным игроку, как работает
> визуальное отображение (кукла NPC + рюкзак), и механика переноса предметов.
>
> Инвентарь NPC — **такой же**, как у игрока. Те же модели данных,
> те же слоты экипировки, та же система рюкзака.

## 📋 Обзор

При убийстве NPC его инвентарь **полностью** становится доступным для лута.
Игрок видит «куклу» убитого NPC со всей надетой экипировкой и рюкзак с содержимым.
Предметы можно забирать по одному или перемещать в свой инвентарь.

## 1️⃣ Принципы системы

### 1.1 Полный лут

При смерти NPC **все** его предметы доступны для лута:
- ✅ Экипированные предметы (оружие, броня, зарядник)
- ✅ Содержимое рюкзака (расходники, материалы, хлам)
- ✅ Расходники из пояса быстрого доступа
- ✅ Духовные камни (если были)
- ❌ Духовное хранилище NPC — **НЕ доступно** (уходит с душой)
- ❌ Техники — **НЕ лутаются** (это знания души, не предметы)
- ❌ Кольца хранения — **НЕ лутаются** содержимое (уходит в складку),
    само кольцо — лутается как предмет

### 1.2 Одинаковый инвентарь

Инвентарь NPC использует **ту же модель данных**, что и инвентарь игрока:
- `InventoryController` — рюкзак (строчная модель: список + масса/объём)
- `EquipmentController` — слоты экипировки (1 слот = 1 предмет)
- Предметы: `Item` с weight, volume, rarity, grade и т.д.

> **Разница:** У NPC нет духовного хранилища и колец хранения (или они
> недоступны при луте). Нет пояса быстрого доступа для _использования_
> (но предметы в поясе — лутаются).

### 1.3 Состояние предметов

Предметы с трупа NPC могут быть повреждены:
- Экипировка: прочность снижена на 10-30% (от боевых повреждений)
- Расходники: без изменений
- Оружие: прочность снижена на 5-20%

> **TBD:** Формула снижения прочности в зависимости от полученного урона.

### 2.2 Кукла NPC (Body Doll)

Кукла NPC отображается **с надетыми на него предметами**:
- Каждый слот экипировки показывает иконку надетого предмета
- Цвет рамки = редкость предмета (как в инвентаре игрока)
- Пустой слот = серый, без иконки

**Взаимодействие с куклой:**
- **Левый клик** на надетый предмет → перенести в инвентарь игрока (снять с NPC)
- **Правый клик** на надетый предмет → контекстное меню:
  - «Забрать» — перенести в инвентарь игрока
  - «Подробнее» — показать tooltip предмета
  - «Надеть на себя» — если требования выполняются, экипировать на игрока

### 2.3 Рюкзак NPC

Рюкзак NPC отображается как **список предметов** (строчная модель):
- Каждый предмет: иконка + название + количество + вес
- Цвет текста/рамки = редкость

**Взаимодействие с рюкзаком NPC:**
- **Левый клик** → перенести 1 штуку в инвентарь игрока
- **Shift+клик** → перенести весь стек
- **Правый клик** → контекстное меню:
  - «Забрать» — перенести в инвентарь
  - «Забрать все этого типа» — весь стек
  - «Подробнее» — tooltip

### 2.4 Вложенный рюкзак (правый клик на сумку)

> **Идея:** Если у NPC в рюкзаке есть **контейнер** (сумка, мешок, сундук),
> при нажатии **правой кнопкой** на сумку открывается **новое вложенное окно**,
> с которого можно перенести предметы в свой инвентарь.

```
┌─────────────────────────────────────────────────────────────────────┐
│  РЮКЗАК NPC                                                         │
│                                                                     │
│  [Пилюля здоровья]  x2                                              │
│  [Ци-настойка]       x1                                              │
│  [Кожаная сумка]     x1  ◀──── ПРАВЫЙ КЛИК                         │
│  [Железная руда]    x15                                              │
│                                                                     │
│  ┌──────────────────────────────────────────────────────────┐       │
│  │  📦 Содержимое: Кожаная сумка                             │       │
│  │                                                            │       │
│  │  [Редкая пилюля]     x1    ◀──── Забрать                 │       │
│  │  [Осколок камня Ци]  x3    ◀──── Забрать                 │       │
│  │  [Свиток техники]    x1    ◀──── Забрать                 │       │
│  │                                                            │       │
│  │  [Забрать всё из сумки]                                    │       │
│  └──────────────────────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────────────────────┘
```

**Механика вложенного окна:**
- Открывается по правому клику на контейнер в рюкзаке NPC
- Показывает содержимое контейнера
- Каждый предмет можно забрать по клику
- «Забрать всё из сумки» — перенести всё содержимое в инвентарь игрока
- Сам контейнер (сумка) можно забрать отдельно (с содержимым или пустой)

## 3️⃣ Механика переноса предметов

### 3.1 Проверка вместимости

Перед переносом предмета из лута в инвентарь игрока:

```
canPickUp = playerInventory.CanAddItem(item)

// Проверки:
// 1. Вес: currentWeight + item.weight ≤ maxCarryWeight
// 2. Объём: currentVolume + item.volume ≤ maxCarryVolume
// 3. Слоты: если рюкзак полон — нельзя добавить (для сеточной модели)
```

Если предмет **не влезает**:
- Показать красную подсветку
- Tooltip: «Слишком тяжело» или «Недостаточно места»
- Предмет остаётся в луте

### 3.2 Порядок переноса

При «Забрать всё»:
1. Экипировка (оружие → броня → аксессуары) — в рюкзак игрока
2. Духовные камни — в рюкзак игрока
3. Расходники — в рюкзак игрока
4. Материалы/хлам — в рюкзак игрока
5. Предметы, не влезающие по весу/объёму — остаются в луте

### 3.3 Авто-стак

При переносе расходников/материалов:
- Если в инвентаре игрока уже есть такой же предмет → увеличить стек
- Если стек полон → создать новый стек
- Если новый стек не влезает → остаётся в луте

## 4️⃣ Жизненный цикл лута

### 4.1 Создание LootEntity

При смерти NPC:

```
1. NPCController.OnDeath()
2. Создать LootEntity на месте смерти
3. Перенести инвентарь NPC в LootEntity:
   ├── EquipmentController → LootEntity.equipmentSlots
   ├── InventoryController → LootEntity.backpackItems
   └── QiStones → LootEntity.qiStones
4. Применить деградацию прочности (от боевых повреждений)
5. Опубликовать NPCLootCreatedEvent
```

### 4.2 Структура данных LootEntity

```csharp
class LootEntity
{
    string Id;                           // Уникальный ID лута
    string SourceNpcId;                  // ID убитого NPC
    string SourceNpcName;                // Имя NPC для UI
    int SourceNpcLevel;                  // Уровень NPC для UI

    // Экипировка (с куклы)
    Dictionary<EquipmentSlot, Item> EquipmentSlots;

    // Рюкзак (содержимое)
    List<Item> BackpackItems;
    float TotalWeight;                   // Общий вес рюкзака
    float MaxWeight;                     // Макс. вес рюкзака NPC

    // Духовные камни
    List<Item> QiStones;

    // Таймер исчезновения
    float RemainingTime;                 // До исчезновения лута
}
```

### 4.3 Таймер исчезновения лута

| Тип лута | Время до исчезновения |
|----------|----------------------|
| Обычный NPC | 5 игровых минут |
| Уникальный/сюжетный NPC | 30 игровых минут |
| Босс | 15 игровых минут |

> **TBD:** Точные значения таймеров. Возможна настройка по локации.

### 4.4 Взаимодействие с лутом

Игрок может взаимодействовать с LootEntity:
1. **Подойти** к трупу (радиус взаимодействия 1.5м)
2. **Нажать E** или **кликнуть** на труп → открыть окно лута
3. Забирать предметы через UI
4. Закрыть окно → лут остаётся (можно вернуться)

## 5️⃣ Особые случаи

### 5.1 Негуманоидные NPC (монстры)

Для монстров (quadruped, arthropod, и т.д.):
- **Кукла не отображается** — вместо неё показываются «Части тела» как предметы
- **Естественное оружие/броня** — можно добыть как материалы (шкура, когти, яд)
- **Рюкзак** — если есть (редко у монстров)

```
┌─────────────────────────────────────────────────────────────┐
│  🎁 Лут: [Волк] L3                               [✕]       │
│                                                               │
│  ┌──────────────────────────────────────────────────────────┐│
│  │  ЧАСТИ ТЕЛА:                                             ││
│  │  [Шкура волка]        x1  3.0 кг  (Материал, T2)        ││
│  │  [Когти волка]        x4  0.5 кг  (Материал, T1)        ││
│  │  [Клыки волка]        x2  0.3 кг  (Материал, T1)        ││
│  │  [Ядовитая железа]    x1  0.2 кг  (Материал, T2) 5%     ││
│  └──────────────────────────────────────────────────────────┘│
│                                                               │
│  ┌──────────────────────────────────────────────────────────┐│
│  │  РЮКЗАК: (пусто)                                         ││
│  └──────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

### 5.2 Spirit (бесплотные)

У духов нет физического тела и экипировки:
- **Кукла не отображается**
- **Ядро духа** — можно добыть как материал (если есть навык)
- **Ци-остатки** — рассеиваются или поглощаются
- Редко: артефакты, которые дух «носил» энергетически

### 5.3 Construct (големы)

У големов тело = экипировка:
- **Части конструкт-тела** — можно добыть как материалы
- **Встроенное оружие** — можно извлечь (с пониженной прочностью)
- **Ядро конструкта** — ценный материал

## 6️⃣ Связь с системой инвентаря игрока

### 6.1 Окно лута + инвентарь игрока

При открытии лута окно инвентаря игрока **также открывается**,
располагаясь рядом с окном лута:

```
┌───────────────────────┐  ┌───────────────────────┐
│  ЛУТ NPC              │  │  ВАШ ИНВЕНТАРЬ         │
│                       │  │                       │
│  [Кукла NPC]          │  │  [Кукла игрока]       │
│  [Рюкзак NPC]         │  │  [Рюкзак игрока]      │
│                       │  │                       │
│  [Забрать всё]        │  │                       │
└───────────────────────┘  └───────────────────────┘
```

Это позволяет:
- Перетаскивать предметы из лута → в инвентарь (drag & drop)
- Перетаскивать из инвентаря → в лут (выбросить/оставить)
- Сравнивать предметы (tooltip рядом)

### 6.2 Drag & Drop между окнами

- Перетаскивание из лута → инвентарь игрока: забрать
- Перетаскивание из инвентаря → лут: выбросить на труп
- Перетаскивание на куклу игрока: экипировать (если требования выполняются)
- Подсветка валидных/невалидных слотов — как в основном инвентаре
