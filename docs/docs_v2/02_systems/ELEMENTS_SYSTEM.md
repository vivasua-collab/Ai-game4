# Система стихий (Elements System)

> **Назначение:** Документ описывает систему стихий (элементов) — единый источник истины о стихиях в проекте. Включает перечень, эффекты по типам техник, Transcendent-эффекты, особое состояние Ци (яд). Документ engine-agnostic: концепции, данные, таблицы — без привязки к движку.

**Связанные документы:** `02_systems/TECHNIQUE_SYSTEM.md`, `02_systems/COMBAT_SYSTEM.md`, `02_systems/FORMATION_SYSTEM.md`, `08_content/LORE_SYSTEM.md`.

## 3. Яд (Poison) — особое состояние Ци

### 3.1. Ключевые свойства

- Не имеет противоположностей (не участвует в цикле стихий).
- Реализуется через `technique.type = poison`.
- Единственное стихийное взаимодействие: **`fire → poison ×1.2`** (выжигание токсинов).

### 3.2. Механика яда

**Несколько дебаффов по Grade:**

| Grade | Дебафф 1 | Дебафф 2 | Дебафф 3 | Дебафф 4 |
|-------|----------|----------|----------|----------|
| Common | DoT (малый) | — | — | — |
| Refined | DoT | Замедление | — | — |
| Perfect | DoT (сильный) | Замедление | Слабость | — |
| Transcendent | DoT (max) | Замедление | Слабость+ | Блок регена |

**Типы дебаффов яда:**

| Дебафф | Эффект |
|--------|--------|
| DoT | Урон по времени (body или qi) |
| Замедление | −% скорости |
| Слабость | −% урона/защиты |
| Блок регена | Нет восстановления HP/Ци |
| Паралич | Невозможность действия |
| Некроз | Постоянная потеря HP |

**Способы доставки яда:**

- `ingestion` — проглатывание.
- `contact` — контакт.
- `inhalation` — вдыхание.
- `injection` — через оружие/жало.
- `technique` — через технику яда.

### 3.3. Отравленное оружие

- Можно нанести яд на оружие (`poisonCoating`).
- Эффект при ударе (`injection`).
- Ограниченное количество ударов (1–10).

### 3.4. Применение яда

- **Техники:** тип `poison` — яд доступен ТОЛЬКО для техник этого типа.
- **Оружие:** `poisonCoating` — отравленное покрытие.
- **Броня:** `poisonResistance` включён в карту сопротивлений.
- **NPC:** ядовитые существа имеют врождённое состояние `poison`.

## 6. Нейтральный — особые случаи

### 6.1. Cultivation

> Все техники культивации — `neutral`. Культивация работает с чистым Ци без стихийного окраса.

### 6.2. Healing

> Все техники исцеления — `neutral`. Исцеление — базовая техника, эффективность зависит только от Grade и уровня.

## 8. Применение стихий

### 8.1. Техники

Каждая техника имеет **ровно одну** стихию согласно таблице ограничений (см. §4).

> **Правило: Одна техника = одна стихия.** Комбинирование стихий в одной технике НЕ предусмотрено.

### 8.2. Оружие

Оружие может наносить урон определённой стихией.

**Структура данных оружия:**
- `elementalDamage.element` — стихия урона.
- `elementalDamage.value` — величина урона.
- `poisonCoating` — отравленное покрытие (яд — состояние Ци, не стихия).

### 8.3. Броня

Броня может давать сопротивление к стихиям и ядам.

**Структура данных брони:**
- `elementalResistance` — карта сопротивлений по стихиям.
- `poisonResistance` включён в карту как отдельная запись (яд — не стихия).

### 8.4. NPC

NPC могут иметь врождённую стихию. Ядовитые существа используют состояние `poison`.

**Структура данных NPC:**
- `innateElement` — врождённая стихия (из 8 элементов).
- `poisonState` — состояние яда (для ядовитых существ).

### 8.5. Формации

Формации (магические массивы) могут иметь стихийный окрас, влияющий на тип эффектов в зоне формации. Подробности — в `02_systems/FORMATION_SYSTEM.md`.

## 9. Важные исключения

### 9.1. Камни Ци — БЕЗ стихии

> **Камни Ци НЕ имеют стихийного окраса.**
>
> Это чистая энергия, которую практик может преобразовать в любую стихию через технику.

```
QiStone:
  capacity:  long   // объём Ци
  quality:   float  // качество
  // НЕТ поля element
```

---

## 10. Структура данных

```
ElementData (ресурс данных):
  id:           string          // "fire", "water", ...
  displayName:  string
  emoji:        string
  color:        Color           // для UI/визуалов
  character:    string          // описание характера
  domain:       string          // описание домена

ElementResistance (карта сопротивлений):
  fire:      float  // 0.0..1.0
  water:     float
  earth:     float
  air:       float
  lightning: float
  void:      float
  light:     float
  neutral:   float
  poison:    float  // отдельная запись (яд — не стихия)
```

> Сопротивления хранятся как `float` (0.0 = 0%, 1.0 = 100%) для брони, щитов, природных свойств видов.

---

## 11. Производительность

- Lookup по стихии — O(1) через enum (8 значений + 1 для яда).
- `elementalResistance` хранится как массив `float[9]`, не словарь — zero-GC, cache-friendly.
- All эффекты стихий применяются в СЛОЯХ 1, 7 (pierce), 10 (consequences) боевого конвейера. См. `02_systems/COMBAT_SYSTEM.md`.
