# Система Ци (Qi System)

> **Назначение:** Документ описывает систему Ци — основную энергию мира культивации. Включает ядро практика, меридианы, проводимость, источники Ци (микроядро, медитация, камни Ци, зарядники), буфер Ци как защиту и поглощение из окружения. Документ engine-agnostic: формулы и данные, без привязки к движку.

**Связанные документы:** `02_systems/BREAKTHROUGH_MODELS.md`, `02_systems/TECHNIQUE_SYSTEM.md`, `02_systems/COMBAT_SYSTEM.md`, `06_player/MORTAL_DEVELOPMENT.md`, `03_world/TIME_SYSTEM.md`.

---

## 1. Обзор

Ци — основная энергия мира культивации. Система Ци управляет накоплением, расходованием и использованием этой энергии.

### 1.1. Свойства Ци

1. **Квантованность** — Ци неделима, минимальная единица = 1.
2. **Тип данных — `long`** (не `float`). На L9 `effectiveQi` достигает ~524 млн — `long` исключает потерю точности при накоплении и операциях.
3. **Два состояния:** Спокойная и Хаотичная.
4. **Агрегатные состояния:**
   - **Газ** — в окружающей среде (плотность в ед/м³).
   - **Твёрдое тело** — в кристаллах (камни духа).
   - **Жидкость** — в теле практиков (меридианы и ядро).
   - **Плазма** — в техниках и массивах.

### 1.2. Плотность Ци

```
qiDensity = 2^(cultivationLevel - 1)
```

Геометрический рост ×2 за каждый уровень культивации. Эта плотность встроена в формулу `capacity` техник и в формулу `effectiveQi` ядра.

## 3. Ядро практика

### 3.1. Ёмкость ядра (coreCapacity)

```
coreCapacity = 1000 × 1.1^totalSubLevels × qualityMultiplier
```

Где:
- `baseCapacity = 1000` (L1.0).
- `totalSubLevels = (level - 1) × 10 + subLevel` (например, L3.5 = 25).
- `qualityMultiplier` — множитель качества ядра (зависит от расы и перков).

### 3.2. Таблица ёмкости по уровням

| Уровень | totalSubLevels | coreCapacity |
|---------|----------------|--------------|
| L1.0 | 0 | 1,000 |
| L2.0 | 10 | 2,594 |
| L3.0 | 20 | 6,727 |
| L4.0 | 30 | 17,450 |
| L5.0 | 40 | 45,260 |
| L6.0 | 50 | 117,390 |
| L7.0 | 60 | 304,480 |
| L8.0 | 70 | 789,750 |
| L9.0 | 80 | 2,048,400 |

### 3.3. Эффективное Ци (effectiveQi)

```
effectiveQi = coreCapacity × qiDensity
```

| Уровень | coreCapacity | qiDensity | effectiveQi |
|---------|--------------|-----------|-------------|
| L1.0 | 1,000 | 1 | 1,000 |
| L2.0 | 2,594 | 2 | 5,188 |
| L3.0 | 6,727 | 4 | 26,908 |
| L4.0 | 17,450 | 8 | 139,600 |
| L5.0 | 45,260 | 16 | 724,160 |
| L6.0 | 117,390 | 32 | 3,756,480 |
| L7.0 | 304,480 | 64 | 19,486,720 |
| L8.0 | 789,750 | 128 | 101,088,000 |
| **L9.0** | **2,048,400** | **256** | **524,390,400 (~524M)** |

> **Критично:** Все значения Ци хранятся как `long` (64-битное целое со знаком), а не `float`. Это исключает потерю точности при значениях до ~524M и выше.

### 3.4. Стартовый объём ядра

| Раса | Диапазон |
|------|----------|
| Люди | 100 – 2,000 |
| Древние расы | 100 – 100,000 |
| Монстры | 100 – 10,000 |

## 4. Система меридиан

### 4.1. Структура меридиан

1. **Ядро** — корень системы меридиан.
2. **Основной ствол** — определяет проводимость.
3. **Ветви** — по телу практика.
4. **Узлы вывода** — точки выхода Ци.

> Концепция «буфера меридиан» (рабочий буфер) удалена как устаревшая. Меридианы — каналы передачи Ци, не хранилища. Проводимость определяет только скорость прохождения Ци.

### 4.2. Проводимость

**Базовая формула при становлении практиком:**

```
conductivity = coreCapacity / 360 секунд
```

**Расширенная формула (для NPC, учитывает возраст):**

```
finalConductivity = baseConductivity × conductivityGrowthMultiplier × (1 + perkBonuses)

Где:
  baseConductivity = coreCapacity / 360
  conductivityGrowthMultiplier = 1.0 + 0.001 × effectiveAge
  effectiveAge = chronologicalAge × levelGrowthFactor(level)
  levelGrowthFactor:
    L0: 1.0, L1: 1.2, L2: 1.5, L3: 2.0, L4: 3.0,
    L5: 5.0, L6: 8.0, L7+: 12.0
```

> Простая формула `baseConductivity × (1 + conductivityBonus)` применяется для игрока. Для NPC используется расширенная формула с `growthMultiplier`, т.к. NPC прожил много лет и его проводимость должна отражать естественный рост меридиан.

### 4.3. Развитие проводимости

> Проводимость МОЖНО развивать через **перки** (постоянно). Временные баффы проводимости (`ConductivityBoost`) — УДАЛЕНЫ. Для увеличения поглощения Ци используйте формации (увеличивают `environmentMult`).

| Источник бонуса | Тип | Величина | Что модифицирует |
|-----------------|-----|----------|------------------|
| Врождённый перк «Золотое качество тела» | Постоянный | +30% | `finalConductivity` |
| Приобретённый перк «Закалка меридиан» | Постоянный | +15% | `finalConductivity` |
| Приобретённый перк «Небесные каналы» | Постоянный | +20% | `finalConductivity` |
| Формация «Круг поглощения» | Локальный | +25% | `environmentMult` (НЕ проводимость!) |
| Формация «Священная гора» | Локальный | ×10 | `environmentMult` |

> **Различие:** Перки увеличивают `finalConductivity` (базовое свойство меридиан). Формации увеличивают `environmentMult` (концентрация Ци в области). Оба увеличивают поглощение, но через разные параметры.

### 4.4. Пример расчёта

```
Базовая проводимость L3.0: 6727 / 360 = 18.7 Ци/сек

С врождённым перком «Золотое качество тела» (+30%):
finalConductivity = 18.7 × 1.30 = 24.3 Ци/сек

С дополнительным перком «Закалка меридиан» (+15%):
finalConductivity = 18.7 × 1.45 = 27.1 Ци/сек
```

### 4.5. Ограничение поглощения

**Правило:** Поглощение Ци НЕ может превышать проводимость меридиан!

```
absorbedQi = min(
    meditationTime × finalConductivity × environmentMult,
    availableQiInEnvironment
)
```

Перки на «+скорость поглощения» эффективны только в пределах проводимости.

## 5. Источники Ци — детали

### 5.1. Микро-ядро (только L1+)

- Генерация: **10% от `coreCapacity` в сутки**.
- Это КОНСТАНТА для всех уровней, НЕ модифицируется баффами.
- Активируется ТОЛЬКО при пробуждении (L1+).
- У смертных (L0) — дремлющее ядро, Ци поступает через медленное поглощение из среды. См. `06_player/MORTAL_DEVELOPMENT.md`.

### 5.2. Медитация

```
qiFromMeditation = meditationTime × finalConductivity × environmentMult
```

Ограничение: `qiFromMeditation ≤ availableQiInEnvironment`.

**Плотность Ци в зонах (из лора):**

| Зона | ρ_окр (ед/м³) |
|------|---------------|
| Внутреннее кольцо | 500–1000+ |
| Среднее кольцо | 200–500 |
| Внешнее кольцо | 100–200 |
| Приграничные | 20–100 |

### 5.3. Радиус сферы поглощения

Практик собирает Ци из сферической зоны радиуса `R` вокруг себя. Радиус растёт с уровнем:

```
R = R_base × (1 + 0.2 × (2^(level/3) - 1))
```

Где `R_base = 10 метров` (базовый радиус).

| Уровень | R (м) | Объём зоны (м³) | Рост относительно L1 |
|---------|-------|-----------------|---------------------|
| L1 | 10 | 4,189 | ×1.0 |
| L2 | 11 | 5,377 | ×1.3 |
| L3 | 12 | 7,238 | ×1.7 |
| L4 | 13 | 9,203 | ×2.2 |
| L5 | 15 | 14,137 | ×3.4 |
| L6 | 16 | 17,157 | ×4.1 |
| L7 | 18 | 24,429 | ×5.8 |
| L8 | 20 | 33,510 | ×8.0 |
| L9 | 22 | 44,602 | ×10.6 |

**Запас Ци в зоне:** `Qi_zone = ρ_окр × (4/3) × π × R³`.

**Время восстановления зоны до 90%:**

```
t_recover = 0.9 × V_zone × ρ_окр / (G × S_zone)
где S_zone = 4 × π × R²,  G = 10 ед/ч·м² (минимальная скорость истечения Ци из недр)
```

| Уровень | R (м) | S_zone (м²) | Время восстановления |
|---------|-------|-------------|---------------------|
| L1 | 10 | 1,257 | ~450 ч (~19 дней) |
| L5 | 15 | 2,827 | ~380 ч (~16 дней) |
| L9 | 22 | 6,082 | ~350 ч (~15 дней) |

> После поглощения Ци из зоны `ρ_окр → 0`, и нужно ждать восстановления из недр.

### 5.4. Камни Ци (Духовные Камни)

| Тип | Ци | Редкость |
|-----|-----|----------|
| Осколок | 1,000 | common |
| Фрагмент | 10,000 | uncommon |
| Камень | 100,000 | rare |
| Кристалл | 1,000,000 | epic |
| Сердце | 10,000,000 | legendary |
| Ядро | 100,000,000 | mythic |

#### Испарение камней в замкнутом пространстве

**Переменные:**
- `ρ_крист = 1.024×10⁹ ед/м³` — плотность кристалла.
- `k = 0.001` — коэффициент равновесия.
- `ρ_равн = k × ρ_крист` — равновесная плотность.
- `ρ_окр` — текущая плотность Ци в помещении.
- `S_крист` — площадь поверхности кристалла.
- `α` — коэффициент испарения.

```
Q_испар = α × S_крист × (ρ_равн - ρ_окр)
```

> Камни Ци НЕ имеют стихийного окраса — это чистая энергия, которую практик преобразует в любую стихию через технику.

### 5.5. Зарядники Ци (Charger)

Зарядник — ограничитель скорости передачи Ци. Проводимость зарядника НЕ зависит от практика.

```
effectiveRate = min(charger.conductivity, practitioner.conductivity)
```

Практик должен подбирать зарядник под свою проводимость.

| Грейд зарядника | Проводимость | Буфер | Слоты | Улучшений |
|-----------------|--------------|-------|-------|-----------|
| Damaged | ×0.5 | ×0.5 | 1–2 | 1 |
| Common | ×1.0 | ×1.0 | 1–3 | 3 |
| Refined | ×1.3 | ×1.3 | 2–5 | 5 |
| Perfect | ×1.6 | ×1.6 | 3–8 | 7 |
| Transcendent | ×2.0 | ×2.0 | 4–12 | 9 |

> Подробности — в `02_systems/CHARGER_SYSTEM.md`.

## 6. Буфер Ци как защита

> Подробно — в `02_systems/COMBAT_SYSTEM.md` §5 и `09_workflow/ALGORITHMS.md` §2.

Ци защищает практика от ЛЮБОГО урона (техники Ци и физического), даже во сне.

**Сводка:**

| Защита | Тип урона | Поглощение | Стоимость | Пробитие |
|--------|-----------|------------|-----------|----------|
| Сырая Ци | Qi-техника | 90% | 3 Ци / 1 урон | 10% всегда |
| Сырая Ци | Физический | 80% | 5 Ци / 1 урон | 20% всегда |
| Щит | Qi-техника | 100% | 1 Ци / 1 урон | 0% |
| Щит | Физический | 100% | 2 Ци / 1 урон | 0% |

## 7. Эффективность техник

### 7.1. Формула

```
эффективность = потрачено_Ци × качество_Ци
```

### 7.2. Пример

- Техника требует 100 единиц Ци.
- Практик 3-го уровня (плотность = 4).
- Эффективность: 100 × 4 = 400 базовых единиц.

> Высококачественная Ци делает технику сильнее без увеличения объёма затрат.

## 8. Производительность

- Регенерация Ци обрабатывается **батчами каждые 10 тиков** (QiTickProcessor), а не каждый тик.
- При `MaxActiveNPCs = 100`: Qi-regen ~0.5 ms / batch tick.
- `long`-арифметика — cheap на современном CPU (64-битные регистры), zero-GC.
- События (изменение Ци, прорыв) публикуются через шину событий как `readonly struct` (zero-GC).

## 9. Структура данных

```
QiData:
  currentQi:     long    // текущее Ци
  coreCapacity:  long    // ёмкость ядра (макс)
  density:       int     // 2^(level-1)
  quality:       float   // множитель качества ядра
  conductivity:  float   // finalConductivity (ед/сек)
  isAwakened:    bool    // true у L1+ (микроядро активно)
  absorptionRadius: float // R в метрах
```

> Все операции над Ци выполняются через эти поля в pure-C# модуле `QiModule`. См. `01_architecture/MODULE_STRUCTURE.md`.
