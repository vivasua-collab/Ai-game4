# Система лора (Lore System)

> **Назначение:** Движко-независимая спецификация лора мира: принципы, Ци, культивация, мир, социальная структура, техники. Описывает законы мира, по которым работают все игровые системы.
>
> **Связанные документы:** `START_LORE.md`, `06_player/JOURNAL_SYSTEM.md`, `02_systems/QI_SYSTEM.md`, `02_systems/ELEMENTS_SYSTEM.md`, `02_systems/BREAKTHROUGH_MODELS.md`, `04_entities/FACTION_SYSTEM.md`.

---

## 1. Принципы мира

### 1.1. Основа

- **Правила мира незыблемы** — не меняются со временем.
- **Мир строго следует установленным законам** — исключения только для Повелителя (пользователя в режиме «творца»).
- **Время течёт плавно** — ничего не происходит мгновенно.
- **Сохранение энергии и материи** строго соблюдается — ничто не берётся из ниоткуда и не исчезает в никуда.

### 1.2. Дискретизация времени

Для расчётов используется дискретизация времени с шагом 0,1 секунды (10 тиков в секунду). Все процессы требуют времени. Временные интервалы стандартные: секунды, минуты, часы, дни.

> См. `03_world/TIME_SYSTEM.md` для деталей: 1 тик = 1 минута игрового времени.

## 2. Ци

### 2.1. Свойства

- Мир наполнен **Ци** — основным параметром энергии.
- Ци — виртуальные частицы.
- Ци **квантованная**, не дробная. Запрещено использовать неполные (дробные) единицы Ци.
- Квант Ци имеет **спин**: Спокойный или Хаотичный.
- Объём пространства может содержать обе формы Ци в разных пропорциях.
- Других типов Ци нет, не существует и не может быть создано.

### 2.2. Состояния Ци

| Состояние | Описание | Период полураспада |
|-----------|----------|---------------------|
| Спокойная Ци | Стабильная, используется в культивации | — |
| Хаотичная Ци | Нестабильная, возникает при техниках/взрывах | 24 часа |

### 2.3. Агрегатные состояния Ци

| Состояние | Где встречается |
|-----------|-----------------|
| Газ | Окружающая среда (атмосферное Ци) |
| Твёрдое тело | Кристаллы Ци (духовные камни) |
| Жидкость | Тело практиков (меридианы, ядро) |
| Плазма | Техники и массивы (при выпуске) |

### 2.4. Плотность Ци

> Подробно — в `09_workflow/ALGORITHMS.md` §3.3 «Плотность Ци».

`qiDensity = 2^(cultivationLevel − 1)` — растёт ×2 за уровень культивации.

## 8. Техники Ци

### 8.1. Принципы

- Любая техника требует **минимального объёма Ци**.
- Эффективность пропорциональна `объём × качество Ци`.
- При выпуске Ци переходит в **плазменное** состояние.

### 8.2. Формула эффективности

```
эффективность = потрачено_Ци × качество_Ци
```

> Качество Ци = `qiDensity = 2^(cultivationLevel − 1)`.

### 8.3. Типы техник (11)

`melee`, `ranged`, `defense`, `healing`, `cultivation`, `support`, `movement`, `poison`, `curse`, `sensory`, `formation`.

> См. `02_systems/TECHNIQUE_SYSTEM.md` для деталей.

## 9. Энергия и материя

### 9.1. Законы сохранения

- **Сохранение энергии:** Ци не берётся из ниоткуда. Любая техника тратит Ци практика или окружающей среды.
- **Сохранение материи:** Предметы не исчезают. Сломанное оружие = материал. Убитый NPC = труп с инвентарём (см. `06_player/INVENTORY_SYSTEM.md` §13).

### 9.2. Источники Ци

| Источник | Описание |
|----------|----------|
| Атмосферное Ци | Пассивное поглощение при медитации |
| Духовные камни | «Твёрдое» Ци, расходник |
| Поглощение | Из других существ (тёмные практики) |
| Формации | Накопление через массивы |

| Бессмертные | Уровень 10, покинули мир. |

### 10.2. Тело практика

> Подробно — в `02_systems/BODY_SYSTEM.md`.

Состоит из частей: голова, торс (с сердцем), руки (левая/правая), кисти (левая/правая), ноги (левая/правая), ступни (левая/правая). Каждая часть имеет:
- `redHP` — функциональное здоровье (70% урона).
- `blackHP` — структурное здоровье (30% урона).

При `redHP ≤ 0` — паралич части. При `blackHP ≤ 0` — отрубание.

## 12. Магия vs Культивация

В мире нет «магии» как отдельного явления. Все сверхъестественные эффекты — это **Ци**, управляющееся через **техники** и **формации**. Меч, наносящий огненный урон, — это не «магический меч», а меч, чей материал (Spirit Iron) проводит Ци стихии Огонь, а зачарование активирует эту проводимость.

> Это важно для единства мира: любая игровая механика должна объясняться через Ци, техники и материалы. Не вводить «магические» исключения.

## 13. Лорные записи

### 13.1. Структура лорной записи

> Подробно — в `06_player/JOURNAL_SYSTEM.md` §4 (LoreEntry).

| Поле | Описание |
|------|----------|
| `era` | Эпоха (из §11) |
| `keyFigures` | Ключевые фигуры |
| `locations` | Упомянутые локации |
| `events` | Связанные события |
| `hiddenText` | Текст, открывающийся при условии |
| `unlockCondition` | Условие открытия скрытого текста |

### 13.2. Точки открытия лора

| Триггер | Пример |
|---------|--------|
| Свиток лора | Предмет `technique_scroll` с лорным текстом |
| Артефакт | Предмет `artifact` с встроенным лором |
| Ключевой диалог | NPC раскрывает лор при достижении отношения |
| Локация | Посещение особой локации (алтарь, руины) |
| Прорыв уровня | При прорыве на новый уровень культивации открывается лор об этом уровне |
