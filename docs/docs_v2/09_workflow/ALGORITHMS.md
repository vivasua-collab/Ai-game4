## 0. Обзор

Документ описывает ключевые алгоритмы и формулы проекта. Все числовые значения и расчёты в коде должны точно соответствовать этому документу.

**Определение тика:** 1 тик = 1 минута игрового времени. Скорость тиков (сколько тиков в реальную секунду) регулируется TimeService и настраивается игроком (пауза/норма/ускорение).

**Жёсткие капы (hard caps) в `GameConstants`:**
- `MAX_STAT_VALUE = 1000` (максимальное значение характеристики)
- `MAX_CULTIVATION_LEVEL = 9` (максимальный уровень культивации, 10 = Вознесение)
- `MAX_EQUIPMENT_GRADE = 5` (максимальный грейд экипировки)

## 1. Подавление уровнем (Level Suppression)

### 1.1. Проблема

Qi buffer с поглощением 90% позволяет практику L1 наносить урон практике L8. Нужен механизм подавления.

### 1.2. Решение

Множитель подавления на основе разницы уровней культивации.

### 1.3. Таблица подавления

| Разница уровней | Normal | Technique | Ultimate |
|-----------------|--------|-----------|----------|
| 0 | ×1.0 | ×1.0 | ×1.0 |
| 1 | ×0.5 | ×0.75 | ×1.0 |
| 2 | ×0.1 | ×0.25 | ×0.5 |
| 3 | ×0.0 | ×0.05 | ×0.25 |
| 4 | ×0.0 | ×0.0 | ×0.1 |
| 5+ | ×0.0 | ×0.0 | ×0.0 |

### 1.4. Формула

```
effectiveAttackerLevel = max(attackerLevel, techniqueLevel)  // для техник
levelDiff = max(0, defenderLevel - effectiveAttackerLevel)
suppression = SUPPRESSION_TABLE[min(5, levelDiff)][attackType]
finalDamage = rawDamage × suppression
```

### 1.5. Типы атак

| Тип | Описание |
|-----|----------|
| `normal` | Обычная атака без техники |
| `technique` | Атака техникой (`technique.level` влияет) |
| `ultimate` | Ultimate-техника (особый флаг `isUltimate`) |

## 2. Буфер Ци (Qi Buffer)

### 2.1. Концепция

> **Ци защищает практика от ЛЮБОГО урона — даже во сне.**
>
> Смертный с кинжалом не может ранить практика L9 — Ци естественно защищает тело.

### 2.2. Типы урона

| Тип урона | Описание | Резонанс |
|-----------|----------|----------|
| **Техники Ци** | Атаки Ци, формации, заклинания | Есть резонанс с Ци практика |
| **Физический урон** | Оружие, кулаки, падения | Нет резонанса |

### 2.3. Конфигурация буфера

**Техники Ци (с резонансом):**

| Параметр | Сырая Ци | Щитовая техника |
|----------|----------|-----------------|
| Поглощение | 90% | 100% |
| Соотношение Ци:Урон | 3:1 | 1:1 |
| Пробитие | 10% ВСЕГДА | 0% |
| Мин. Ци для активации | 10 | 10 |

**Физический урон (без резонанса):**

| Параметр | Сырая Ци | Щитовая техника |
|----------|----------|-----------------|
| Поглощение | 80% | 100% |
| Соотношение Ци:Урон | 5:1 | 2:1 |
| Пробитие | 20% ВСЕГДА | 0% |
| Мин. Ци для активации | 10 | 10 |

> **Почему 5:1 и 20%?**
> - Нет резонанса — Ци «гасит» физику грубо, без точности.
> - Труднее блокировать меч, чем сгусток Ци.
> - Щит эффективнее (но требует техники и поддержания).

### 2.4. Регенерация vs Поглощение

| Механизм | Описание |
|----------|----------|
| **Регенерация (микроядро)** | 10% от ёмкости ядра/сутки — базовый параметр, НЕ модифицируется баффами |
| **Медитация (активная)** | `проводимость × плотность × тики × множитель уровня` — модифицируется уровнем культивации |
| **Поглощение из окружения** | `qiAbsorptionRate` в MortalStageData — для смертных, отдельный механизм |
| **Бонусы экипировки к регенерации** | Additive множитель, не модифицирует базовый параметр микроядра |
| **Формации** | `QiRestoration` в FormationBuffType — отдельная система |

### 2.5. Формулы расчёта

**Техники Ци:**
```
// Сырая Ци
absorbableDamage = damage × 0.90
requiredQi = absorbableDamage × 3.0
piercingDamage = damage × 0.10  // 10% ВСЕГДА

// Щит
requiredQi = damage × 1.0
piercingDamage = 0
```

**Физический урон:**
```
// Сырая Ци (естественная защита)
absorbableDamage = damage × 0.80
requiredQi = absorbableDamage × 5.0
piercingDamage = damage × 0.20  // 20% ВСЕГДА

// Щитовая техника
requiredQi = damage × 2.0
piercingDamage = 0
```

### 2.6. Примеры

**Техники Ци:**

| Сценарий | Урон | Ци до | Ци после | Поглощено | В HP |
|----------|------|-------|----------|-----------|------|
| Сырая Ци, достаточно | 100 | 500 | 230 | 90 (270 Ци) | 10 |
| Сырая Ци, мало | 100 | 150 | 0 | 50 (150 Ци) | 50 |
| Щит, достаточно | 100 | 500 | 400 | 100 (100 Ци) | 0 |
| Нет Ци | 100 | 0 | 0 | 0 | 100 |

**Физический урон (кинжал смертного):**

| Сценарий | Урон | Ци до | Ци после | Поглощено | В HP |
|----------|------|-------|----------|-----------|------|
| Сырая Ци, достаточно | 100 | 500 | 140 | 80 (400 Ци) | 20 |
| Сырая Ци, мало | 100 | 200 | 0 | 40 (200 Ци) | 60 |
| Практик L9 (512,100 Ци) | 100 | 512100 | 511700 | 80 (400 Ци) | 20 |
| Щит, достаточно | 100 | 500 | 300 | 100 (200 Ци) | 0 |

### 2.7. Лорное обоснование

- Ци практика образует естественную «ауру» вокруг тела.
- Практик L9 с ядром 2,048,400 Ци: кинжал смертного (100 урона) требует 400 Ци для поглощения = 0.02% от ядра — ничтожно мало.
- Практик L1 с ядром 1,000 Ци: меньше Ци для защиты, кинжал может пробить быстрее.
- Резонанс техник Ци: эффективнее «поглощается» (3:1 вместо 5:1), но 10% ВСЕГДА пробивает.
- Физический урон: нет резонанса — Ци гасит грубо, требует больше (5:1), но 20% пробитие.

## 4. Расчёт урона техник

### 4.1. Основная формула

```
finalDamage = capacity × gradeMultiplier × ultimateMultiplier
```

### 4.2. Компоненты

**Capacity:**
```
baseCapacity = getBaseCapacity(techniqueType, combatSubtype)
levelMultiplier = 2^(techniqueLevel - 1)
masteryBonus = 1 + (mastery / 100) × 0.5

capacity = floor(baseCapacity × levelMultiplier × masteryBonus)
```

**Qi Cost:**
```
qiCost = floor(baseCapacity × levelMultiplier)
```

**Grade Multiplier:**
```
gradeMultiplier = GRADE_DAMAGE_MULTIPLIERS[grade]
// common: 1.0, refined: 1.3, perfect: 1.6, transcendent: 2.0
```

**Ultimate Multiplier:**
```
ultimateMultiplier = isUltimate ? 2.0 : 1.0
```

### 4.3. Дестабилизация

При `qiInput > capacity`:
```
excessQi = qiInput - capacity

// Урон практику
backlashDamage = floor(excessQi × 0.5)

// Урон по цели (только melee!)
targetDamage = isMelee ? floor(qiInput × 0.5) : 0

// Рассеянное Qi
dissipatedQi = excessQi
```

## 5. Пайплайн урона (11 слоёв)

### 5.1. Архитектура

```
СЛОЙ 1: Исходный урон
rawDamage = capacity × gradeMult × ultimateMult
                                  ↓
СЛОЙ 1b: Урон оружия (melee_weapon)
// Для атак с оружием: weaponDamage добавляется к rawDamage
                                  ↓
СЛОЙ 2: Level Suppression
damage ×= suppressionMultiplier
                                  ↓
СЛОЙ 3: Определение части тела
hitPart = rollBodyPart()
                                  ↓
СЛОЙ 3b: Бафф/Дебафф формаций
// damage ×= formationBuffMultiplier (+30% урон, -50% скорость и т.д.)
                                  ↓
СЛОЙ 4: Активная защита
dodge/parry/block → снижение урона
                                  ↓
СЛОЙ 5: Qi Buffer (для ЛЮБОГО урона — техники Ци и физический)
90%/80% поглощение (Ци/физика) / 100% щит
                                  ↓
СЛОЙ 6: Покрытие брони
if (random() < coverage) → СЛОЙ 7
                                  ↓
СЛОЙ 7: Снижение бронёй
damage ×= (1 - damageReduction)
damage -= effectiveArmor × 0.5
                                  ↓
СЛОЙ 8: Материал тела
damage ×= (1 - materialReduction)
                                  ↓
СЛОЙ 9: Распределение по HP
redHP -= damage × 0.7
blackHP -= damage × 0.3
                                  ↓
СЛОЙ 10: Последствия
кровотечение, шок, оглушение, смерть
```

### 5.2. Формулы по слоям

**Слой 4 — Активная защита:**
```
// Уклонение
dodgeChance = 5% + (AGI-10) × 0.5% - armorDodgePenalty

// Парирование
parryChance = weaponParryBonus + (AGI-10) × 0.3%

// Блок щитом
blockChance = shieldBlock + (STR-10) × 0.2%
```

**Слой 6-7 — Броня:**
```
// Покрытие
if (random() < armor.coverage) {
  // Процентное снижение (кап 80%)
  damageReduction = min(0.8, armor.damageReduction + materialBonus + gradeBonus)
  damage *= (1 - damageReduction)
  
  // Плоское вычитание
  penetration = weapon.penetration + attackerSTR × 0.5
  effectiveArmor = max(0, armor.armor - penetration)
  damage = max(1, damage - effectiveArmor × 0.5)
}
```

**Слой 8 — Материал тела:**
```
materialReduction = MATERIAL_DAMAGE_REDUCTION[bodyMaterial]
damage *= (1 - materialReduction)
```

### 5.3. Материалы тела

| Материал | Твёрдость | Снижение физ. урона |
|----------|-----------|---------------------|
| Organic | 3 | 0% |
| Scaled | 6 | 30% |
| Chitin | 5 | 20% |
| Ethereal | 1 | 70% (физики) |
| Mineral | 8 | 50% |
| Chaos | 5 | переменно |

> Конструкты НЕ имеют собственного материала — определяется составом.

## 6. Мягкие капы (Soft Caps)

### 6.1. Формула диминишинга

```
effectiveBonus = cap × (1 - e^(-bonus / (cap × decayRate)))
```

**Типы капов:**
- **positive** — ограничивает положительный бонус сверху (кап = максимум).
- **negative** — ограничивает отрицательный бонус снизу (кап = минимум, например -50%).
- **absolute** — ограничивает бонус в обе стороны (±cap).
- **range** — ограничивает значение в диапазоне `[min, max]`.

### 6.2. Боевые характеристики

| Переменная | Тип капа | Значение | Decay | Описание |

### 6.9. Правила добавления новых капов

1. Каждый новый модификатор, добавляемый в BuffType или экипировку, ДОЛЖЕН иметь кап в этой таблице.
2. Тип капа:
   - `positive` — баффы не могут превысить cap.
   - `negative` — дебаффы не могут быть хуже cap.
   - `absolute` — ограничение в обе стороны.
3. Decay rate:
   - < 1.0 — быстрый диминишинг (кап достигается быстро).
   - 1.0 — стандартный.
   - \> 1.0 — медленный диминишинг (можно подойти ближе к капу).

## 10. Система стихий

### 10.1. Стихии

| Элемент | Русское название | Противоположность | Сродство |
|---------|------------------|-------------------|----------|
| fire | Огонь | water | air |
| water | Вода | fire | lightning |
| earth | Земля | air | fire |
| air | Воздух | earth | fire, lightning |
| lightning | Молния | **void** | water, air |
| void | Пустота | **lightning, light** | — |
| light | Свет | **void** | water, air |
| neutral | Нейтральный | — | — |

> **Poison (Яд)** — НЕ стихия, а состояние Ци. Не имеет противоположностей. Эффекты ядов реализуются через `technique.type = poison`.
> Единственные стихийные взаимодействия с ядом: Fire→Poison ×1.2 (выжигание токсинов), Light→Poison ×1.2 (очищение).

### 10.2. Множители эффективности атаки (Вариант А, принят 2026-04-10)

**Противоположные элементы (×1.5 / ×0.8):**
- Fire ↔ Water: атакующий Fire по Water = ×1.5, Water по Fire = ×1.5; сродство ×0.8.
- Earth ↔ Air: атакующий Earth по Air = ×1.5, Air по Earth = ×1.5; сродство ×0.8.
- Lightning ↔ Void: атакующий Lightning по Void = ×1.5, Void по Lightning = ×1.5; сродство ×0.8.
- Light ↔ Void: атакующий Light по Void = ×1.5, Void по Light = ×1.5; сродство ×0.8.

**Односторонние:**
- Fire → Poison: ×1.2 (выжигание токсинов).
- Light → Poison: ×1.2 (очищение).
- Void → All: ×1.2 (поглощение).

## 12. Вместимость ядра Ци (Модель В — Растущий резервуар + Сжатие Ци)

> **Решение принято:** 2026-04-10 — Модель В выбрана как основная.

### 12.1. Формула

```
coreCapacity = 1000 × 1.1^totalSubLevels × qualityMultiplier
qiDensity = 2^(level-1)
effectiveQi = coreCapacity × qiDensity
conductivity = coreCapacity / 360

Требование прорыва = capacity(nextLevel) × density(nextLevel)
После прорыва: currentQi = 0
```

**Базовая ёмкость:** 1000 единиц Ци (L1.0).

### 12.2. Рост ёмкости

| Уровень | totalSubLevels | coreCapacity | qiDensity | effectiveQi |
|---------|----------------|--------------|-----------|-------------|
| L1.0 | 0 | 1,000 | 1 | 1,000 |
| L2.0 | 10 | 2,594 | 2 | 5,188 |
| L3.0 | 20 | 6,727 | 4 | 26,908 |
| L4.0 | 30 | 17,450 | 8 | 139,600 |
| L5.0 | 40 | 45,260 | 16 | 724,160 |
| L6.0 | 50 | 117,390 | 32 | 3,756,480 |
| L7.0 | 60 | 304,480 | 64 | 19,486,720 |
| L8.0 | 70 | 789,750 | 128 | 101,088,000 |
| L9.0 | 80 | 2,048,400 | 256 | 524,390,400 |

> Все Ци-значения — `long` (не `float`). На L9 ~524M — точность `float` потерялась бы.

## 13. Проводимость Ци

Характеристика, определяющая эффективность работы с Ци:
- Влияет на урон техник.
- Влияет на эффективность медитации.
- Может развиваться через перки (постоянно).

**Формула:** `conductivity = coreCapacity / 360`

**С бонусами:**
```
finalConductivity = baseConductivity × (1 + conductivityBonus)
```

**Ограничение поглощения:** Поглощение Ци НЕ может превышать проводимость меридиан:
```
absorbedQi = min(
    meditationTime × finalConductivity × environmentMult,
    availableQiInEnvironment
)
```

## 15. Время каста техник

### 15.1. Формула

```
baseTime = qiCost / conductivity
effectiveSpeed = conductivity × (1 + cultivationBonus) × (1 + masteryBonus)
effectiveTime = max(0.1, qiCost / effectiveSpeed)
```

### 15.2. Бонусы

| Источник | Бонус |
|----------|-------|
| Уровень культивации | +5% за уровень выше 1 |
| Мастерство техники | +1% за 1% мастерства |

### 15.3. Пример

```
// qiCost=50, conductivity=2.0, level=3, mastery=50%
cultivationBonus = (3-1) × 0.05 = 0.10
masteryBonus = 0.50
effectiveSpeed = 2.0 × 1.10 × 1.50 = 3.3
baseTime = 50 / 2.0 = 25 сек
effectiveTime = 50 / 3.3 = 15.15 сек
```

## 16. Полный пример пайплайна урона с числами

**Сценарий:** Практик L3 атакует практика L5 техникой `melee_strike` (Common grade, mastery 50%).

```
1. Исходный урон:
   baseCapacity = 64 (melee_strike)
   levelMultiplier = 2^(3-1) = 4
   masteryBonus = 1 + (50/100) × 0.5 = 1.25
   capacity = 64 × 4 × 1.25 = 320
   gradeMultiplier = 1.0 (Common)
   ultimateMultiplier = 1.0
   rawDamage = 320 × 1.0 × 1.0 = 320

2. Level Suppression (атакующий L3, защитник L5, diff=2):
   suppression = 0.1 (technique, diff=2)
   damage = 320 × 0.1 = 32

3. Масштабирование от характеристик (STR=15):
   statBonus = (15 - 10) × 0.05 = 0.25 (+25%)
   damage = 32 × 1.25 = 40

4. Уклонение (AGI=12, броня penalty=0):
   dodgeChance = 5% + (12-10) × 0.5% = 6%
   → Не уклонился (94% шанс)

5. Qi Buffer (сырая Ци, защитник L5, Ци=724,160):
   Физический урон, сырая Ци:
   absorbable = 40 × 0.80 = 32
   requiredQi = 32 × 5.0 = 160
   piercingDamage = 40 × 0.20 = 8
   → 8 HP урона прошло

6. Броня (coverage=0.7, DR=0.3):
   → Попадание по броне (70% шанс)
   damage = 8 × (1 - 0.3) = 5.6
   → Без брони (30% шанс): 8

7. Материал тела (Organic, 0%):
   damage = 5.6 (без изменений)

8. Распределение по HP:
   redHP -= 5.6 × 0.7 = 3.92
   blackHP -= 5.6 × 0.3 = 1.68
```

## 17. Qi Buffer — примеры поглощения

### 17.1. Сценарий 1: Техника Ци, 100 урона, 500 Ци (сырая Ци)

```
absorbableDamage = 100 × 0.90 = 90
requiredQi = 90 × 3.0 = 270
piercingDamage = 100 × 0.10 = 10

Ци после: 500 - 270 = 230
В HP: 10 урона
```

### 17.2. Сценарий 2: Физический урон, 100, 200 Ци (сырая Ци)

```
absorbableDamage = 100 × 0.80 = 80
requiredQi = 80 × 5.0 = 400
→ Недостаточно Ци! (только 200)
absorbed = 200 / 5.0 = 40 (урона поглощено)
piercingDamage = 100 × 0.20 = 20

Ци после: 0
В HP: 100 - 40 = 60 (40 поглощено + 20 пробитие = 60 прошло)
```

### 17.3. Сценарий 3: Щитовая техника, 100 урона, 500 Ци

```
// Техника Ци
requiredQi = 100 × 1.0 = 100
piercingDamage = 0

Ци после: 500 - 100 = 400
В HP: 0 (полное поглощение!)

// Физический урон
requiredQi = 100 × 2.0 = 200
piercingDamage = 0

Ци после: 500 - 200 = 300
В HP: 0 (полное поглощение!)
```
