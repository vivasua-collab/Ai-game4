# Конфигурации

> **Статус:** Концепция (engine-agnostic).
> **Связанные документы:** `DATA_MODELS.md`, `SAVE_SYSTEM.md`, `02_systems/QI_SYSTEM.md`, `02_systems/TECHNIQUE_SYSTEM.md`, `06_player/EQUIPMENT_SYSTEM.md`.

---

## 1. Обзор

Документ описывает конфигурационные данные проекта: уровни культивации, типы техник, материалы, грейды, стихии, NPCConfig, GameConstants.

**Хранение конфигураций** — **data resources** (текстовые ресурсные файлы данных). Конкретный формат зависит от реализации:
- JSON-файлы (портативный, текстовый, легко редактируется, читается AI-агентами напрямую);
- текстовые ресурсные файлы движка (если движок поддерживает текстовый формат ресурсов);
- комбинация обоих.

> Конфигурации — это **нейтральные классы/структуры**, сериализуемые в текстовый формат. НЕ используются движко-специфичные ресурсные типы; выбор движка влияет только на конкретный формат сериализации, не на сами данные.

> **Проводимость** вычисляется по формуле: `coreCapacity / 360 сек`. Подробнее — в `02_systems/QI_SYSTEM.md`.

### 2.2 Способности по уровням

**L1 — Пробуждённое Ядро:**
- первичное накопление Ци в ядре;
- тело становится чуть выносливее.

**L2 — Течение Жизни:**
- ускоренное заживление (порезы за час);
- лёгкое усиление мышц;
- интуитивное чувство опасности.

**L3 — Пламя Внутреннего Огня:**
- регуляция температуры тела волей;
- очищение воды/воздуха от примесей Ци;
- доступ к простым боевым техникам Ци.

**L4 — Объединение Тела и Духа:**
- физические параметры превосходят человеческие пределы;
- кратковременное «парение».

**L5 — Сердце Небес:**
- слушание Ци ландшафта;
- эмоциональная стабильность.

**L6 — Разрыв Пелены:**
- искажение локального поля Ци;
- тело почти неуязвимо для обычного оружия;
- способность жить без еды/воды.

**L7 — Вечное Кольцо:**
- пассивное поглощение Ци даже во сне;
- старение остановлено.

**L8 — Глас Небес:**
- предсказание природных катаклизмов;
- регенерация при потере конечностей.

**L9 — Бессмертное Ядро:**
- почти бессмертие;
- создание духовных артефактов с волей.

### 2.3 Формулы культивации

Формулы плотности Ци, роста ёмкости ядра, прорыва и генерации — в `02_systems/QI_SYSTEM.md` и `09_workflow/ALGORITHMS.md`. Здесь — только справочная таблица уровней.

## 6. Система Grade техник

> Источник истины: `02_systems/TECHNIQUE_SYSTEM.md` §«Система Grade».

### 6.1 Множители Grade

| Grade | Урон (множитель) | qiCost (множитель) | Шанс выпадения |
|-------|------------------|---------------------|----------------|
| common | ×1.0 | ×1.0 | ~80% |
| refined | ×1.2 | ×1.0 | ~13% |
| perfect | ×1.4 | ×1.0 | ~5% |
| transcendent | ×1.6 | ×1.0 | ~2% |

> **Grade НЕ зависит от уровня.** Транцендентные предметы могут выпадать даже на L1 с шансом 2%.

### 6.2 Ultimate-техники

- 5% шанс для transcendent-техник.
- Множитель урона: ×1.3.
- Множитель стоимости Ци: ×1.5.
- Маркер в названии: `⚡ {name}`.

### 6.3 Ограничения Ultimate

- Макс. 1 на персонажа.
- Кулдаун: 1 час игрового времени (60 тиков).
- Требует 9-й уровень культивации или особую технику.

## 8. Система грейдов экипировки

> Источник истины: `06_player/EQUIPMENT_SYSTEM.md` §2 «Система грейдов».

### 8.1 Грейды экипировки

| Grade | Множитель параметров | Шанс выпадения |
|-------|----------------------|----------------|
| damaged | ×0.5 | — (только через повреждение) |
| common | ×1.0 | ~80% |
| refined | ×1.2 | ~13% |
| perfect | ×1.4 | ~5% |
| transcendent | ×1.6 | ~2% |

### 8.2 Распределение грейдов (НЕ зависит от уровня)

```
Обычный (Common):       80%
Улучшенный (Refined):   13%
Совершенный (Perfect):   5%
Трансцендентный:         2%
```

Это распределение **одинаково для L1 и L9**. Уровень влияет на абсолютные значения (baseCapacity, durability), но не на распределение грейдов.

### 8.3 Уровни прочности (durabilityCondition)

| Condition | % от maxDurability | Эффект |
|-----------|---------------------|--------|
| pristine | 100% | без штрафов |
| good | 75–99% | без штрафов |
| worn | 50–74% | −5% к параметрам |
| damaged | 25–49% | −20% к параметрам |
| broken | <25% | −50% к параметрам, риск поломки |

## 13. Хранение конфигураций

### 13.1 Data resources — формат

```
config/
├── cultivation_levels.json          # 10 уровней культивации
├── technique_types.json             # типы и подтипы техник
├── techniques/
│   ├── basic/level-1.json           # 1024 базовых техник
│   ├── advanced/level-{2-6}.json    # 512+256+128+64+32 = 992
│   └── master/level-{7-9}.json      # 16+8+4 = 28
├── materials.json                   # ~50 материалов (5 тиров)
├── grades.json                      # 4 грейда (common..transcendent)
├── elements.json                    # 6–7 стихий
├── npc_config.json                  # NPCConfig
├── game_constants.json              # GameConstants
├── items/
│   ├── weapons.json
│   ├── armor.json
│   ├── accessories.json
│   ├── consumables.json
│   ├── chargers.json
│   └── qi_stones.json
├── species/                         # SpeciesPreset (~50 видов)
│   ├── human.json
│   └── ...
└── formations/
    ├── cores.json
    └── types.json
```

## 14. Принципы конфигураций

1. **Data resources (JSON / текстовые ресурсные файлы движка), НЕ движко-специфичные ресурсные типы.** Нейтральные классы, сериализуемые в текстовый формат.
2. **Grade НЕ зависит от уровня.** 2% transcendent даже на L1.
3. **`long` для Qi-значений** в конфигах (qiCost, baseCapacity).
4. **Базовые формулы в ALGORITHMS.md и QI_SYSTEM.md**, не здесь.
5. **Пресеты техник = ~2046 шт.** Базовый паттерн распределения по уровням: `1024, 512, 256, 128, 64, 32, 16, 8, 4` (база / 2^(L-1)).
6. **Камни Ци** характеризуются только объёмом и типом Ци (calm/chaotic), без качества.
