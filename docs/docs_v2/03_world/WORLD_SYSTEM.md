# Система мира

> **Статус:** Концепция (engine-agnostic).
> **Связанные документы:** `WORLD_MAP_SYSTEM.md`, `LOCATION_MAP_SYSTEM.md`, `TRANSITION_SYSTEM.md`, `WORLD_SAVE_SYSTEM.md`, `TILE_SYSTEM.md`.
> Источник истины по размерностям мира — `WORLD_MAP_SYSTEM.md` §1.

---

## 1. Обзор

Мир игры — это огромный континуум культивационной вселенной сянси. Размер мира определяется не техническими ограничениями движка, а жанровыми конвенциями: практике доступны путешествия на тысячи километров, годы уходят на переход между регионами, и значительная часть мира остаётся неисследованной даже после тысяч часов игры.

Система мира — это **концептуальная модель**, которая описывает:
- структуру континуума (плоский эллипсоид суши, опоясанный непроходимым Ци-морем);
- иерархию размерностей (мир → чанк → сектор → локация → тайл);
- модель загрузки (per-location scene loading, а НЕ open-world streaming);
- разделение между «точками интереса» (загружаемыми локациями) и «дикими землями» (процедурными переходами).

**Архитектурный принцип:** игрок не бегает по непрерывному открытому миру. Игрок выбирает локацию на карте мира, эта локация загружается как отдельная сцена, и внутри неё происходит геймплей. Между локациями — путешествие по игровому времени с возможными процедурными встречами (см. `TRANSITION_SYSTEM.md`). Это аналог RimWorld / Disco Elysium / Baldur's Gate, а не Skyrim / Witcher.

## 2. Структура мира

### 2.1 Метафора мира

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        МИР КУЛЬТИВАЦИИ                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   Форма: Условно плоский эллипсоид                                          │
│   Обитаемая суша: 200,000 × 200,000 км (40 млрд км²)                       │
│   Бесконечное Ци-море: кольцо за пределами суши (непроходимое)              │
│   Купол неба: высота 10,000 км в центре                                     │
│   Недра: глубина 6,000 км                                                   │
│                                                                              │
│   Летосчисление: Э.С.М. (Эра Сердца Мира)                                   │
│   Текущий год на старте: 1864                                               │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

Мир в ~268 раз больше Земли по площади суши. Это сознательное лорное решение: миры сянси описывают огромные континенты, где путешествия занимают месяцы и годы, а многие области остаются «белыми пятнами».

### 2.2 Двухуровневая модель навигации

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      КАРТА МИРА (внешний уровень)                            │
│                                                                              │
│    ┌────┬────┬────┬────┬────┐                                              │
│    │ 🏔️ │ 🌲 │ 🏘️ │ 🌲 │ 🌊 │   Сектора (ячейки карты мира 10×10 км)       │
│    ├────┼────┼────┼────┼────┤   Перемещение за игровое время                │
│    │ 🌲 │ 🏛️ │ 👤 │ 🌾 │ 🌲 │   Вид «сверху» на мир                         │
│    ├────┼────┼────┼────┼────┤   Фог войны                                    │
│    │ 🏔️ │ 🌲 │ 🌲 │ 🐺 │ 🏔️ │                                                │
│    └────┴────┴────┴────┴────┘                                                │
│                              │                                               │
│                              │ Enter Location                                │
│                              ▼                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                     ЛОКАЛЬНАЯ СЦЕНА (внутренний уровень)                     │
│                                                                              │
│    ┌──────────────────────────────────────┐                                  │
│    │  🌲 🪨     🏠        🌲 🌲           │   Локальная арена                 │
│    │        👤                    🐺      │   Реальное время                  │
│    │  🌲 🌲          🪨     🌲 🌲         │   Статические объекты             │
│    │        🌲 🌲                          │   Динамические NPC                │
│    │              🌲    🌲 🌲             │   Игрок                           │
│    └──────────────────────────────────────┘                                  │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

**Принцип:** одновременно активна только одна локальная сцена. Карта мира — это навигационный интерфейс (не 3D-пространство). Путешествия между локациями — это **travel screens** с анимацией пути и игровыми событиями (см. `TRANSITION_SYSTEM.md`).

| Уровень | Единица | Размер | Функция |
|---------|---------|--------|--------|

## 4. Чанк — единица сохранения

**Чанк (100 × 100 км)** — это базовая единица персистентности мира. Один чанк = один файл сохранения.

- Мир содержит 4,000,000 чанков, но в типичной сессии игрок посещает 10–500 чанков.
- Чанк содержит 100 секторов (10×10).
- Чанк хранит: метаданные секторов, список локаций, дельту изменённых объектов,种子 (seed) для процедурной генерации тайлов.
- **Тайлы внутри чанка не сохраняются индивидуально.** Они восстанавливаются процедурно из seed + дельта изменений (см. `WORLD_SAVE_SYSTEM.md`).

---

## 5. Сектор — единица карты мира

**Сектор (10 × 10 км)** — это ячейка на глобальной карте мира, минимальная единица стратегической навигации.

- В одном секторе — 1–10 локаций (точек интереса).
- Сектор хранит только метаданные: тип местности, climate, qiDensity, dangerLevel, список локаций.
- Тайлы на уровне сектора **не хранятся**. Между локациями внутри сектора лежат «дикие земли» — процедурные переходы, а не загружаемые сцены.

Пример сектора:

```
Сектор «Долина Туманных Рек» (10×10 км)
├── Город «Туманный»        — 1×1 км     (250,000 тайлов)
├── Деревня «Тихая»         — 300×300 м  (22,500 тайлов)
├── Храм «Утренней Росы»    — 200×200 м  (10,000 тайлов)
├── Хутор «Старого Цая»     — 100×100 м  (2,500 тайлов)
└── «Дикие земли» между ними — не загружаются как сцена
```

---

## 6. Локация — единица загрузки

**Локация (переменный размер, 100 м … 10 км)** — это загружаемая сцена, в которой проходит основной геймплей.

### 6.1 Типы локаций и размеры

| Тип | Размер | Тайлов | Примеры |
|------|--------|--------|---------|
| Мегаполис | 10 × 10 км | **25,000,000** | Столица империи, главный город секты |
| Большой город | 3 × 3 км | 2,250,000 | Город-государство, торговый хаб |
| Средний город | 1 × 1 км | 250,000 | Районный центр |
| Посёлок | 500 × 500 м | 62,500 | Крупное село |
| Деревня | 300 × 300 м | 22,500 | Сельское поселение |
| Хутор | 100 × 100 м | 2,500 | Одинокая ферма |
| Храм / Святилище | 200 × 200 м | 10,000 | Храмовый комплекс |
| Подземелье | переменный | до 100,000 | Пещера, катакомбы |
| Дикие земли | — | — | Процедурная генерация при переходе |

**Принцип:** размер локации определяется её контентом, а не фиксированной сеткой. Расчёт тайлов: `(ширина_м / 2) × (высота_м / 2)`.

### 6.2 Per-location scene loading

```
В любой момент времени активна ОДНА локация.

[Карта мира] ──(выбор локации)──► [Загрузка сцены] ──► [Активная локация]
                                                                │
                                                                │ (выход / переход)
                                                                ▼
                                                          [Карта мира]
```

**НЕ используется open-world streaming:**
- нет подгрузки тайлов по радиусу вокруг игрока;
- нет бесшовного перехода между соседними локациями без travel screen;
- нет симуляции всего мира в фоне.

**Что это даёт:**
- Предсказуемый performance budget: мегаполис 25M тайлов загружается один раз и живёт в памяти только пока игрок в нём.
- Глубокая детализация: каждая локация наполнена уникальным контентом, а не «штампуется» процедурно.
- Изолированная симуляция: NPC, погода, события живут только в активной локации. Внеактивные локации «замораживаются» во времени или симулируются в упрощённом режиме (см. `TRANSITION_SYSTEM.md` §«Таймер памяти»).

---

## 7. Дикие земли — процедурные переходы

**Дикие земли** — это пространство между локациями внутри сектора. Они **не загружаются как сцены**.

- При путешествии между локациями игроку показывается **travel screen** (анимация пути + прогресс времени).
- Во время путешествия может произойти **процедурная встреча** (random encounter) — тогда загрузится временная боевая сцена.
- Сами «дикие земли» не сохраняются: они каждый раз генерируются заново по seed сектора.

Подробнее — в `TRANSITION_SYSTEM.md`.

| Тип места | Радиус | Модификатор Ци | Особенности |
|-----------|--------|----------------|-------------|
| Sanctuary (Святилище) | 500 м – 5 км | ×3–10 | Безопасная зона, регенерация |
| Spirit Spring (Духовный источник) | 100 м – 1 км | ×2–5 | Источник чистого Ци |

| Cursed Source (Проклятый источник) | 200 м – 2 км | ×0.5 | Искажённое Ци, коррупция |

Места силы — это **точки интереса**, размещаемые в локациях. Высокое Ци пагубно для низкоуровневых практиков и благоприятно для высокоуровневых; опасно для новорождённых (риск хтони).

## 10. Объекты мира

### 10.1 Статические объекты (персистентные)

Сохраняются при уходе игрока из локации:
- деревья, камни, руды, руины, святилища;
- собранные ресурсы (исчезают);
- открытые сундуки (остаются пустыми);
- разрушенные объекты;
- квестовые триггеры.

### 10.2 Динамические сущности (сессионные)

Генерируются при входе в локацию или респаунятся по таймеру памяти:
- NPC, животные, духи;
- обычные враги (респаун через игровое время);
- ресурсы (регенерация).

### 10.3 Неперсистентные (сбрасываемые)

- позиция игрока (возвращается в точку входа);
- временные эффекты;
- боевые состояния.

Подробнее о персистентности — в `TRANSITION_SYSTEM.md` §«Таймер памяти локации».

## 11. Координаты

### 11.1 Единицы измерения

- **Метры** — основная единица расстояния в игровом мире.
- **1 метр = 32 пикселя** — масштаб спрайтов.
- **1 тайл = 2 × 2 метра** — навигационная ячейка.

### 11.2 Координатная сетка

```
World (200,000 × 200,000 km)
  └── Chunk grid: 2,000 × 2,000 chunks   (по 100 км)
       └── Sector grid: 10 × 10 sectors    (по 10 км) внутри чанка
            └── Location offset (м)         внутри сектора
                 └── Tile grid: W/2 × H/2    внутри локации
                      └── Z level: -5..+5   логический уровень
```

Координаты сущности в мире определяются иерархически:
`worldId → chunkId → sectorId → locationId → (tileX, tileY, zLevel)`.

Это позволяет за O(1) определить чанк сохранения, к которому относится любая сущность, и за O(1) найти локацию, в которой находится игрок.

## 12. Принципы мира

1. **Мир огромен, но игрок его не обходит.** Большинство чанков остаётся «чёрными» (Hidden) всю игру. Это сознательное дизайн-решение.
2. **Локации — это точки интереса, а не тайлы на сетке.** Размер и форма локации диктуются контентом (город, данж, храм), а не сеткой 1×1 км.
3. **Дикие земли процедурны.** Пространство между локациями не хранится в сохранении — оно генерируется из seed сектора при каждом переходе.
4. **Сохранение — чанковое.** Один чанк = один файл. Игрок может играть годами и не превысить разумный размер сохранения (см. `WORLD_SAVE_SYSTEM.md`).
5. **Активна одна локация.** Никакого open-world streaming. Это упрощает performance budget, NPC AI, сохранения и тестирование.
