# Дизайн: страты мира

> **Статус:** Концепция
> **Дата:** 2026-08-15

## Терминология

**Страта** (от лат. stratum) — логический уровень данных тайла.
**Render Layer** — уровень отображения в Godot (ZIndex).
Не путать: страты = данные, render layers = отображение.

## Страты мира

| Страта | Имя | Влияние | Примеры | Кол-во на тайл |
|--------|-----|---------|---------|----------------|
| 0 | Биом | Только Ци | Океан, Лес, Степь, Горы | 1 |
| 1 | Поверхность | Скорость + Ци | Grass, Dirt, Stone, Water | 1 |
| 2 | Бонусная | Скорость + Ци + урон | Проклятая земля, Пожар, Туман | 0-1 |
| 3-9 | Объекты | Взаимодействие | Дерево, Камень, Труп, Дроп | 0-7 (1 на страту) |

## Правила наложения

- Страта 0: определяется при генерации, неизменна
- Страта 1: базовый тайл, может меняться (дорога, заморозка)
- Страта 2: 0 или 1, временная, новая заменяет старую
- Страты 3-9: 1 объект = 1 страта, кучка однотипных = 1 страта (стак)
- Запрет: два объекта одной категории не могут быть на одной страте
