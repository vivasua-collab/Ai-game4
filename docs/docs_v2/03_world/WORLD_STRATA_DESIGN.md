---

## 1. Терминология

**Страта** (от лат. stratum — слой) — логический уровень данных тайла.
**Render Layer** — уровень отображения в Godot (ZIndex).

Это разные понятия: страты описывают **данные**, render layers — **отображение**.

---

## 2. Страты мира

| Страта | Имя | Влияние | Примеры | Кол-во объектов на тайл |
|--------|-----|---------|---------|------------------------|
| **0** | Биом | Только на Ци | Океан, Леса, Степь, Горы | 1 (определяется по noise) |
| **1** | Поверхность | Скорость перемещения + Ци | Grass, Dirt, Stone, Water, Sand, Road | 1 (одно на тайл) |
| **2** | Бонусная | Скорость + Ци + урон (бонусы/дебафы) | Проклятая земля, Святая земля, Пожар, Туман, Гроза | 0-1 (опционально) |
| **3-9** | Объекты | Взаимодействие, ресурсы, препятствия | Дерево, Камень, Куст, Здание, Труп, Дроп | 0-7 (1 объект на страту) |

### 2.1. Правила наложения

**Страта 0 (Биом)** — определяется при генерации, неизменна.
- Влияет только на базовую плотность Ци в области.
- Не влияет на проходимость или урон.

**Страта 1 (Поверхность)** — базовый тайл, один на клетку.
- Влияет на: `moveCost` (множитель скорости), `qiDensity` (базовая Ци).
- Может меняться: выкопать яму, насыпать дорогу, заморозить воду.

**Страта 2 (Бонусная)** — опциональный эффект поверх поверхности.
- Влияет на: `moveCost`, `qiDensity`, `damageBonus` (множитель урона).
- Временная: пожар горит N минут, проклятие длится M дней.
- **Правило:** 0 или 1 бонусная страта на тайл. Новая заменяет старую.

**Страты 3-9 (Объекты)** — до 7 объектов на тайл.
- **Правило:** 1 объект = 1 страта. Кучка однотипных = 1 страта (стак).
- Страта 3: самый нижний объект (труп, дроп на земле).
- Страта 4: растительность (куст, трава).
- Страта 5: дерево/камень (крупный объект).
- Страта 6: строение (стена, забор).
- Страта 7: эффект (формация, ловушка).
- Страта 8: резерв (будущие типы).
- Страта 9: резерв.
- **Запрет:** два объекта одной категории не могут быть на одной страте.

### 2.2. Пример заполнения тайла

```
Тайл (25, 25):
  Страта 0: Биом = Grassland (qiDensity ×1.0)
  Страта 1: Поверхность = Grass (moveCost ×1.0)
  Страта 2: Бонус = Holy_Ground (moveCost ×0.8, qiRegen ×1.5, damageBonus ×1.2)
  Страта 3: Объект = T Corpse (lootable)
  Страта 4: Объект = Bush_Berry (harvestable)
  Страта 5: (пусто)
  Страта 6: (пусто)
  Страта 7: (пусто)
```

## 3. Управление камерой

| Действие | Клавиша | Описание |
|----------|---------|----------|
| Зум ближе | Колесо мыши вверх | Увеличить масштаб (Zoom += 0.5) |
| Зум дальше | Колесо мыши вниз | Уменьшить масштаб (Zoom -= 0.5) |
| Предел зума | 1.0 - 8.0 | Min=1 (далеко), Max=8 (близко) |
| Центрирование | Middle Mouse | Центр на игроке (сброс к Zoom=3) |

## 5. Render Layers (ZIndex) — отображение

| ZIndex | Назначение | Источник |
|--------|------------|---------|
| 1 | Terrain (поверхность) | TileMapLayer Ground |
| 2 | Transitions (сглаживание) | TileMapLayer Transitions |
| 3 | Objects (деревья, камни) | TileMapLayer Objects (YSort) |
| 4 | Player + NPC | Sprite2D (YSort) |
| 5 | Effects (формации) | Node2D |
| 10 | HUD | CanvasLayer |

**Важно:** ZIndex не связан со стратами напрямую. Страта 5 (дерево) и страта 3 (труп) могут оба рендериться на ZIndex=3 (Objects), но с разным YSort.

## 6. Упрощение

**Что убрано из предыдущего дизайна:**
- ~~Multi-layer TileSet physics~~ — слишком сложно для v1
- ~~Navigation layers per stratum~~ — один navigation layer на всю карту
- ~~Custom data layers per stratum~~ — данные в GameTile struct, не в TileSet

**Принцип:** страты — это **данные** (GameTile struct). Render layers — это **отображение** (Godot ZIndex). Не смешивать.
