## 1. Единая система размерностей

> Все размеры в проекте определяются этой таблицей. При изменении — обновить все зависимые документы.

### 1.1 Иерархия размерностей

```
УРОВЕНЬ 0: МИР (World)
├── Размер: 200,000 × 200,000 км
├── Функция: Контейнер всего мира
└── Единиц: 4,000,000 чанков

УРОВЕНЬ 1: ЧАНК (Chunk) — единица СОХРАНЕНИЯ
├── Размер: 100 × 100 км
├── Функция: Один файл сохранения
└── Единиц: 100 секторов (10×10)

УРОВЕНЬ 2: СЕКТОР (Sector) — единица КАРТЫ МИРА
├── Размер: 10 × 10 км
├── Функция: Ячейка на глобальной карте, навигация «путешествие во времени»
└── Содержит: 1–10 локаций (точек интереса)

УРОВЕНЬ 3: ЛОКАЦИЯ (Location) — единица ЗАГРУЗКИ
├── Размер: ПЕРЕМЕННЫЙ (100 м … 10 км)
├── Функция: Загружаемая сцена, прецизионный вход в сектор
└── Содержит: до 25,000,000 тайлов

УРОВЕНЬ 4: ТАЙЛ (Tile) — единица НАВИГАЦИИ
├── Размер: 2 × 2 м ← СТАНДАРТ
├── Функция: Навигация, collision, размещение объектов
└── Содержит: данные о проходимости, объектах, субъектах
```

### 1.2 Ключевые параметры

| Параметр | Значение | Расчёт | Примечание |
|----------|----------|--------|------------|
| Обитаемая суша | 200,000 × 200,000 км | — | Эллипсоид |
| Размер чанка | 100 × 100 км | — | Единица сохранения |
| Размер сектора | 10 × 10 км | — | Ячейка карты мира |
| Размер локации | 100 м … 10 км | — | Переменный |
| **Размер тайла** | **2 × 2 м** | — | **СТАНДАРТ** |
| Площадь тайла | 4 м² | 2 × 2 | — |
| Тайлов в 1 км² | 250,000 | (1000/2)² | — |
| Тайлов в секторе (10×10 км) | 25,000,000 | (10000/2)² | 25 млн |
| Чанков в мире | 4,000,000 | (200000/100)² | — |
| Секторов в чанке | 100 | 10×10 | — |
| Масштаб отображения | 1 пиксель = 2 м | — | На миникарте |
| Масштаб спрайтов | 1 метр = 32 пикселя | — | — |

### 1.3 Почему тайл 2 × 2 м

- **1 × 1 м — слишком мелко:** 100M тайлов на 1 км², перерасход памяти и производительности, избыточная детализация для 2D игры сверху.
- **10 × 10 м — слишком грубо:** дерево занимает целый тайл, неточная боевка, дом = 1 тайл.
- **2 × 2 м — оптимально:**
  - детализация: дерево = 1 тайл, дом = 9–25 тайлов;
  - производительность: 250,000 тайлов на 1 км²;
  - боевка: точное позиционирование, 1 шаг = 0.5 тайла;
  - совместимость: игрок = 1 тайл, дракон = 4+ тайлов.

## 2. Обзор карты мира

### 2.1 Концепция двухуровневой системы

Карта мира реализована как **двухуровневая система навигации**, обеспечивающая баланс между стратегическим обзором и тактическим взаимодействием.

```

│  🌲  🏛️  👤  🌾  🌲  🌊  🌲  🏔️                                              │

   • Перемещение: за игровое время (тики)
   • Вид: стратегический обзор «сверху»
   • Фог войны: скрывает неисследованные области
                              │
                              │ Enter Location
                              ▼

   • Масштаб: 1 тайл = 2×2 м

   • Вид: тактический «сверху» (orthographic top-down)
   • Объекты: детальное взаимодействие
```

## 3. Структура карты мира

### 3.1 Сектора — базовые единицы карты мира

**Сектор** — минимальная единица навигации на карте мира (10 × 10 км).

```

│   Содержит 1–10 локаций (точек интереса):                                │
│                                                                         │
│   ┌────────────┐                                                        │
│   │ 🏘️ Город   │  1×1 км = 250,000 тайлов                              │
│   └────────────┘                                                        │
│         ┌──────┐                                                        │
│         │ 🌲   │  Дикие земли (не загружаются как сцена)                │
│         └──────┘                                                        │
│   ┌──────┐                                                              │
│   │ 🏛️   │  Храм 200×200 м = 10,000 тайлов                             │
│   └──────┘                                                              │
│                                                                         │
│   Тип местности: forest                                                 │
│   Ци плотность: 120                                                     │
│   Опасность: 3                                                          │
│   Точки интереса: 3 (город, храм, деревня)                              │

ТАЙЛЫ НЕ ХРАНЯТСЯ на уровне сектора!

```

**Характеристики сектора:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `sectorId` | string | Уникальный идентификатор (X_Y) |
| `terrainType` | enum | Основной тип местности |
| `elevation` | float | Высота над уровнем моря (0–10000) |
| `qiDensity` | int | Плотность Ци в секторе |
| `dangerLevel` | int | Уровень опасности (1–9) |
| `climate` | enum | Климатическая зона |
| `discovered` | bool | Открыт ли сектор |
| `lastVisited` | long | Timestamp последнего посещения |
| `locations` | List | Список локаций в секторе |

### 3.4 Фог войны

```
СОСТОЯНИЯ ВИДИМОСТИ:

████████  ░░░░░░░░  ▓▓▓▓▓▓▓▓  🌲🏔️🏘️
Hidden    Explored  Visible   Current

│ Состояние │ Описание │ Что видно │ Обновление │
├───────────┼──────────┼───────────┼────────────┤
│ Hidden    │ Никогда  │ Ничего    │ При входе  │
│           │ не были  │           │ в сектор   │
│ Explored  │ Были     │ Статичные │ При входе  │
│ (Memory)  │ раньше   │ объекты   │ в сектор   │
│ Visible   │ Сейчас   │ Всё       │ В реальном │
│ (Current) │ там      │           │ времени    │

РАДИУС ВИДИМОСТИ:
• Базовый: 1 сектор (текущий, 10×10 км)
• С возвышенностью: +2 сектора
• С техникой: +3–5 секторов
• С артефактом: +10 секторов
```

**Флаги состояния чанков/секторов** (для сохранения):

| Флаг | Цвет | Описание | Что хранится |
|------|------|----------|--------------|
| Hidden | Чёрный | Не видим, не посещён | Ничего |
| Visible | Серый | Видим через разведку/техники (радиус ~100 км) | Базовая информация (тип местности, примерное Ци) |
| Known | Известный | Известен из книг/карт/разговоров | Точки интереса, неполная информация |
| Visited | Белый | Лично посещён | Полное или частичное сохранение |

Переходы состояний:
- Чёрный → Серый: при использовании техник разведки.
- Чёрный → Известный: при изучении карты/информации.
- Любой → Белый: при личном посещении.

## 4. Типы местности на карте мира

### 4.1 Основные типы и влияние на путешествия

| Местность | Скорость | Выносливость | Опасности | Особенности |
|-----------|----------|--------------|-----------|-------------|
| **Plains** | ×1.0 | Норма | Минимум | Открытый обзор |
| **Forest** | ×0.7 | +20% | Засады | Укрытие от взгляда |
| **Mountains** | ×0.3 | +50% | Обрывы | Бонус к Ци на пиках |
| **Desert** | ×0.5 | +100% | Жара | Потеря воды |
| **Swamp** | ×0.4 | +80% | Болезнь | Ядовитые газы |
| **Sea** | ×0.2 | +30% | Шторм | Требует лодку |
| **Tundra** | ×0.6 | +60% | Холод | Обморожение |
| **Volcanic** | ×0.5 | +100% | Лава | Огненный урон |

> Множители скорости здесь (×0.7 лес = замедление) инвертированы к множителям времени в `TRANSITION_SYSTEM.md` (×1.5 лес = больше времени). Связь: `terrainMultiplier(TRANSITION) = 1 / speedMultiplier(тут)`.

```
└───────────────────────────────────────────────────────────────────────┘

В секторах (10×10 км):
• Базовый: 10 секторов в каждом направлении
• С техниками: до 30 секторов
```

## 7. Перемещения по карте мира

### 7.1 Скорости путешествия

| Способ | Скорость | Описание |
|--------|----------|----------|
| Пешком | 5 км/ч | Базовая скорость практика |
| Верхом | 15 км/ч | Требует лошадь/транспорт |
| Полёт (L4+) | 30–100 км/ч | Техника культивации |
| Телепорт (L7+) | мгновенно | Только в известные точки |

### 7.2 Расчёт времени пути

```
travelTime = distance × (1 / speed) × terrainModifier × weatherModifier × dangerModifier

Пример:
Город → Деревня: 3 км
Скорость пешком: 5 км/ч
Модификатор дороги: ×1.2 (хорошая дорога)
Итог: 3 / 5 × 1.2 = 0.72 ч = 43 минуты игрового времени
```

Путешествие по карте мира происходит в **ускоренном игровом времени** (см. `TIME_SYSTEM.md`). Подробности — в `TRANSITION_SYSTEM.md`.

### 7.3 Случайные встречи при путешествии

| Фактор | Шанс встречи | Тип встреч |
|--------|--------------|------------|
| Безопасная дорога | 5% | Торговцы, странники |
| Обычная дорога | 15% | Бандиты, звери |
| Опасная территория | 30% | Враги, духи |
| Ночная дорога | +10% | Призраки, демоны |
| Дождь/Туман | +5% | Скрытые угрозы |
| Охрана/Конвой | -10% | Меньше инцидентов |

## 8. Принципы карты мира

1. **Карта мира — это навигационный интерфейс, а не 3D-пространство.** Игрок не «бегает» по карте мира — он выбирает сектор/локацию и запускает путешествие.
2. **Сектор = ячейка карты мира.** На секторе нет тайлов; сектор хранит только метаданные и список локаций.
3. **Локации — это точки интереса внутри сектора.** Между ними лежат «дикие земли» (процедурные переходы, не загружаемые сцены).
4. **Фог войны — главный интерфейс исследования.** Игрок постепенно открывает сектора: Чёрный → Серый → Известный → Белый.
5. **Радиус видимости — это游戏-механика, а не технический лимит.** На него влияют техники, артефакты, погода, время суток.
