# Система переходов

> **Статус:** Концепция (engine-agnostic).
> **Сектор = 10 × 10 км | Тайл = 2 × 2 м.** См. `WORLD_MAP_SYSTEM.md` §1.
> **Связанные документы:** `WORLD_SYSTEM.md`, `WORLD_MAP_SYSTEM.md`, `LOCATION_MAP_SYSTEM.md`, `TIME_SYSTEM.md`.

---

## 1. Обзор

Система переходов управляет перемещением игрока между различными уровнями детализации мира: от глобальной карты мира к конкретным локациям и интерьерам зданий. Это **travel-screens based transitions**, а не open-world streaming.

Система переходов покрывает:
- переход между картой мира и локацией;
- переход между локациями (через дикие земли);
- переход локация ↔ интерьер здания (дверь);
- телепортацию (техники, порталы, предметы);
- специальные переходы (измерения, данжи);
- сохранение состояния при переходах;
- таймер «памяти» локации (респаун врагов, регенерация ресурсов).

## 2. Двухуровневая модель

```
УРОВЕНЬ 1: КАРТА МИРА (глобальная навигация)
┌────┬────┬────┬────┬────┐
│ 🏔️ │ 🌲 │ 🏘️ │ 🌲 │ 🌊 │   Игрок видит мир «с высоты птичьего полёта»
├────┼────┼────┼────┼────┤   Перемещение между секторами
│ 🌲 │ 🏛️ │ 👤 │ 🌾 │ 🌲 │   Время течёт ускоренно
└────┴────┴────┴────┴────┘
              │
              │ Enter Location
              ▼
УРОВЕНЬ 2: ЛОКАЛЬНАЯ СЦЕНА (детальный геймплей)
┌──────────────────────────────────────┐
│  🌲 🪨     🏠        🌲 🌲           │   Детальный вид локации
│        👤                    🐺      │   Реальное время
│  🌲 🌲          🪨     🌲 🌲         │   Бой, взаимодействие
└──────────────────────────────────────┘
```

Дополнительно — **трёхуровневая модель** для интерьеров:

```
УРОВЕНЬ 1: МИРОВАЯ КАРТА (глобальная навигация)
              │
              │ Enter Sector
              ▼
УРОВЕНЬ 2: ЛОКАЛЬНАЯ СЦЕНА (область/сектор)
              │
              │ Enter Building
              ▼
УРОВЕНЬ 3: ИНТЕРЬЕР ЗДАНИЯ (комнаты/подземелья)
```

> В большинстве случаев интерьер — это не отдельная сцена, а набор строительных элементов в основной локации (см. `TILE_SYSTEM.md` §13 «Свободное строительство»). Полноценные подлокации (отдельные сцены) используются только для подземелий, специальных данжей и измерений.

## 3. Виды переходов

| Тип перехода | Направление | Триггер | Время загрузки |
|--------------|-------------|---------|----------------|
| World → Location | Вглубь | Клик/вход в сектор | Среднее |
| Location → World | Наружу | Выход/телепорт | Быстрое |
| Location → Building | Вглубь | Вход в дверь | Быстрое (или мгновенное, если дом — часть локации) |
| Building → Location | Наружу | Выход из двери | Быстрое |
| Телепортация | Любой | Техника/предмет | Мгновенное |
| Измерение | Спец. | Формация/ритуал | Долгое |

## 4. Переход: карта мира → локация

### 4.1 Триггеры входа

**Кнопка «Войти в локацию»** — основной способ. Игрок выбирает локацию в секторе и подтверждает вход.

**Пересечение границы** — автоматический вход при перемещении в сектор с обязательным входом:
- подземелья (dungeons);
- города (cities);
- места силы (power spots);
- случайные события (random encounters).

**Диалог/NPC** — квестовый NPC может отправить игрока в конкретную локацию:
- квестовый NPC → данж;
- торговец → лавка;
- стражник → город.

### 4.2 Сохранение позиции на карте мира

При входе в локацию сохраняется:

```
WorldMapPosition {
    sectorId: "forest_03_12",        // ID сектора
    coordinates: { x: 156, y: 89 },  // Позиция в секторе (м)
    facing: Direction.South,         // Направление взгляда
    timestamp: 1864_05_12_14_30,     // Игровое время
}
```

Зачем нужно:
- при выходе из локации вернуться в ту же точку;
- продолжить путешествие с того же места;
- корректное сохранение игры.

### 4.3 Пайплайн загрузки локации

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  Trigger │ ──►│  Save    │ ──►│  Load    │ ──►│  Spawn   │
│  Entry   │    │  State   │    │  Scene   │    │  Player  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
     │               │               │               │
     ▼               ▼               ▼               ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│Определить│    │Сохранить │    │Загрузить │    │Разместить│
│ тип входа│    │позицию   │    │ассеты    │    │игрока    │
│          │    │на карте  │    │сцены     │    │в точке   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
     │                               │
     │                               ▼
     │                         ┌──────────┐
     │                         │ Generate │
     │                         │ Objects  │
     │                         └──────────┘
     │                               │

┌──────────────────────────────────────────────────────────────┐
│                      ЭТАПЫ ГЕНЕРАЦИИ                          │
```

### 4.4 Анимация перехода

- **Затемнение (Fade):** 0.3 с затемнение → 0.5 с загрузочный экран → 0.8 с появление локации.
- **Тематическая анимация:** спиральный вихрь (cultivation theme), подходящий под эстетику сянси.

## 5. Переход: локация → карта мира

### 5.1 Триггеры выхода

- нажатие кнопки «Выйти на карту мира»;
- достижение границы локации (ворота, выходы);
- использование телепорта на карту;
- смерть (respawn на карте мира в безопасной точке).

### 5.2 Сохранение состояния локации

```
Иерархия персистентности:

ПЕРСИСТЕНТНЫЕ (сохраняются всегда):
• Собранные ресурсы (руды исчезают)
• Открытые сундуки (остаются пустыми)
• Убитые боссы (не респавнятся)
• Разрушенные объекты
• Квестовые триггеры

ПОЛУ-ПЕРСИСТЕНТНЫЕ (таймер памяти):
• Обычные враги (респаун через время)
• Ресурсы (регенерация)
• NPC (возвращение на места)

НЕПЕРСИСТЕНТНЫЕ (сбрасываются):
• Позиция игрока (возвращение в точку входа)
• Временные эффекты
• Боевые состояния
```

### 5.3 Таймер «памяти» локации

Когда игрок покидает локацию, её состояние «помнится» определённое игровое время. После этого — частичный сброс.

| Тип локации | Время памяти | Что сбрасывается |
|-------------|--------------|-------------------|
| Город | ∞ (вечно) | Ничего (полная персистентность) |
| Деревня | 7 дней | NPC возвращаются |
| Дикие земли | 3 дня | Враги респавнятся |
| Подземелье | ∞ (вечно) | Прогресс сохраняется |
| Данж (проходимый) | 24 часа | Полный сброс |
| Данж (рейдовый) | 7 дней | Полный сброс |
| Место силы | 1 день | Ресурсы регенерируют |
| Измерение | 0 (сброс) | Полный сброс при выходе |

**Формула респавна врагов:**

```
respawnTime = baseTime × (1 + playerLevel / 10)

Пример:
baseTime = 3 дня
playerLevel = 4
respawnTime = 3 × (1 + 0.4) = 4.2 дня
```

**Обоснование:** чем сильнее игрок, тем дольше «след» его присутствия.

**Лор:** «Мир культивации обладает памятью. Места, где практик проявил свою волю, дольше сохраняют его отпечаток. Но Ци мира постепенно смывает следы, и жизнь возвращается в привычное русло.»

## 6. Путешествие между локациями (дикие земли)

> **Главная концепция:** между локациями внутри сектора лежат «дикие земли», которые **не загружаются как сцены**. Путешествие происходит через **travel screen** с анимацией пути и игровым временем.

### 6.1 Вариант 1: мгновенный переход

- Триггер → подтверждение → загрузка.
- Для коротких расстояний (< 1 км).
- Внутри одной локации (двери, порталы).

### 6.2 Вариант 2: путешествие во времени

- Расчёт времени: `расстояние × скорость × модификаторы`.
- Экран загрузки с анимацией пути.
- Возможность случайной встречи (encounter).
- Прибытие в целевую локацию.

```
Пример расчёта:
Город → Деревня: 3 км
Скорость пешком: 5 км/ч
Модификатор дороги: ×1.2 (хорошая дорога)
Итог: 3 / 5 × 1.2 = 0.72 ч = 43 минуты игрового времени
```

### 6.3 Вариант 3: карта мира (быстрое путешествие)

- Из меню карты → выбор известной локации.
- Только если локация уже посещена или известна.
- Требует времени (игрового) и ресурсов (Ци/деньги).
- Мастера могут телепортироваться (техники).

### 6.4 Случайные встречи

| Фактор | Шанс встречи | Тип встреч |
|--------|--------------|------------|
| Безопасная дорога | 5% | Торговцы, странники |
| Обычная дорога | 15% | Бандиты, звери |
| Опасная территория | 30% | Враги, духи |
| Ночная дорога | +10% | Призраки, демоны |
| Дождь/Туман | +5% | Скрытые угрозы |
| Охрана/Конвой | −10% | Меньше инцидентов |

При срабатывании встречи загружается **временная боевая сцена** — фрагмент диких земель с врагами. После боя игрок продолжает путь (или возвращается на карту мира).

## 7. Переход: локация → здание (интерьер)

### 7.1 Входы в здания

| Тип здания | Примеры | Особенности входа |
|------------|---------|-------------------|
| Жилое | Дом, таверна | Открытый вход |
| Торговое | Лавка, рынок | Часы работы |
| Культурное | Храм, библиотека | Требования (уровень) |
| Военное | Казарма, арена | Ранг/фракция |
| Секретное | Склад, тайник | Ключ/пароль |
| Данж-здание | Руины, склеп | Квест/уровень |

### 7.2 Загрузка интерьера

```
Пайплайн:
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ Проверка │ ──►│ Сохран.  │ ──►│ Загрузка │ ──►│ Размещ.  │
│ доступа  │    │ позиции  │    │ сцены    │    │ игрока   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

**Два режима загрузки:**

- **Быстрая (additive):** интерьер подгружается как дополнение. Основная локация не выгружается. Время: 0.2–0.5 сек. Используется, когда дом — набор элементов в основной локации (свободное строительство, см. `TILE_SYSTEM.md` §13).
- **Полная (replacement):** текущая локация выгружается, загружается сцена интерьера. Время: 0.5–1.5 сек. Используется для подземелий, измерений, больших данжей.

### 7.3 Условия входа

| Условие | Тип здания | Сообщение при отказе |
|---------|------------|----------------------|
| Нет требований | Жилое | — (вход свободен) |
| Часы работы | Торговое | «Закрыто. Приходите утром.» |
| Уровень культивации | Храм | «Требуется L3 для входа.» |
| Членство фракции | Казарма | «Только для членов секты.» |
| Ключ/предмет | Тайник | «Заперто. Нужен ключ.» |
| Квест | Данж | «Требуется квест.» |
| Плата | VIP-зал | «Вход: 100 дух. камней.» |

## 8. Переход: здание → локация

### 8.1 Типы выходов

1. **Основной выход:** дверь, через которую вошли. Всегда доступна (если не заперта).
2. **Альтернативный выход:** чёрный ход, окно, потайной ход. Может вести в другое место локации.
3. **Телепорт-выход:** портал в конце данжа, телепорт к входу здания.
4. **Экстренный выход:** при смерти, при использовании свитка возврата.

### 8.2 Возврат в точку входа

При выходе из здания игрок возвращается в ту же точку локации, где стоял при входе. Это обеспечивает связность и предсказуемость.

## 9. Телепортация

### 9.1 Виды телепортации

| Тип | Уровень | Дальность | Кулдаун | Описание |
|------|---------|-----------|---------|----------|
| Мигание (Blink) | L3+ | короткая (в локации) | 3 сек | Тактический рывок |
| Шаг Тени | L5+ | средняя | 10 сек | Скрытное перемещение |
| Полёт | L4+ | бесконечно | нет | Непрерывное движение |
| Телепортация | L7+ | 1 км | 5 мин | Стратегическое перемещение |
| Разрыв Пространства | L8+ | 50 км | 1 час | Дальняя телепортация |
| Марш Пустоты | L9+ | 500 км | — | Легендарная техника |

### 9.2 Кулдауны

| Телепорт | Базовый кулдаун | Снижение от уровня |
|----------|-----------------|---------------------|
| Мигание (Blink) | 3 сек | −0.5 сек / L выше L3 |
| Шаг Тени | 10 сек | −1 сек / L выше L5 |
| Полёт | нет | — |
| Телепортация | 5 мин | −30 сек / L выше L7 |
| Разрыв Пространства | 1 час | −5 мин / L выше L8 |
| Городской портал | 30 мин | — |
| Свиток возврата | 1 час | — |
| Камень призыва | 10 мин | — |

**Глобальный кулдаун:** после любой телепортации — 1 сек глобального кулдауна (предотвращает спам телепортов).

### 9.3 Лорное обоснование

> Мир культивации огромен — расстояния исчисляются тысячами километров. Обычные смертные путешествуют месяцами. Практики используют техники ускорения. Мастера могут телепортироваться на огромные расстояния.
>
> Переход с мировой карты в локацию — это «приземление» в конкретном месте для детального исследования или боя. Время на мировой карте течёт иначе: 1 секунда реального времени = 1 минута игрового времени (на стандартной скорости).

## 10. Специальные переходы

### 10.1 Измерения

- Доступ через формации или ритуалы.
- Опасные: можно потерять тело.
- Полный сброс при выходе.
- Уникальные ресурсы и враги.

### 10.2 Данжи

- Инстансы для группы (в будущей мультиплеер-версии).
- Прогресс сохраняется до полного прохождения.
- Босс в конце, уникальный лут.
- Кулдаун на повторный вход (7 дней для рейдовых).

## 13. Уникальные механики переходов (идеи)

### 13.1 Следы перехода (Transition Trails)

При телепортации L7+ остаётся «пространственный след»:
- виден другим практикам с навыком «Чувство пространства»;
- позволяет определить направление и уровень практика;
- исчезает через 1–24 часа (зависит от уровня).

### 13.2 Засады (Transition Ambush)

Игрок может подстерегать врагов в точках перехода:
- затаиться рядом с выходом/порталом;
- возможность внезапной атаки;
- защита: навык «Острое чутьё» обнаруживает засады;
- ограничение: нельзя в безопасных зонах.

### 13.3 Пробитие барьеров (Barrier Piercing)

- Локации защищены барьерами (L5–L9).
- Телепортация сквозь барьер: требует уровень > уровня барьера, расход Ци × 3, триггерит тревогу.
- Провал: отбрасывание + урон.

### 13.4 Временные разрывы (Temporary Rifts)

- Телепортация L8+ оставляет «разрыв» на 5–30 минут.
- Двусторонний портал, может использовать любой (включая врагов).
- Можно разрушить атакой по разрыву.

### 13.5 Запретные зоны

Некоторые места блокируют телепортацию:
- антимагические барьеры;
- священные земли богов;
- проклятые земли;
- территории Великих Формаций.

При попытке телепорта — сообщение: «Пространство здесь запечатано древней силой...»

## 14. Принципы системы переходов

1. **Travel-screens based, не open-world streaming.** Между локациями — travel screen с анимацией и игровым временем.
2. **Дикие земли процедурны.** Не загружаются как сцены; встречи — временные боевые сцены.
3. **Per-location scene loading.** Активна одна локация; переход — смена сцены.
4. **Таймер памяти.** Состояние локации «помнится» разное время в зависимости от типа.
5. **Точки входа/выхода.** У каждой локации несколько входов; игрок возвращается в точку выхода.
6. **Телепортация — игровая механика.** Доступна с L3+, кулдауны и глобальный 1-сек кулдаун.
