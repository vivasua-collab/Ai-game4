# План: отвязка персонажа от центра тайла

> **Статус:** Концепция
> **Дата:** 2026-08-15

## Принцип

1. **Логическая позиция** (PlayerService.Position, int) — меняется мгновенно, для игровой логики
2. **Визуальная позиция** (PlayerVisualService, float) — интерполируется к логической, для рендеринга
3. **Sprite2D** обновляется из визуальной позиции каждый кадр

## Этапы

| Этап | Что | Сложность |
|------|-----|-----------|
| 1 | PlayerVisualService + lerp | Низкая |
| 2 | Snap при спавне/телепорте | Низкая |
| 3 | Скорость lerp зависит от TimeSpeed | Средняя |
| 4 | Pixel-perfect движение | Высокая |
