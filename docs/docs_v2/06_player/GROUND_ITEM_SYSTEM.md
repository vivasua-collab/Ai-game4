# Предметы на земле (Ground Item System)

> **Назначение:** Движко-независимая спецификация механики предметов, выпавших в игровой мир и доступных для подбора.
>
> **Связанные документы:** [INVENTORY_SYSTEM.md](./INVENTORY_SYSTEM.md), [EQUIPMENT_SYSTEM.md](./EQUIPMENT_SYSTEM.md), [DEATH_AND_LOOT.md](../04_entities/DEATH_AND_LOOT.md), [PROCEDURAL_SPRITES.md](../07_ui/PROCEDURAL_SPRITES.md), [SAVE_SYSTEM.md](../05_data/SAVE_SYSTEM.md).

---

## 1. Когда используются

Предметы на земле появляются в трёх случаях:

1. **Overflow инвентаря по объёму** — при попытке добавить предмет, превышающий лимит объёма рюкзака, излишек автоматически выпадает на землю рядом с игроком.
2. **Trash zone (🗑)** — игрок перетаскивает предмет из инвентаря на иконку корзины в окне инвентаря; предмет выбрасывается на землю.
3. **Смерть NPC** — лут (экипировка, расходники) выпадает на землю рядом с трупом. См. [DEATH_AND_LOOT.md](../04_entities/DEATH_AND_LOOT.md).

---

## 2. Drop — выбрасывание предмета

### 2.1. Позиция в мире
- Предмет получает пиксельные координаты в игровом мире (не индекс тайла).
- Базовая позиция = позиция выбрасывающей сущности (игрок или NPC).

### 2.2. Random offset
- К финальной позиции добавляется случайное смещение в небольшом радиусе, чтобы несколько выпавших предметов не накладывались друг на друга.
- Offset детерминирован через `SeededRandom` (см. [PROCEDURAL_SPRITES.md §Кэширование](../07_ui/PROCEDURAL_SPRITES.md) и [ALGORITHMS.md](../09_workflow/ALGORITHMS.md)).

### 2.3. Событие
- При drop публикуется `ItemDroppedEvent` (полезная нагрузка: ID экземпляра предмета, позиция, источник).
- Подписчики: рендерер мира (отрисовка спрайта), система сохранения (игнорирует — save отключён).

---

## 3. Pickup — подбор предмета

### 3.1. Активация
- Игрок нажимает клавишу **E** находясь в радиусе **1.5 тайла** от ближайшего предмета на земле.
- Если в радиусе несколько предметов — выбирается ближайший.

### 3.2. Событийный поток
```
E pressed → InteractionService находит ближайший GroundItem
          → публикуется ItemPickedUpEvent
          → ItemPickedUpEvent трансформируется в ItemAddRequestEvent
          → InventoryService.TryAddItem(...)
             ├── успех → предмет удаляется с земли (GroundItemRemovedEvent)
             └── переполнение по объёму → предмет остаётся на земле,
                                          излишек инвентаря выпадает рядом
```

### 3.3. Циклический overflow
- Если при подборе инвентарь переполняется — предмет подбираться не будет; он остаётся лежать.
- Излишек инвентаря при добавлении выпадает рядом (как обычный drop).
- Объём не может быть превышен (overflow запрещён), в отличие от веса (overflow разрешён).

---

## 4. Trash zone (🗑)

### 4.1. Концепция
- Иконка корзины в окне инвентаря принимает drag&drop предметов.
- Принимает **только предметы из рюкзака** (не экипированные).
- Экипированные предметы должны быть сначала сняты в рюкзак, затем выброшены.

### 4.2. Поведение
- При drop на иконку 🗑 — предмет выпадает на землю рядом с игроком через стандартный механизм drop (§2).
- Предмет не уничтожается — он переходит из инвентаря в мир.

## 5. Спрайты

### 5.1. Размер и категория
- Размер спрайта: **16×16 пикселей**.
- Спрайт выбирается по **категории предмета** (8 категорий).

### 5.2. Восемь категорий
| # | Категория | Примеры предметов |
|---|-----------|-------------------|
| 1 | Оружие (weapon) | dagger, sword, axe, spear, greatsword, bow, staff |
| 2 | Броня (armor) | шлем, нагрудник, поножи, сапоги, перчатки, пояс |
| 3 | Аксессуар (jewelry) | кольцо, амулет |
| 4 | Расходник (consumable) | пилюли, свитки, еда |
| 5 | Материал (material) | руда, трава, кость |
| 6 | Камень Ци (qi_stone) | духовные камни |
| 7 | Свиток техники (technique_scroll) | обучающие свитки |
| 8 | Прочее (artifact/tool/implant/charger) | артефакты, инструменты, импланты, зарядники |

### 5.3. Процедурная генерация
- Спрайты рисуются в рантайме через Image API (без PNG-ассетов).
- Кэшируются по ключу категории после первого создания.
- См. [PROCEDURAL_SPRITES.md](../07_ui/PROCEDURAL_SPRITES.md) для общего принципа.

---

## 6. Сохранение

- **Save отключён** для предметов на земле.
- При сохранении игры состояние GroundItemService не сериализуется.
- При перезагрузке сцены все предметы на земле исчезают.
- Это сознательное решение: предметы на земле — временное состояние, не критичное для прогресса.

> См. [SAVE_SYSTEM.md §ISaveable](../05_data/SAVE_SYSTEM.md) — GroundItemService НЕ реализует `ISaveable`.
