# Развитие смертного (Mortal Development)

> **Назначение:** Документ описывает этапы развития смертного до пробуждения ядра культивации (L0 → L1) — теория дремлющего ядра, фазы пробуждения, типы пробуждения, историю первых культиваторов. Документ engine-agnostic: концепции и данные — без привязки к движку.

**Связанные документы:** `02_systems/QI_SYSTEM.md`, `02_systems/BREAKTHROUGH_MODELS.md`, `04_entities/ENTITY_TYPES.md`, `08_content/LORE_SYSTEM.md`, `08_content/START_LORE.md`.

## 1. Проблема и решение

> **Разрыв в лоре:** Как появились первые культиваторы, если ядро необходимо активировать? Смертный → ??? → Практик 1-го уровня.

### Решение: Этап 0 — Смертный

#### Теория Дремлющего Ядра

У каждого живого существа с душой есть **дремлющее ядро** — зачаток духовного центра, который может быть пробуждён.

## 3. Дремлющее ядро

### 3.1. Что это такое?

Дремлющее ядро — духовный центр, который есть у каждого смертного с рождения. Оно:
- Формируется в процессе роста организма.
- Накапливает естественную Ци из окружающей среды.
- Служит «спящим» аналогом активного ядра практика.

### 3.2. Сформированность ядра

| Уровень | Описание | Способность к пробуждению |
|---------|----------|---------------------------|
| 0–20% | Зачаток | Невозможно |
| 20–50% | Развивающееся | Крайне сложно (0.001%) |
| 50–80% | Сформированное | Сложно (0.1%) |
| 80–100% | Зрелое | Возможно (1–5%) |

### 3.3. Естественная ёмкость

Смертные могут накапливать Ци даже без активного ядра.

> **Важно:** Дремлющее ядро — НЕ микроядро практика. Микроядро (источник 10%/сутки) активируется ТОЛЬКО при пробуждении. У смертных Ци поступает **только через естественное медленное поглощение организмом** из окружающей среды — пассивный процесс, не требующий осознанного участия. См. `02_systems/QI_SYSTEM.md` §5.1.

| Возраст | Макс. Ци (условные единицы) |
|---------|----------------------------|
| Новорождённый | 1–5 |
| Ребёнок (7 лет) | 10–30 |
| Подросток (16 лет) | 50–100 |
| Взрослый (25 лет) | 100–200 |
| Зрелый (40 лет) | 80–150 |
| Старец (60+ лет) | 30–80 |

## 4. Пробуждение ядра

### 4.1. Тип 1: Естественное пробуждение (Спонтанное)

**Механизм:** Происходит без внешнего вмешательства, обычно в экстремальных условиях. Требует высокой сформированности ядра (≥90%).

**Условия:**
- Нахождение в зоне высокой плотности Ци.
- Эмоциональный/физический шок.
- Глубокая медитация (годы практики).

**Шанс:**
- Базовый: 0.01%.
- В зоне высокой плотности Ци: 0.1%.
- При критическом состоянии: 1%.

**Исторический контекст:** Первые культиваторы пробудились именно так — в местах силы (священные горы, источники, пещеры с высокой концентрацией Ци).

### 4.2. Тип 2: Направленное пробуждение (С помощью учителя)

**Механизм:** Практик направляет Ци в дремлющее ядро смертного, «зажигает» ядро извне. Самый надёжный способ.

**Требования к учителю:**
- Минимальный уровень: 3.0 (Пламя Внутреннего Огня).
- Тратит 10–30% своего Ци на пробуждение.

**Шанс успеха:**
- Сформированность 50–80%: 20–50%.
- Сформированность 80–100%: 60–90%.

### 4.3. Тип 3: Артефактное пробуждение (С помощью предмета)

**Механизм:** Использование специального артефакта — пилюли пробуждения, камня пробуждения, формации пробуждения.

| Тип артефакта | Эффективность | Редкость |
|---------------|---------------|----------|
| Пилюля пробуждения (низшая) | 5% шанс | Обычная |
| Пилюля пробуждения (высшая) | 30% шанс | Редкая |
| Камень пробуждения | 50% шанс | Эпическая |
| Формация пробуждения | 80% шанс | Легендарная |

### 4.4. Тип 4: Насильственное пробуждение (Опасное)

**Механизм:** Принудительная активация ядра. Высокий риск повреждения или смерти.

**Риски:**
- 30% — повреждение меридианов.
- 20% — безумие.
- 10% — смерть.

**Используется:** Тёмными сектами, в экстренных случаях, слишком амбициозными смертными.

## 5. История первых культиваторов

### 5.1. Эпоха До Пробуждения (до Э.С.М.)

**Мир до культивации:**
- Люди жили обычной жизнью.
- Знали о существовании Ци, но не могли управлять.
- Шаманы и мудрецы пытались контактировать с Ци.
- Легенды о «бессмертных» из древности.

### 5.2. Первое пробуждение

> В начале времён, когда мир был молод, Ци свободно текла по земле. В местах, где Ци собиралась в озёра, смертные могли случайно пробудиться. Первые практики не знали техник — они просто дышали в местах силы.

**Научная теория:**

1. **Период высокой плотности Ци:** Миллионы лет назад плотность Ци была значительно выше.
2. **Естественный отбор:** Случайные пробуждения происходили чаще.
3. **Накопление знаний:** Первые практики начали изучать свои способности.
4. **Создание техник:** Разработка методов помощи другим в пробуждении.
5. **Формирование сект:** Организованное обучение новым поколениям.

### 5.3. Семь Первых Пробудившихся

| Имя | История | Дар |
|-----|---------|-----|
| **Небесный Странник** | Пробудился на вершине священной горы | Техники перемещения |
| **Огненный Мудрец** | Пробудился в вулкане | Техники огня |
| **Тихая Река** | Пробудилась на дне священного озера | Техники воды |
| **Каменное Сердце** | Пробудился в пещере с кристаллами | Техники защиты |
| **Шёпот Ветра** | Пробудился во время бури | Техники воздуха |
| **Пустота** | Пробудился на границе мира | Техники пустоты |
| **Сердце Мира** | Пробудился в центре мира | Основатель Э.С.М. |

## 6. Механика перехода L0 → L1

### 6.1. Сравнение измерений

| Параметр | Смертный (L0) | Практик L1 |
|----------|---------------|------------|
| Ядро | Дремлющее (пассивное) | Активное (микроядро генерирует Ци) |
| Макс. Ци | 100–200 | 1 000+ |
| Регенерация Ци | Только естественное медленное поглощение организмом из среды | 10% `coreCapacity`/сутки (от микроядра) |
| Использование техник | Невозможно | Возможно |
| Продолжительность жизни | 70–100 лет | 100+ лет |
| Старение | Обычное | Замедленное |

## 7. Игровая механика

### 7.1. Стартовые варианты

| Вариант | Описание | Бонусы |
|---------|----------|--------|
| **Рождённый практиком** | Пробудился при рождении (редко) | — |
| **Естественное пробуждение** | Пробудился сам | +5% ко всем характеристикам |
| **Учительское пробуждение** | Стандартный путь | Без бонусов/штрафов |
| **Артефактное пробуждение** | С помощью пилюли | +50 начального Ци |
| **Насильственное пробуждение** | Рискованный путь | +1 случайная черта |

> **Решение:** `AwakeningType` НЕ даёт бонусов/штрафов к проводимости. Бонусы в этой таблице (+5% статов, +50 Ци, +1 черта) — TBD, будут продуманы в будущем.

### 7.2. Окно пробуждения

Возраст **16–40** — оптимальное время для пробуждения. После 50 лет шанс резко падает.

## 9. Структура данных

```
MortalDevelopmentState:
  age:                  int       // хронологический возраст (годы)
  chronologicalAge:     int       // для расчёта effectiveAge NPC
  coreFormation:        float     // 0.0..1.0 — сформированность дремлющего ядра
  dormantQi:            long      // накопленная Ци (малые значения 1..200)
  awakeningReadiness:   float     // вычисляется из coreFormation и шансов
  awakeningType:        AwakeningType?  // null если не пробуждён

AwakeningType (enum):
  Natural               // естественное
  TeacherGuided         // с помощью учителя
  Artifact              // с помощью артефакта
  Forced                // насильственное
  BornAwakened          // рождённый практиком
```

> При переходе L0→L1 событие `AwakeningEvent` публикуется через шину событий, триггерит: активацию микроядра (генерация 10%/сутки), установку `currentQi = dormantQi`, пересчёт `conductivity` (L1 multiplier), генерацию `AwakeningType`-бонусов (TBD).

## 10. Производительность

- Mortal development — медленный процесс, проверка готовности пробуждения выполняется только при значимых событиях (рост `coreFormation` на 5%+).
- Все данные — `long`/`float`, zero-GC.
- История «Семи Первых Пробудившихся» — лорный контент, не требует рантайм-вычислений.
