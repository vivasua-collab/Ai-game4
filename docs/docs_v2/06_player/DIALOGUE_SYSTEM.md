# Система диалогов (Dialogue System)

> **Назначение:** Движко-независимая спецификация диалогов игрока с мирными NPC: открытие, пауза, ролевые реплики, UI, возобновление.
>
> **Связанные документы:** [NPC_AI_SYSTEM.md](../04_entities/NPC_AI_SYSTEM.md), [NPC.md](../04_entities/NPC.md), [HOTKEYS.md](../07_ui/HOTKEYS.md), [UI_DESIGN.md](../07_ui/UI_DESIGN.md), [TIME_SYSTEM.md](../03_world/TIME_SYSTEM.md).

---

## 1. Принцип

### 1.1. Триггер
- Игрок подходит к мирному NPC на расстояние взаимодействия (≤ 1.5 тайла) и нажимает **E**.
- Публикуется `InteractionRequestEvent` → `InteractionService` определяет, что цель — мирный NPC, и открывает `DialogueWindow`.

### 1.2. Пауза
- При открытии диалога **игра ставится на паузу** (публикуется `GamePausedEvent`).
- Симуляция (тики, AI, бой) останавливается.
- Возобновление — при закрытии окна диалога (`GameResumedEvent`).

### 1.3. Условие диалога
- NPC должен быть **мирным**: диспозиция `Neutral`, `Friendly`, `Merchant` (НЕ `Hostile`).
- NPC должен быть жив.
- Роль NPC должна поддерживать диалог (см. §2). Enemy — не поддерживает (только бой).

> См. [NPC_AI_SYSTEM.md](../04_entities/NPC_AI_SYSTEM.md) §диспозиции.

## 2. Ролевые диалоги (7 ролей)

Каждый NPC имеет одну из 7 ролей. Роль определяет палитру реплик и предлагаемые действия.

| Роль | Назначение | Примеры реплик |
|------|-----------|----------------|
| **Торговец (Merchant)** | Предлагает товары | «Глянь мой товар», «Могу предложить пилюлю за 50 камней» |
| **Старейшина (Elder)** | Даёт советы, обучение | «Путь культивации долог...», «Помни о балансе Инь и Ян» |
| **Культиатор (Cultivator)** | Обсуждение практик | «Я тренирую технику Огня», «Твой уровень Ци растёт» |
| **Страж (Guard)** | Информация о безопасности | «В лесу замечены волки», «Будь осторожен ночью» |
| **Ученик (Student)** | Просьбы о помощи | «Помоги мне с тренировкой», «Где мне найти траву?» |
| **Прохожий (Passerby)** | Светская беседа | «Хорошая погода сегодня», «Слышал новости из столицы?» |
| **Враг (Enemy)** | Без диалога | (только бой) |

> Enemy всегда имеет диспозицию `Hostile` — E рядом с ним не открывает диалог, а триггерит боевой режим.

## 3. UI: DialogueWindow

### 3.1. Структура окна
```
┌─────────────────────────────────────────┐
│  [NPC портрет]  Имя NPC (роль)          │
│─────────────────────────────────────────│
│                                         │
│  Текст NPC (typewriter effect):        │
│  «Приветствую, странник. Что тебя      │
│   привело в нашу деревню?»             │
│                                         │
│─────────────────────────────────────────│
│  Варианты ответов:                     │
│   1. Расскажи о деревне.               │
│   2. Где я могу найти учителя?         │
│   3. Я хочу торговать.                 │
│   4. Прощай.                           │
│                                         │
└─────────────────────────────────────────┘
```

### 3.2. Варианты ответов
- От **1 до 4** вариантов одновременно.
- Выбор — клик мыши или клавиша **1–4**.
- Каждый вариант ведёт к:
  - следующей реплике NPC (branch),
  - действию (открыть торговлю, выдать квест, завершить диалог),
  - завершению диалога.

### 3.3. Завершение диалога
- Закрытие окна: ESC, клавиша-выход, или выбор варианта «Прощай».
- При закрытии публикуется `DialogueEndedEvent` → `GameResumedEvent`.

## 4. Пауза и возобновление

### 4.1. Состояние паузы
- `GamePausedEvent` останавливает `TimeService` (tick-rate = 0).
- AI NPC, бой, движение животных — замораживаются.
- UI остаётся активным (диалоговое окно принимает ввод).

### 4.2. Возобновление
- При `DialogueEndedEvent` публикуется `GameResumedEvent`.
- Симуляция возвращается к предыдущей скорости (normal / fast / quick / superSuperSlow).
- Если до паузы шёл бой — возвращается боевая скорость `superSuperSlow`.

> См. [TIME_SYSTEM.md](../03_world/TIME_SYSTEM.md) для скоростей симуляции.

## 5. Typewriter-эффект (опционально)

### 5.1. Принцип
- Текст NPC появляется посимвольно (эффект печатающейся машинки).
- Скорость: ~30 символов в секунду (настраиваемо).

### 5.2. Пропуск
- Любой ввод (клик / клавиша / пробел) мгновенно показывает весь текст.
- После полного текста — варианты ответов становятся активными.

### 5.3. Отключаемость
- Typewriter можно отключить в настройках (мгновенный показ текста).
- По умолчанию — включён.

## 6. События

| Событие | Когда | Кто слушает |
|---------|-------|-------------|
| `DialogueStartedEvent` | Открытие окна | TimeService (pause), UIService |
| `DialogueChoiceSelectedEvent` | Игрок выбрал вариант | DialogueService (перейти к branch) |
| `DialogueEndedEvent` | Закрытие окна | TimeService (resume), UIService |
| `InteractionCompletedEvent` | Завершение взаимодействия (диалог/торговля/квест) | QuestModule, NPCModule |

> Контракты — `readonly struct`. См. [DI_AND_EVENTBUS.md §2.3](../01_architecture/DI_AND_EVENTBUS.md) (DialogueContracts: 4 события).
