# Система инвентаря

> **Назначение:** Движко-независимая спецификация инвентаря игрока. Описывает модель хранения предметов, структуру экрана инвентаря, механику drag&drop и взаимодействия.
>
> **Связанные документы:** `EQUIPMENT_SYSTEM.md`, `07_ui/UI_DESIGN.md`, `07_ui/HOTKEYS.md`, `02_systems/BODY_SYSTEM.md`, `05_data/DATA_MODELS.md`.

---

## 1. Обзор

Инвентарь — это совокупность трёх мест хранения предметов у персонажа:

1. **Рюкзак (Backpack)** — основное переносное хранилище. Строчная модель: список предметов + ограничения по массе и объёму. Размер определяется типом рюкзака (улучшаемый).
2. **Кукла тела (Body Doll)** — слоты экипировки на теле персонажа. Принцип: **1 слот = 1 предмет**.
3. **Духовное хранилище (Spirit Storage)** + **Кольцо хранения (Storage Ring)** — вне-пространственные хранилища, доступные из любой локации при выполнении условий разблокировки.

Открытие/закрытие панели инвентаря — горячая клавиша **B** (см. `07_ui/HOTKEYS.md`).

## 2. Строчная модель предметов (line model)

> Решение зафиксировано как каноническое. Альтернативная сеточная модель (Tetris-style `posX/posY`, `sizeWidth × sizeHeight`) отложена и не реализуется в v1.

### 2.1. Поля предмета

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Уникальный идентификатор экземпляра |
| `nameId` | string | ID пресета (для поиска в реестре) |
| `name` | string | Локализованное название |
| `description` | string | Лорное описание |
| `type` | ItemType | Тип предмета (см. §2.3) |
| `category` | ItemCategory | Базовый класс (Consumable/Equipment/Material/QiStone/TechniqueScroll) |
| `rarity` | Rarity | Редкость (Common…Mythic, 6 уровней) |
| `icon` | string | Эмодзи-символ или путь к ассету-иконке |
| `quantity` | int | Текущее количество в стаке |
| `maxStack` | int | Максимум в одном стаке |
| `stackable` | bool | Можно ли стакать |
| `weight` | float | Масса в кг (ключевое ограничение рюкзака) |
| `volume` | float | Объём в условных единицах (ключевое ограничение кольца хранения) |
| `allowNesting` | enum | `none` / `spirit` / `ring` / `any` — куда можно поместить |
| `value` | int | Базовая стоимость в духовных камнях |

> Полей `sizeWidth`, `sizeHeight`, `posX`, `posY` в модели **нет**. Позиция предмета в рюкзаке задаётся порядковым индексом в списке.

### 2.2. Базовые классы предметов (5)

| Базовый класс | Подкатегории |
|---------------|--------------|
| Consumable | consumable |
| Equipment | weapon, armor, jewelry, charger, tool, artifact, implant |
| Material | material |
| Qi Stone | qi_stone |
| Technique Scroll | technique_scroll |

### 2.3. Типы предметов (11 подтипов)

`weapon`, `armor`, `jewelry`, `charger`, `tool`, `consumable`, `artifact`, `implant`, `material`, `qi_stone`, `technique_scroll`.

### 2.4. Редкость

| Редкость | Цвет рамки | Множитель стоимости |
|----------|------------|---------------------|
| Common | Серый | ×1 |
| Uncommon | Зелёный | ×2 |
| Rare | Синий | ×5 |
| Epic | Фиолетовый | ×15 |
| Legendary | Золотой | ×50 |
| Mythic | Красный | ×200 |

### 2.5. Объём предмета (по умолчанию)

| Категория | Объём (ед.) |
|-----------|-------------|
| Расходники (пилюли, свитки) | 0.1 |
| Кольца, амулеты | 0.1–0.3 |
| Еда, травы | 0.5 |
| Ингредиенты, материалы | 0.5–1 |
| Лёгкое оружие (кинжалы) | 1 |
| Среднее оружие (мечи) | 2 |
| Броня (перчатки, сапоги) | 1–2 |
| Тяжёлое оружие (двуручное) | 3–4 |
| Тяжёлая броня (нагрудник) | 3–4 |
| Рюкзак | 2–5 |
| Кольцо хранения | 0.3 |

### 2.6. Флаг вложения (`allowNesting`)

| Значение | Описание |
|----------|----------|
| `none` | Нельзя поместить ни в какое вне-пространственное хранилище (живые существа, квестовые предметы) |
| `spirit` | Только в духовное хранилище |
| `ring` | Только в кольцо хранения |
| `any` | В любое из двух (по умолчанию для обычных предметов) |

## 3. Рюкзак (Backpack)

### 3.1. Концепция

Рюкзак — это отдельная система персонажа (не слот экипировки на кукле). Игрок может сменить рюкзак, но не может носить два одновременно. При смене рюкзака содержимое старого сохраняется внутри него как контейнер.

### 3.2. Параметры рюкзака

| Поле | Описание |
|------|----------|
| `id` | ID рюкзака |
| `name` | Название |
| `slotCount` | Количество слотов (стартовый — 15) |
| `maxWeight` | Максимальная переносимая масса, кг |
| `maxVolume` | Максимальный объём, ед. |
| `weightReduction` | Снижение веса содержимого, % |
| `beltSlots` | Дополнительные слоты быстрого доступа (0–4) |

### 3.3. Стартовый рюкзак

| Параметр | Значение |
|----------|----------|
| Название | Тканевая сумка |
| `slotCount` | **15** |
| `maxWeight` | 30 кг |
| `maxVolume` | 30 ед. |
| `weightReduction` | 0% |
| `beltSlots` | 0 |

### 3.4. Примеры рюкзаков (дальнейшее расширение)

| Рюкзак | Слотов | Снижение веса | Бонус кг | Слотов пояса |
|--------|--------|---------------|----------|--------------|
| Тканевая сумка | 15 | 0% | +0 | 0 |
| Кожаный ранец | 20 | 10% | +10 | 1 |
| Железный контейнер | 25 | 15% | +20 | 2 |
| Духовный мешок | 36 | 25% | +30 | 2 |
| Межпространственный сундук | 56 | 40% | +50 | 4 |

### 3.5. Эффективный вес

```
effectiveWeight = Σ(item.weight × item.quantity) × (1 − backpack.weightReduction)
```

### 3.6. Смена рюкзака

- При смене на непустой рюкзак: содержимое остаётся внутри старого (старый рюкзак становится предметом-контейнером).
- При надевании нового: если целевой слот не помещается по `maxWeight`/`maxVolume` — операция отменяется, подсвечивается красным.

## 4. Кукла тела (Body Doll)

### 4.1. Слоты экипировки (15)

> Принцип: **1 слот = 1 предмет**. Система слоёв экипировки (Матрёшка v1 — несколько предметов в один слот) упразднена.

| # | Слот | ID | Описание | Статус |
|---|------|-----|----------|--------|
| 1 | Голова | `head` | Шлем, корона, шапка | ✅ Активен |
| 2 | Торс | `torso` | Нагрудник, кираса, роба | ✅ Активен |
| 3 | Пояс | `belt` | Пояс, кушак (НЕ зарядник) | ✅ Активен |
| 4 | Ноги | `legs` | Поножи, штаны | ✅ Активен |
| 5 | Ступни | `feet` | Сабатоны, сапоги | ✅ Активен |
| 6 | Основная рука | `weapon_main` | Одноручное оружие, щит | ✅ Активен |
| 7 | Вторичная рука | `weapon_off` | Одноручное оружие, щит, инструмент | ✅ Активен |
| 8 | Амулет | `amulet` | Ожерелье, колье | 🔒 Заглушка |
| 9 | Кольцо лев. 1 | `ring_left_1` | Кольцо | 🔒 Заглушка |
| 10 | Кольцо лев. 2 | `ring_left_2` | Кольцо | 🔒 Заглушка |
| 11 | Кольцо прав. 1 | `ring_right_1` | Кольцо | 🔒 Заглушка |
| 12 | Кольцо прав. 2 | `ring_right_2` | Кольцо | 🔒 Заглушка |
| 13 | Зарядник Ци | `charger` | Пояс-накопитель, браслет | 🔒 Заглушка |
| 14 | Кисти | `hands` | Перчатки, боевые перчатки | 🔒 Заглушка |
| 15 | Спина | `back` | Плащ, ранец | 🔒 Заглушка |

### 4.2. Правила экипировки

1. Каждый слот вмещает **один** предмет (кроме двуручного оружия).
2. **Двуручное оружие** занимает одновременно `weapon_main` и `weapon_off`. Второй слот блокируется и не принимает предметы.
3. **Зарядник** — один на персонажа (слот `charger`).
4. **Кольца** — максимум 4 (по 2 на каждую руку), при условии что слоты разблокированы.
5. **Амулет** — только 1 (слот `amulet`).
6. Перед экипировкой проверяются **требования** (уровень культивации, мин. сила/ловкость, совместимые виды, требуемые части тела). При невыполнении — операция запрещена.
7. Слоты-заглушки (🔒) не отображаются в UI v1 и не принимают предметы; они зарезервированы под будущее расширение (ювелирная система, зарядники, перчатки, плащи).

### 4.3. Силуэт тела (Body Silhouette)

- Визуальное представление куклы — **процедурный силуэт** (генерируется кодом, не требует художественного ассета).
- Части тела кликабельны, цветовая индикация состояния (см. `02_systems/BODY_SYSTEM.md`): здоровая / повреждена / изуродована / парализована / критическое / отрублена.
- При наведении мыши на часть тела показывается тултип с её HP и статусом.

## 5. Духовное хранилище (Spirit Storage)

### 5.1. Концепция

Вне-пространственное хранилище («межмировая складка»). Используется для долгосрочного хранения предметов, не помещающихся в рюкзак или не нужных «под рукой».

### 5.2. Характеристики

| Параметр | Значение |
|----------|----------|
| Размер | Без ограничений |
| Представление | Каталогизатор (список с фильтрацией), НЕ сетка |
| Доступ | Из любой локации |
| Разблокировка | Уровень культивации 3 (Пробуждённое Ядро → Пламя Внутреннего Огня) |

### 5.3. Стоимость использования

| Ресурс | Формула | Примечание |
|--------|---------|------------|
| Ци | `baseCost + weight × costPerKg` | Зависит от массы предмета |
| Время | ~2 сек | Время «открытия отверстия» в складку |

- Качество предмета не влияет на стоимость.
- На ранних уровнях (мало Ци) — ограничивающий фактор.
- На поздних уровнях — несущественно.

### 5.4. Каталогизатор

Вместо сетки — список с группировкой, фильтрацией и поиском:

- **Фильтр по типу** (оружие / броня / материалы / расходники / свитки / камни Ци).
- **Фильтр по редкости** (Common…Mythic).
- **Фильтр по весу** (лёгкие / средние / тяжёлые).
- **Текстовый поиск** по названию.
- **Сортировка** по типу / редкости / весу / дате помещения.

## 6. Кольцо хранения (Storage Ring)

### 6.1. Концепция

Альтернативный механизм вне-пространственного хранения. Кольцо надевается на слот кольца на кукле. Объём **ограничен**.

### 6.2. Характеристики

| Параметр | Значение |
|----------|----------|
| Слотов на кукле | 1–2 (кольцо на левой/правой руке) |
| Объём | Ограничен (зависит от качества кольца) |
| Доступ | Из любой локации (кольцо при себе) |
| Разблокировка | Наличие кольца хранения в инвентаре |

### 6.3. Стоимость использования

| Ресурс | Формула | Примечание |
|--------|---------|------------|
| Ци | `baseCost + volume × costPerUnit` | Зависит от ОБЪЁМА предмета |
| Время | ~1.5 сек | Быстрее, чем духовное хранилище |

### 6.4. Примеры колец хранения

| Кольцо | Объём | Стоимость извлечения |
|--------|-------|----------------------|
| Кольцо-щель | 5 | 5 + volume × 3 |
| Кольцо-карман | 15 | 5 + volume × 2 |
| Кольцо-кладовая | 30 | 5 + volume × 1 |
| Кольцо-пространство | 60 | 5 + volume × 0.5 |

### 6.5. Взаимодействие духовного хранилища и кольца

Обе системы существуют одновременно. Правила вложения запрещают:

1. **Кольцо хранения → Духовное хранилище** (кольцо — самостоятельный артефакт, его содержимое не вкладывается в складку). `allowNesting = none` для колец хранения.
2. **Кольцо хранения → Другое кольцо хранения** (пространственная нестабильность).
3. **Духовное хранилище → Кольцо хранения** (извлечение возможно только в рюкзак или руки).
4. **Обычный предмет** перемещается в соответствии с флагом `allowNesting`.

```
Рюкзак ↔ Кукла ↔ Руки
    ↕              ↕
Дух. хранилище    Кольцо хранения

Запрещено:
  Дух. хранилище  ✗→ Кольцо хранения
  Кольцо хранения ✗→ Дух. хранилище
  Кольцо хранения ✗→ Кольцо хранения
```

## 7. Пояс быстрого доступа (Quick Access Belt)

### 7.1. Концепция

Пояс — особый слот экипировки на кукле (`belt`). Тип надетого пояса определяет, сколько слотов быстрого доступа доступно для расходников.

| Тип пояса | Слотов | Назначение |
|-----------|--------|------------|
| Обычный ремень | 0 | Без функций |
| Пояс зелий | 2–4 | Быстрый доступ к расходникам |
| Пояс-зарядник | 0 | Даёт зарядник Ци |
| Комбинированный | 2 + зарядник | Смешанный |

### 7.2. Ограничения

- Только расходники (пилюли, свитки, еда).
- После использования предмет удаляется из слота.
- Если слот пуст — горячая клавиша игнорируется.

## 8. Drag & Drop

### 8.1. Базовые правила

- **Захват предмета:** клик левой кнопкой мыши.
- **Перемещение:** удержание + движение мыши. Захваченный предмет визуально увеличивается (~1.1×) и следует за курсором.
- **Отпускание:**
  - В валидную позицию — предмет перемещается.
  - На занятый слот — предметы меняются местами (swap), если совместимы.
  - Мимо панели — предмет выпадает на землю (drop в мир).
- Подсветка валидных слотов — зелёная рамка, невалидных — красная.

### 8.2. Маршруты перетаскивания

| Откуда → Куда | Поведение |
|---------------|-----------|
| Рюкзак → Рюкзак | Перемещение / swap / стак |
| Рюкзак → Кукла | Экипировка (если требования выполнены) |
| Кукла → Рюкзак | Снять предмет |
| Рюкзак → Пояс | Назначить в быстрый слот (только расходники) |
| Рюкзак → Дух. хранилище | Переместить (списать Ци, ~2 сек) |
| Рюкзак → Кольцо хранения | Переместить (проверка объёма + Ци, ~1.5 сек) |
| Лут → Рюкзак игрока | Забрать |
| Рюкзак игрока → Лут | Выбросить на труп |

### 8.3. Альтернативные способы переноса

- **Shift + клик** — переместить предмет в доступное вне-пространственное хранилище (если оба доступны — показать диалог выбора).
- **Ctrl + клик** — разделить стек (открыть диалог «сколько перенести»).
- **Delete** на выбранном предмете — выбросить.
- **Правый клик** — контекстное меню (см. §9).

## 9. Контекстное меню

Открывается по правому клику на предмет (или по удержанию правой кнопки мыши ≥ 300 мс — см. `07_ui/HOTKEYS.md`).

| Действие | Условие |
|----------|---------|
| Экипировать | Предмет экипируемый, не надет, требования выполнены |
| Снять | Предмет надет на персонаже |
| Использовать | Предмет расходуемый |
| В духовное хранилище | `allowNesting = spirit` или `any`, достаточно Ци |
| В кольцо хранения | `allowNesting = ring` или `any`, есть место, достаточно Ци |
| Разделить стек | `quantity > 1` и `stackable = true` |
| Выбросить | Любой предмет |
| Подробнее | Открыть расширенный тултип |

## 10. Тултип предмета

При наведении на предмет показывается карточка:

```
┌──────────────────────────┐
│ ★★ Меч Рассвета          │  ← Редкость (цвет рамки, звёздочки ★)
│ Редкий  │  Меч           │
│──────────────────────────│
│ Урон: 45                 │  ← Боевые параметры
│ Скорость: 1.2            │
│ Пробитие: 15%            │
│──────────────────────────│
│ Материал: Сталь (T2)     │  ← Матрёшка: база + материал + грейд + зачарование
│ Грейд: Улучшенный        │
│ Прочность: 78/120 (65%)  │
│──────────────────────────│
│ Объём: 2  │  Вес: 2.5 кг │  ← Характеристики хранения
│ Вложение: Любое          │
│──────────────────────────│
│ +5% шанс крита           │  ← Бонусы
│ +3 сила                  │
│──────────────────────────│
│ Требования:              │
│   Культивация: 2+        │
│   Сила: 12+              │
│──────────────────────────│
│ "Выкован на рассвете..." │  ← Лорное описание
│ Стоимость: 500 камней    │
└──────────────────────────┘
```

Количество звёздочек `★` в заголовке соответствует уровню редкости (1–6).

## 12. Горячие клавиши (инвентарь)

| Клавиша | Действие |
|---------|----------|
| **B** | Открыть/закрыть инвентарь |
| **E** | Контекстное действие (подобрать предмет, открыть сундук, осмотреть труп) |
| **1–4** | Использовать предмет из пояса быстрого доступа (если слоты есть) |
| **ЛКМ** | Выбрать / перетащить предмет |
| **ПКМ** (короткий) | Открыть контекстное меню предмета |
| **Shift + клик** | Переместить в доступное вне-пространственное хранилище |
| **Ctrl + клик** | Разделить стек |
| **Delete** | Выбросить выбранный предмет |

## 13. Окно лута (Loot Window)

При взаимодействии с трупом NPC (клавиша **E** в радиусе 1.5 м) открывается окно лута. Подробно механика описана в `04_entities/NPC.md` (раздел смерти/лута), здесь — кратко:

- **Кукла NPC** отображается со всей надетой экипировкой. Снятие — кликом или через контекстное меню.
- **Рюкзак NPC** показывается как список предметов (та же строчная модель).
- Кнопки: «Забрать всё», «Забрать экипировку», «Закрыть».
- Окно инвентаря игрока открывается рядом, поддерживается drag&drop между окнами.
- Таймер исчезновения лута: обычный NPC — 5 минут, босс — 15 минут, уникальный/сюжетный — 30 минут.

Что НЕ лутается:
- Духовное хранилище NPC (уходит с душой).
- Техники (это знания души, не предметы).
- Содержимое колец хранения (уходит в складку; само кольцо лутается как предмет).

## 14. Состояние предметов

Экипировка с трупов может быть повреждена (см. `EQUIPMENT_SYSTEM.md` §4):

- Оружие: прочность −5…−20%.

## 16. Глобальный вес (инвентарь + экипировка)

> Канонический документ для механики #2 из [GAMEPLAY_MECHANICS.md](../02_systems/GAMEPLAY_MECHANICS.md).

Вес персонажа = вес предметов в инвентаре + вес надетой экипировки. Оба компонента влияют на штраф скорости.

### 16.1. Расчёт общего веса

```
totalWeight = inventoryWeight + equipmentWeight

inventoryWeight = Σ(item.weight × item.quantity) × (1 − backpack.weightReduction)
equipmentWeight = Σ(equippedItem.weight)   // без weightReduction
```

- **Инвентарь:** суммарный вес всех предметов (включая стаки), с учётом `weightReduction` рюкзака (см. §3.5).
- **Экипировка:** суммарный вес надетых предметов (оружие, броня, аксессуары, пояс) — без скидки.
- **Максимум:** базовый (50 кг) + бонусы рюкзака (`backpack.maxWeight`).

### 16.2. Штраф экипировки (MoveSpeedPenalty)

Тяжёлая броня даёт отрицательный процент (например, нагрудник −15%, поножи −5%). Применяется всегда, даже без перевеса.

```
moveSpeedMult *= (1.0 + equipmentPenalty)   // equipmentPenalty ∈ [−0.5, 0]
```

- Штраф суммируется по всем надетым предметам экипировки.
- Применяется до проверки перевеса (независимо от него).

### 16.3. Штраф перевеса

Если `totalWeight > maxWeight`, скорость дополнительно снижается:

```
ratio = (totalWeight - maxWeight) / maxWeight   // cap 3.0
speedMult *= 1.0 / (1.0 + ratio)
```

- При 2× перевесе (`ratio = 1.0`) → `speedMult ×= 0.5` (половина скорости).
- При 4× перевесе (`ratio = 3.0`, cap) → `speedMult ×= 0.25` (четверть скорости).
- `ratio` ограничен сверху 3.0 — даже при экстремальном перевесе скорость не падает ниже 0.25×.

### 16.4. Объём

- Объём инвентаря ограничен (`backpack.maxVolume`, по умолчанию 30 ед.).
- При переполнении по объёму — излишек **выпадает на землю** (через [GROUND_ITEM_SYSTEM.md §2](./GROUND_ITEM_SYSTEM.md)).
- **Вес может превышать максимум** (overflow разрешён — см. §16.3 штраф).
- **Объём не может быть превышен** (overflow запрещён — излишек сразу выпадает).

### 16.5. Итоговая формула скорости

```
finalSpeedMult = baseSpeed
               × (1.0 + equipmentPenalty)         // штраф экипировки
               × (1.0 / (1.0 + overburdenRatio))  // штраф перевеса (если есть)
```

> См. также [EQUIPMENT_SYSTEM.md §4](./EQUIPMENT_SYSTEM.md) — свойства предметов экипировки, влияющие на вес/штраф.
