# Система экипировки

> **Назначение:** Движко-независимая спецификация экипировки персонажа — оружия, брони, украшений, зарядников Ци, артефактов, инструментов. Описывает архитектуру генерации «Матрёшка», грейды, материалы, прочность, бонусы и зачарование.
>
> **Связанные документы:** `INVENTORY_SYSTEM.md`, `02_systems/BODY_SYSTEM.md`, `02_systems/COMBAT_SYSTEM.md`, `02_systems/QI_SYSTEM.md`, `02_systems/BUFF_MODIFIERS_SYSTEM.md`, `05_data/CONFIGURATIONS.md`.

---

## 1. Обзор

Экипировка — это предметы, надеваемые на слоты куклы тела (см. `INVENTORY_SYSTEM.md` §4). Каждая экипировка описывается четырёхслойной моделью генерации «Матрёшка», к которой может добавляться пятый слой — зачарование.

> **Важно:** «Матрёшка» — это архитектура **ГЕНЕРАЦИИ** предметов (База × Материал × Грейд × Зачарование), а **не** система слоёв экипировки. Слои экипировки (несколько предметов в один слот) упразднены. Принцип: **1 слот = 1 предмет**.

## 2. Архитектура «Матрёшка» (генерация)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        ЭКИПИРОВКА                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   ┌──────────────────────────────────────────────────────────────────────┐   │
│   │              БАЗОВЫЙ КЛАСС — НЕИЗМЕНЕН                                │   │
│   │  ├── Тип          — weapon, armor, jewelry, charger, tool, artifact   │   │
│   │  ├── Подтип       — sword, torso, ring, belt, ...                    │   │
│   │  ├── Уровень      — 1-9 (определяет базовые параметры)               │   │
│   │  └── Требования   — сила, ловкость, уровень культивации              │   │
│   └──────────────────────────────────────────────────────────────────────┘   │
│                              +                                               │
│   ┌──────────────────────────────────────────────────────────────────────┐   │
│   │              МАТЕРИАЛ — НЕИЗМЕНЕН                                      │   │
│   │  ├── ID           — "iron", "spirit_iron", "dragon_bone", ...        │   │
│   │  ├── Тир          — 1-5 (определяет базовую прочность)               │   │
│   │  ├── Категория    — metal, organic, mineral, wood, crystal          │   │
│   │  └── Свойства     — проводимость, твёрдость, особые эффекты         │   │
│   └──────────────────────────────────────────────────────────────────────┘   │
│                              +                                               │
│   ┌──────────────────────────────────────────────────────────────────────┐   │
│   │              ГРЕЙД — ИЗМЕНЯЕМОЕ КАЧЕСТВО                               │   │
│   │  ├── Damaged     — Эффективность ×0.5, Прочность ×0.5                │   │
│   │  ├── Common      — Эффективность ×1.0, Прочность ×1.0                │   │
│   │  ├── Refined     — Эффективность ×1.3, Прочность ×1.5                │   │
│   │  ├── Perfect     — Эффективность ×1.6, Прочность ×2.5                │   │
│   │  └── Transcendent— Эффективность ×2.0, Прочность ×4.0                │   │
│   └──────────────────────────────────────────────────────────────────────┘   │
│                              +                                               │
│   ┌──────────────────────────────────────────────────────────────────────┐   │
│   │              ЗАЧАРОВАНИЕ — НАКЛАДЫВАЕМЫЙ МОДИФИКАТОР (опц.)           │   │
│   │  ├── T1–T5 (сила бонуса)                                              │   │
│   │  └── Категория: боевое / защитное / Ци / вампиризм / специальное     │   │
│   └──────────────────────────────────────────────────────────────────────┘   │
│                              =                                               │
│   ┌──────────────────────────────────────────────────────────────────────┐   │
│   │                    ИТОГОВЫЕ ПАРАМЕТРЫ                                 │   │
│   │  Эффективность = BaseStats × GradeMultiplier                         │   │
│   │  Прочность     = MaterialBaseDurability × GradeMultiplier            │   │
│   │  Проводимость  = MaterialConductivity × GradeMultiplier              │   │
│   │  Бонусы        = Σ(base, grade, material, set, enchant)              │   │
│   └──────────────────────────────────────────────────────────────────────┘   │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

> **5 источников бонусов предмета:** `base`, `grade`, `material`, `set`, `enchant`.

| Уровень | Damaged | Common | Refined | Perfect | Transcendent |
|---------|---------|--------|---------|---------|--------------|
| L1 | 30% | 60% | 10% | 0% | 0% |

### 4.3. Изменение грейда

**Повышение (апгрейд):**
- Требуются материалы + духовные камни.
- Шанс успеха: 50–95%.
- При провале: материалы потеряны.

**Понижение:**
- При плохом ремонте (качество < 50%).
- Шанс: 25–40%.
- Теряются бонусы и эффекты.

## 6. Система прочности

### 6.1. Состояния (5)

| Состояние | Прочность | Эффективность | Цвет |
|-----------|-----------|---------------|------|
| Pristine | 100% | 100% | 🟢 Зелёный |
| Good | 80–99% | 95% | 🟢 Светло-зелёный |
| Worn | 60–79% | 85% | 🟡 Жёлтый |
| Damaged | 20–59% | 60% | 🟠 Оранжевый |
| Broken | <20% | 20% | ⚫ Чёрный |

### 6.2. Потеря прочности

**Комбинированный метод:**

1. **Базовый износ** — при каждом использовании.
2. **Ударный износ** — при сильных ударах (урон выше порога).

**Порог удара** = `hardness × 10`.

**Пример:**
- Железный меч (твёрдость 5): порог = 50 урона.
- Если получен урон 80: дополнительный износ = (80 − 50) / 10 = 3.

### 6.3. Ремонт

| Метод | Требования | Результат |
|-------|------------|-----------|
| NPC-кузнец | Духовные камни + материалы | 100%, без риска |
| Самостоятельный | Навык + материалы | До 90%, риск понижения грейда |
| Ци-ремонт | Высокая культивация | Только для духовных материалов |

**Понижение грейда при плохом ремонте:**
- Качество < 50%: шанс понижения 25–40%.
- Понижение теряет бонусы и эффекты.

## 7. Система бонусов

### 7.1. Типы бонусов

**Combat:**
- `damage` — Урон
- `armorPenetration` — Пробитие
- `critChance` — Шанс крита
- `critDamage` — Крит. урон
- `attackSpeed` — Скорость атаки

**Defense:**
- `armor` — Броня
- `dodgeChance` — Уклонение
- `blockChance` — Блок
- `healthMax` — Макс. HP

**Qi:**
- `qiRestoration` — Восстановление Ци
- `qiConductivity` — Проводимость (только перки, не экипировка)
- `qiCostReduction` — Снижение стоимости

> ⛔ **Запрещено в бонусах экипировки:** `coreCapacity` (определяется уровнем культивации), `qiRegen` (10%/сутки, немодифицируема), первичные статы (STR/AGI/INT/VIT).

**Elemental:**
- `resistance_fire` / `resistance_water` / `resistance_earth` / `resistance_air` / `resistance_lightning` / `resistance_void`

**Special:** вампиризм, удача, восприятие и т. д.
**Utility:** скорость, скрытность, радиус подбора и т. д.

### 7.2. Структура бонуса

| Поле | Описание |
|------|----------|
| `type` | Тип бонуса |
| `value` | Значение |
| `isPercent` | `true` — процентный, `false` — абсолютный |
| `source` | `base` / `grade` / `material` / `set` / `enchant` |

### 7.3. Генерация бонусов по грейду

| Грейд | Кол-во бонусов | Множитель силы |
|-------|----------------|----------------|
| Damaged | 0 | — |
| Common | 0–1 | ×1.0 |
| Refined | 1–2 | ×1.3 |
| Perfect | 2–4 | ×1.6 |
| Transcendent | 4–6 | ×2.0 |

## 8. Система зачарования (Enchant)

### 8.1. Обзор

Зачарование — наложение магического эффекта на предмет экипировки. Это **5-й источник бонусов** (`enchant`), независимый от грейда и материала.

### 8.2. Типы зачарований

| Категория | Примеры | Эффект | Сила |
|-----------|---------|--------|------|
| Боевые | Пылающий клинок, Громовой удар | +X% урона стихией | +5% … +50% |
| Защитные | Каменная кожа, Ледяной щит | +X% защиты / сопротивления | +5% … +30% |
| Ци-зачарования | Поток Ци, Резонанс ядра | +X% qiRestoration, −X% qi_cost | +5% … +25% |
| Вампиризм | Кровавый клинок, Душепийца | life_steal, thorns | +5% … +30% |
| Специальные | Удача, Зоркость | +X% luck, perception | +5% … +20% |

### 8.3. Тиры зачарований (5)

| Тир | Сила бонуса | Требование к предмету | Метод нанесения |
|-----|-------------|----------------------|-----------------|
| **T1** (Обычное) | +5% … +10% | Common+ | Свиток зачарования, NPC |
| **T2** (Усиленное) | +10% … +20% | Refined+ | Свиток + духовный камень |
| **T3** (Мощное) | +20% … +30% | Perfect+ | Мастер-зачарователь + камень+ |
| **T4** (Великое) | +30% … +40% | Perfect+ | Ритуал формации + камень-кристалл |
| **T5** (Мифическое) | +40% … +50% | Transcendent | Артефакт зачарования + ядро дух. камня |

### 8.4. Правила

1. **Один слот зачарования** — предмет может иметь максимум 1 зачарование (T1–T3) или до 2 (T4–T5, но разных типов).
2. **Перезапись** — новое зачарование заменяет старое (старое теряется).
3. **Зависимость от грейда** — зачарование НЕ усиливает грейд и НЕ заменяет его. Это отдельный слой «Матрёшки».
4. **Множитель грейда** — сила зачарования умножается на множитель эффективности грейда:
   ```
   effectiveEnchant = baseEnchantValue × gradeEfficiencyMultiplier
   ```
   Пример: Зачарование «Пылающий клинок» (+15% урона огнём) на Perfect грейде (×1.6) → +24%.
5. **Совместимость** — стихийное зачарование может конфликтовать с innateElement практика (штраф −50% эффективности при несовпадении).

### 8.5. Примеры

**Пример 1: «Пылающий меч Небесного огня»**
```
База: Меч (sword), Steel T2, Refined
Грейд бонусы: +30% урона, ×1.3 эффективность
Зачарование: Пылающий клинок T2 (+15% урона огнём)
Итого: +30% физ. урон + (15% × 1.3) = +30% физ. + 19.5% огн.
```

**Пример 2: «Кольцо Духовного потока»**
```
База: Кольцо (ring), Jade T3, Perfect
Грейд бонусы: +60% qiConductivity, ×1.6 эффективность
Зачарование: Поток Ци T3 (+25% qiRestoration)
Итого: +60% qiConductivity + (25% × 1.6) = +60% cond. + 40% rest.
```

## 10. Оружие и урон

### 10.1. Классификация оружия

| Класс | Описание | Примеры |
|-------|----------|---------|
| Unarmed | Без оружия | Кулаки, когти |
| Light | Лёгкое | Кинжалы, короткие мечи |
| Medium | Среднее | Мечи, топоры, копья |
| Heavy | Тяжёлое | Двуручники, молоты |
| Ranged | Дальнобойное | Луки, арбалеты |
| Magic | Магическое | Посохи, жезлы |

### 10.2. Подтипы оружия

| Подтип | Слот | Урон | Скорость | Дальность |
|--------|------|------|----------|-----------|
| unarmed | hands | Низкий | Быстрая | 0.5 м |
| dagger | weapon_main/off | Средний | Быстрая | 0.5 м |
| sword | weapon_main | Высокий | Средняя | 1.0 м |
| greatsword | weapon_twohanded | Очень высокий | Медленная | 1.5 м |
| axe | weapon_main | Высокий | Средняя | 1.0 м |
| spear | weapon_twohanded | Высокий | Средняя | 2.0 м |
| bow | weapon_twohanded | Средний | Средняя | 30 м |
| staff | weapon_twohanded | Низкий | Медленная | 1.5 м |

### 10.3. Типы урона

| Тип | Описание | Эффективность |
|-----|----------|---------------|
| Slashing | Рубящий | Против ткани |
| Piercing | Колющий | Против щелей в броне |
| Blunt | Дробящий | Против хитина |
| Elemental | Стихийный | Зависит от элемента |

### 10.4. Формула урона оружия (гибридная)

```
baseDamage  = max(handDamage, weaponDamage × 0.5)
bonusDamage = weaponDamage × statScaling
totalDamage = baseDamage + bonusDamage

handDamage  = 3 + (STR − 10) × 0.3
statScaling = (STR × STR_BONUS + AGI × AGI_BONUS) / 100
```

### 10.5. Влияние на техники

Оружие с техникой `melee_strike`:
- Добавляет свой урон к урону техники.
- Может иметь бонус к урону техник.
- Может снижать стоимость Ци техник.

### 11.1. Параметры брони

| `armor` | Базовая броня | 1–100 |

| `dodgePenalty` | Штраф уклонения | −40% … 0% |

### 11.2. Подтипы брони

| Подтип | Защищаемые части тела | Покрытие |

### 11.3. Штрафы веса

**Базовая вместимость** = `10 + (STR − 10) × 2` кг.

**Перегруз:**
- Каждый кг перегруза: −0.5% скорости, −0.3% уклонения, +1% стоимости выносливости.

### 11.4. Проводимость Ци материалов

| Материал | Штраф к qi_efficiency |
|----------|----------------------|
| Ткань (cloth) | 0% |

| Железо (iron) | −10% |
| Сталь (steel) | −15% |
| Холодное железо | −20% |
| Духовное железо | +5% |
| Нефрит (jade) | +10% |

### 11.5. Объём экипировки

| Категория | Формула `volume` | Пример |
|-----------|------------------|--------|
| Оружие | `clamp(weight, 1, 4)` | Меч 2.5 кг → 2.5 ед. |
