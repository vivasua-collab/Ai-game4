# Система фракций

> **Раздел:** Сущности мира — социальная структура
> **Статус:** Концептуальная спецификация (дизайн-документ)
> **Самостоятельный документ:** не требует иных файлов для понимания.
>
> Этот документ описывает **политическую структуру мира**: государства, альянсы, секты; а также расчёт отношений и репутации.

---

## 1. Назначение

Система фракций описывает политическую структуру мира: государства, альянсы и секты. Культиваторы стоят над светской жизнью, но секты служат признаком государственной принадлежности и формируют политическую карту мира.

---

## 2. Иерархия принадлежности

```
1. ГОСУДАРСТВО (Nation)
   ├── Территория (границы, законы)
   ├── Светская власть (император, наместники)
   └── Союзы сект (официальные и неофициальные)

2. ФРАКЦИЯ (Faction) — Альянс сект
   ├── Идеология (праведный путь, демонический, нейтральный)
   ├── Политическое влияние
   └── Секты-участники

3. СЕКТА (Sect)
   ├── Организация культиваторов
   ├── Ресурсы, территории, техники
   ├── Иерархия (ученики, старейшины, мастер)
   └── Принадлежность к государству/фракции

4. КУЛЬТИВАТОР (Character/NPC)
   ├── Личность (над государственными границами)
   ├── Членство в секте (опционально)
   └── Одеяние секты (визуальная принадлежность)
```

## 5. Секта (Sect)

### 5.1. Типы сект

| Тип | Описание |
|-----|----------|
| `orthodox`    | Ортодоксальная (традиционная) |
| `unorthodox`  | Неортодоксальная (нетрадиционные методы) |
| `demonic`     | Демоническая (запретные практики) |
| `neutral`     | Нейтральная |
| `scholarly`   | Учебная (академия) |
| `martial`     | Боевая (военная) |

### 5.2. Статус секты

| Статус | Описание |
|--------|----------|
| `official`     | Официальная (признана государством) |
| `underground`  | Подпольная (скрытая) |
| `exiled`       | Изгнанная |
| `nomadic`      | Кочевая |
| `independent`  | Независимая |

### 5.3. Параметры секты

| Параметр | Описание |
|----------|----------|
| `name`                | Название |
| `description`         | Описание |
| `locationId`          | ID локации штаб-квартиры |
| `powerLevel`          | Уровень мощи |
| `nationId`            | Государство |
| `factionId`           | Фракция/Альянс |
| `sectType`            | Тип секты |
| `standing`            | Статус |
| `relations`           | Отношения с другими сектами |
| `insignia`            | Визуальная идентификация (цвета, символ, узор) |
| `reputation`          | Репутация (overall, byNation, byFaction) |
| `atWar`               | Список сект, с кем в состоянии войны |
| `allied`              | Список союзников |
| `vassalOf`            | Вассалитет (если есть) |
| `vassals`             | Вассальные секты |

### 5.4. Структура отношений секты

```
SectRelations:
  sects:     {sectId → disposition (-100..+100)}
  atWar:     [sectId, ...]    // С кем в состоянии войны
  allied:    [sectId, ...]    // С кем в союзе
  vassalOf:  sectId           // Вассалитет
  vassals:   [sectId, ...]    // Вассальные секты
```

## 6. Одеяние секты (Sect Attire)

### 6.1. Назначение

1. Показывает принадлежность культиватора к секте.
2. Влияет на отношение других NPC.
3. Даёт бонусы (репутация, защита).
4. Может быть снято для скрытия принадлежности.

### 6.2. Эффекты

| Эффект | Описание |
|--------|----------|
| `attitudeBonusWithSect`     | + к отношению с членами секты |
| `attitudePenaltyWithEnemies`| − к отношению с врагами секты |
| `reputationModifier`        | Множитель репутации |

### 6.3. Слоты экипировки

- Основное одеяние — слот `torso`.
- Дополнительные элементы: значок секты (`accessory1`), пояс секты (`accessory2`).

### 6.4. Примеры одеяний

| Секта | Цвета | Символ | dispositionBonusWithSect | dispositionPenaltyWithEnemies | reputationModifier |
|-------|-------|--------|--------------------------|-------------------------------|--------------------|
| Небесного Меча | Небесно-голубой + серебристый | ⚔️ | +20 | −15 | ×1.1 |
| Кровавой Луны  | Тёмно-красный + чёрно-синий   | 🌙 | +25 | −30 | ×0.8 |

## 7. Расчёт отношений

### 7.1. Иерархия уровней отношений

| Уровень | Влияние | Источник |
|---------|---------|----------|
| **Личный**         | 100% (вес 1.0) | Действия игрока, диалоги, квесты |
| **Сектовый**       | 50% (вес 0.5)  | Войны, союзы, политические действия |
| **Фракционный**    | 30% (вес 0.3)  | Идеологические конфликты, альянсы |
| **Государственный**| 20% (вес 0.2)  | Дипломатия, войны, торговля |

### 7.2. Формула итогового attitude

```
finalAttitude =
    + personalAttitude
    + sectRelation      × 0.5
    + factionRelation   × 0.3
    + nationRelation    × 0.2
    + attireModifier
    + reputationModifier
```

### 7.3. Пороги Attitude

| Значение | Отношение | Поведение |
|----------|-----------|-----------|
| 80–100   | Клятвенный союзник | Самопожертвование |
| 50–79    | Союзник | Лояльность |
| 10–49    | Друг | Помощь, торговля |
| −9..9    | Нейтральный | Безразличие |
| −20..−10 | Недоброжелательный | Избегание |
| −50..−21 | Враждебный | Атака если спровоцирован |
| −100..−51 | Ненависть | Атака без предупреждения |

### 7.4. Примеры расчёта

**Пример 1: Член враждебной секты**
```
personal: 0 (не знает лично) × 1.0 = 0
sect:     −80 (враги) × 0.5 = −40
attire:   −30 (штраф за одеяние врага)
Итого:    0 + (−40) + (−30) = −70 → Враждебный
```

**Пример 2: Односектовец**
```
personal: 20 (немного знает) × 1.0 = 20
sect:     50 (одна секта) × 0.5 = 25
attire:   +20 (бонус за одеяние секты)
Итого:    20 + 25 + 20 = 65 → Союзник / Друг
```

| `enemy`   | Враг (война или вражда) |

## 9. Репутация

### 9.1. Структура репутации секты

```
reputation:
  overall:     -100..+100  // Общая репутация
  byNation:    {nationId → disposition}
  byFaction:   {factionId → disposition}
```

### 9.2. Источники изменения репутации

- **Квесты:** успешное выполнение повышает репутацию секты.
- **Преступления:** нападение на членов секты — снижение.
- **Дипломатия:** союзы и альянсы — изменение.
- **События мира:** войны между сектами — изменение всех вовлечённых.

## 11. Архитектурное представление

Система фракций реализуется как **модуль** приложения:

| Компонент | Назначение |
|-----------|------------|
| Менеджер фракций    | Центральный доступ к фракциям, сектам, государствам |
| Данные государства  | Хранение государств (Nation) |
| Данные фракции      | Хранение фракций (Faction) |
| Данные секты        | Хранение сект (Sect) |
| Калькулятор отношений| Расчёт `finalAttitude` по формуле (§7.2) |
| Реестр одеяний      | Конфигурация одеяний сект и их эффектов |

Сообщения между подсистемами — неизменяемые структуры (zero-GC). Кросс-модульные взаимодействия — через **шину событий** (`FactionRelationChanged`, `SectWarDeclared`, `ReputationChanged`).

Сохранение: фракции, секты, государства являются `ISaveable`. Динамические отношения и репутация — в `relations` и `reputation` полях.

Производительность:
- Расчёт `finalAttitude` — O(1) (сумма 4–6 значений).
- Вызывается при каждом взаимодействии NPC с игроком.
- Кэширование: результат кэшируется до изменения любого источника.

## 12. Интеграция

### 12.1. С NPC AI

- Расчёт `finalAttitude` используется в `NPC_AI_SYSTEM.md` для выбора поведения (атака, бегство, диалог).
- Пороги Attitude (§7.3) — те же, что в `NPC_AI_SYSTEM.md` §10.

### 12.2. С NPC

- Каждый NPC имеет `SectId` (опционально) и `AttitudeScore` к игроку.
- При спавне NPC наследует отношение своей секты к игроку (если личное ещё не сформировано).

### 12.3. С экипировкой

- Одеяние секты — отдельный подтип экипировки.
- При надевании одеяния — пересчёт `attireModifier` для всех NPC поблизости.

### 12.4. С диалогами

- Диалоги с NPC зависят от `finalAttitude`.
- Торговля, обучение, квесты — доступны только при достаточном Attitude.
