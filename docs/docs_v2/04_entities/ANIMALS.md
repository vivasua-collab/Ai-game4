# Животные (Animals)

> **Назначение:** Движко-независимая спецификация простых животных в мире: виды, спавн, тело, поведение, retaliation.
>
> **Связанные документы:** [BODY_SYSTEM.md](../02_systems/BODY_SYSTEM.md), [NPC_AI_SYSTEM.md](./NPC_AI_SYSTEM.md), [COMBAT_SYSTEM.md](../02_systems/COMBAT_SYSTEM.md), [DEATH_AND_LOOT.md](./DEATH_AND_LOOT.md), [PROCEDURAL_SPRITES.md](../07_ui/PROCEDURAL_SPRITES.md).

---

## 1. Виды

В игре реализовано три вида простых животных. Все используют морфологию `Quadruped`.

| Вид | Морфология | Размер | STR / END / AGI / INT | Диспозиция |
|-----|-----------|--------|------------------------|------------|
| Волк (wolf) | Quadruped | Medium | 8 / 14 / 10 / 4 | Neutral → Hostile при уроне (retaliation) |
| Олень (deer) | Quadruped | Medium | 6 / 12 / 8 / 2 | Neutral, мирный |
| Кролик (rabbit) | Quadruped | Small | 3 / 14 / 4 / 1 | Neutral, быстрый, мирный |

> Порядок стат: **STR / END / AGI / INT**. Числа — абсолютные значения характеристик.

### 1.1. Отличия по размеру
- **Medium** (волк, олень): стандартные HP частей тела, стандартная скорость движения.
- **Small** (кролик): пониженный множитель HP (×0.5), повышенная базовая скорость движения (+25%).

## 2. Спавн

### 2.1. Количество
- При старте сцены спавнится **3–5 животных** (рандомное число в диапазоне).

### 2.2. Детерминированность
- Все случайные решения (какой вид, какое количество, где именно) использует `SeededRandom` с фиксированным seed.
- Одинаковый seed → одинаковый спавн. См. [ALGORITHMS.md](../09_workflow/ALGORITHMS.md).

### 2.3. Распределение
- Вид выбирается равновероятно из трёх (wolf / deer / rabbit) либо по весам биома (если биом определяет фауну).
- Позиция — в радиусе N тайлов от стартовой точки игрока, но не ближе 8 тайлов (чтобы не было мгновенной агрессии).

## 3. Body Assembly

### 3.1. Принцип
Каждое животное получает собранное тело через `BodyFactory.CreateBody(morphology, size, vitality)`.

```
BodyFactory.CreateBody(
    morphology = Quadruped,
    size       = Medium | Small,
    vitality   = (зависит от вида: волк = средняя, кролик = низкая)
)
→ IBodyDataProvider (для NPC/животных)
```

### 3.2. Структура тела Quadruped
- 8 частей: голова, торс, сердце, передняя левая нога, передняя правая нога, задняя левая нога, задняя правая нога, хвост.
- Каждая часть имеет RedHP (функциональный) и BlackHP (структурный).
- Сердце — только RedHP (нет структурного HP). См. [BODY_SYSTEM.md §5](../02_systems/BODY_SYSTEM.md).

### 3.3. Масштабирование HP
```
effectiveHP = baseHP × vitalityMultiplier × sizeMultiplier
```
- `vitalityMultiplier` — множитель по виду (волк = 1.0, олень = 0.85, кролик = 0.6).
- `sizeMultiplier` — Medium = 1.0, Small = 0.5.

## 4. Поведение

### 4.1. Случайное блуждание (wander)
- Каждые **2–5 секунд** (cooldown зависит от вида) животное выбирает новую точку цели в радиусе **5 тайлов** от текущей позиции.
- Движется к цели обычным путём (без A*, простое прямолинейное движение).

### 4.2. Cooldown по виду
| Вид | Cooldown wander |
|-----|-----------------|
| Волк | 3 сек |
| Олень | 4 сек |
| Кролик | 2 сек (чаще перемещается) |

### 4.3. Покой
- Если цель достигнута — животное стоит до следующего wander-тика.
- Не агрессивно к игроку по умолчанию (Neutral).

---

## 5. Retaliation

### 5.1. Триггер
- При получении урона животное помечается как `hostile` (только к атаковавшему, не глобально).

### 5.2. Поведение hostile
- Прекращает wander.
- Начинает преследовать атаковавшего.
- Публикует `AttackIntentEvent` каждые **3 тика** (3 игровые минуты) — пока цель в зоне досягаемости.

### 5.3. Cooldown атаки
- Cooldown между атаками: **3 тика** (1 атака / 3 тика).

### 5.4. Прекращение retaliation
- Цель уходит из радиуса агро (5 тайлов) → животное возвращается к wander через ~5 тиков.
- Цель умирает → животное возвращается к wander.
- Само животное умирает → `NPCDeathEvent`, лут выпадает (см. [DEATH_AND_LOOT.md](./DEATH_AND_LOOT.md)).

> Кролик retaliation не применяет (мирный вид) — вместо этого удваивает скорость убегания.

## 6. Спрайты

### 6.1. Размер и палитра
- Все спрайты животных — **48×48 пикселей**, процедурно генерируемые.

| Вид | Базовый цвет | Отличительные черты |
|-----|--------------|---------------------|
| Волк (wolf) | Серый | Острая морда, уши торчком, пушистый хвост |
| Олень (deer) | Коричневый | Рога (ветвистые), длинные ноги |
| Кролик (rabbit) | Белый | Длинные уши, короткий хвост-помпон |

### 6.2. Кэширование
- Один спрайт на вид создаётся один раз и кэшируется.
- Переиспользуется всеми экземплярами того же вида.
- См. [PROCEDURAL_SPRITES.md](../07_ui/PROCEDURAL_SPRITES.md) для общего принципа.
