## 1. Назначение

Все объекты мира делятся на две верхние категории:

| Категория | Название | Контроллер | Примеры |
|-----------|----------|------------|---------|
| **Живые**   | SoulEntity    | player / ai | Игрок, NPC, монстры, духи, големы |
| **Неживые** | PhysicalObject | none | Камни, руды, деревья, строения |

```
ВСЕ ОБЪЕКТЫ МИРА
├── ЖИВЫЕ (SoulEntity)
│   ├── ✅ Игрок, NPC, монстры
│   ├── ✅ Духи, големы
│   ├── ✅ Духовные артефакты
│   │
│   └── Признаки:
│       • Душа (Soul)
│       • Контроллер (player / ai)
│       • Body + Qi + Mind
│
└── НЕЖИВЫЕ (PhysicalObject)
    ├── ⬜ Камни, руды
    ├── ⬜ Деревья, растения
    ├── ⬜ Строения, декорации
    │
    └── Признаки:
        • Нет души
        • controller = 'none'
        • Только физика
```

## 2. Трёхуровневая система классификации

```
УРОВЕНЬ 1: SoulType — ПЕРВИЧНЫЙ
   Определяет: Структура сущности (Body + Qi + Mind)
   Значения: character | creature | spirit | artifact | construct
                       │
                       ▼
УРОВЕНЬ 2: Morphology — ВТОРИЧНЫЙ
   Определяет: Внешняя форма тела
   Значения: humanoid | quadruped | bird | serpentine | amorphous | ...
                       │
                       ▼
УРОВЕНЬ 3: Species — КОНКРЕТНЫЙ
   Определяет: Конкретный вид с уникальными характеристиками
   Значения: human | elf | wolf | dragon | ghost | golem | ...
```

## 3. Уровень 1: SoulType (Природа сущности)

| SoulType | Body | Qi | Mind | Описание | Примеры |
|----------|------|-----|------|----------|---------|
| `character` | ✅ organic        | ✅ core       | ✅ full      | Разумные существа | Игрок, NPC, Эльф, Демон |
| `creature` | ✅ organic/scaled | ✅ core       | ⚠️ instinct  | Животные, звери   | Волк, Тигр, Дракон |
| `spirit`   | ❌ / ethereal     | ✅ reservoir  | ✅ full      | Бесплотные сущности | Призрак, Элементаль |
| `artifact` | ✅ mineral        | ✅ reservoir  | ⚠️ simple    | Разумные предметы  | Разумный меч |
| `construct` | ✅ mineral/organic | ✅ reservoir | ⚠️ simple    | Искусственные создания | Голем |

### Характеристики по типам

**Character:**
- Полное сознание и речь.
- Может культивировать (ядро).
- Может использовать техники.
- Социальные взаимодействия.

**Creature:**
- Инстинктивное поведение.
- Может культивировать (ядро).
- Врождённые техники.
- Не может говорить (обычно).

**Spirit:**
- Полное сознание.
- Резервуар Ци (не ядро).
- Эфирное тело.
- Иммунитет к физике.

**Artifact:**
- Простое сознание.
- Резервуар Ци.
- Материальное тело.
- Специфические функции.

**Construct:**
- Простое сознание.
- Резервуар Ци.
- Искусственное тело.
- Следует командам.

## 6. Материалы тела

| Материал | Твёрдость | Снижение урона | Особенности |
|----------|-----------|----------------|-------------|
| `organic`  | 3 | 0%  | Базовый материал |
| `scaled`   | 6 | 30% | Чешуя, защита от физики |
| `chitin`   | 5 | 20% | Экзоскелет, уязвим к дробящему |
| `ethereal` | 1 | 70% физики | Проходит сквозь материю |
| `mineral`  | 8 | 50% | Камень, очень твёрдый |
| `chaos`    | 5 | Переменно | Непредсказуемые свойства |

> Материал снижает входящий **физический** урон (damage reduction).
> Конструкты (`construct`) не имеют собственного материала тела — их материал определяется составом (минерал, органика и т.д.).

## 7. SoulEntity (Живые объекты)

### 7.1. Архитектура

```
SOUL ENTITY (ЖИВАЯ СУЩНОСТЬ)
│
├── SOUL CORE (ОБЯЗАТЕЛЬНО)
│   id | soulType | controller (player/ai) | status
│
├── BODY (опционально)
│   Физическое тело
│   Части тела с HP
│   Материал тела
│   Морфология
│
├── QI (обязательно)
│   Ядро (для character, creature) или резервуар (для spirit, construct)
│   Текущее и максимальное Ци
│   Проводимость
│
├── MIND (опционально)
│   Тип сознания (full, instinct, simple)
│   Личность (для character):
│     • Attitude (числовое -100..+100)
│     • PersonalityTrait [Flags] — 8 черт характера
│   Память и знания
│
└── ATTACHMENTS
    techniques[] | inventory[] | effects[]
```

### 7.2. Компоненты

**Soul Core (обязательно):**
- Уникальный идентификатор.
- Тип сущности (SoulType).
- Контроллер (player или ai).
- Статус (alive, dead, unconscious).

**Body (опционально):**
- Физическое тело.
- Части тела с HP.
- Материал тела.
- Морфология.

**Qi (обязательно):**
- Ядро (для `character`, `creature`) или резервуар (для `spirit`, `construct`).
- Текущее и максимальное Ци.
- Проводимость.

**Mind (опционально):**
- Тип сознания (`full`, `instinct`, `simple`).
- Личность (для `character`):
  - **Attitude** (числовое −100..+100) — отношение к цели.
  - **PersonalityTrait [Flags]** — 8 черт характера: Aggressive, Cautious, Treacherous, Ambitious, Loyal, Pacifist, Curious, Vengeful.
- Память и знания.

> **Attitude + PersonalityTrait** — замена устаревшего `Disposition`. См. `04_entities/NPC_AI_SYSTEM.md`.

## 8. PhysicalObject (Неживые объекты)

### 8.1. Архитектура

```
PHYSICAL OBJECT (НЕЖИВОЙ ОБЪЕКТ)
│
├── BASE (ОБЯЗАТЕЛЬНО)
│   id | name | category (resource/structure/container/decoration/item)
│
├── PHYSICS (обязательно)
│   Положение, коллизия
│
├── DURABILITY (опц.)
│   Прочность, износ
│
├── QI STORE (опц.)
│   Хранилище Ци (для камней Ци, артефактов)
│
└── CONTENTS
    resources[] | inventory[] | interactions[]
```

### 8.2. Категории

| Категория | Взаимодействие | Примеры |
|-----------|----------------|---------|
| `resource`    | mine, harvest, chop | Руда, дерево, трава |
| `structure`   | — | Стены, здания |
| `container`   | open | Сундуки |
| `decoration`  | — | Камни, статуи |
| `item`        | use | Предметы |

## 9. Дополнительные типы сущностей

Помимо базовых SoulEntity и PhysicalObject, в мире присутствуют производные сущности, обслуживающие игровые механики:

| Тип | Описание | Связь |
|-----|----------|-------|
| **Projectile**      | Снаряды (стрелы, огненные шары, Ци-удары) | Создаются техниками, имеют короткое время жизни |
| **Formation**       | Активная магическая формация (см. `02_systems/FORMATION_SYSTEM.md`) | Не является ни живой, ни неживой — это **поле эффекта** |
| **Effect zone**     | Зона визуального/механического эффекта (ливень, дым) | Временная, не сохраняется |
| **Drop / Loot**     | Выпавший предмет на земле | Подтип `item` с положением в мире |

> **Производные сущности** реализуются через pooling (объектный пул), поскольку создаются и уничтожаются с высокой частотой. См. `01_architecture/PERFORMANCE_STRATEGY.md`.

## 10. Сравнение SoulEntity vs PhysicalObject

| Критерий | SoulEntity | PhysicalObject |
|----------|------------|----------------|
| **Душа** | ✅ Есть | ❌ Нет |
| **Контроллер** | player / ai | none |
| **Действия** | Осознанные | Реактивные |
| **Движение** | Самостоятельное | Неподвижны |
| **Qi** | core или reservoir | qiStore (опц.) |
| **Техники** | ✅ Используют | ❌ Не могут |
| **Инвентарь** | ✅ Носит | ✅ Может содержать |
| **Развитие** | ✅ Культивация | ❌ Нет |

## 11. Архитектурное представление

Сущности реализуются как **композиция компонентов**, управляемых модулями:

- **SoulEntity** — это не единый класс, а композиция: soul core + body + qi + mind. Каждый компонент управляется соответствующим модулем (Body Module, Qi Module, NPC Module, Player Module).
- **PhysicalObject** — отдельный модуль мира (World Module), управляет размещением, коллизиями, взаимодействиями.
- **Projectile / Effect zone** — пулируемые сущности, создаваемые боевым модулем.

Кросс-модульные взаимодействия:
- Сущность может получать урон через **единую систему BodyParts** (DamageService).
- Сущность может быть целью техник, баффов, эффектов через **уникальный идентификатор**.
- Сущность публикует события через **шину событий** (`DamagedEvent`, `HealedEvent`, `DiedEvent`).
